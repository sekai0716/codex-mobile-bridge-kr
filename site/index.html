    FOUR CLIENTS / ONE BRIDGE

    네 가지 앱의 작업을 각각 이어서.

    컴퓨터에 설치된 클라이언트를 검색하고 필요한 클라이언트만 활성화하세요. 하단 표시줄에서 앱을 전환하거나 채팅 목록을 스와이프하세요.

    Codex

    모델, 기술, 승인, 계획 및 목표 제어를 통해 로컬 및 SSH 채팅을 계속하세요. 공식 계정 및 호환 API는 원래 데스크톱 작업 공간에 유지됩니다.

    Claude Desktop

    코드 및 Cowork 세션은 그룹화되어 있습니다. 메시지를 계속하고 지원되는 승인에 응답하세요. 자동 설정은 macOS 및 Windows를 지원합니다. 초기 연결에는 잠금 해제된 데스크톱이 필요할 수 있습니다.

    DeepSeek Harness

    귀하의 계정과 작업 공간을 유지하면서 호환되는 Harness 플러그인을 통해 연결하세요. 모델, 추론 및 보고된 할당량을 검사합니다. 모바일 앱은 별도의 네이티브 DSH 모바일 페이지를 열 수도 있습니다.

    ZCode

    네이티브 채팅을 계속하고, 첨부 파일을 보내고, 승인을 처리하세요. 모델과 기술을 선택하고, API 연결을 관리하고, 보고된 할당량을 검사하세요. macOS, Windows 또는 Linux에서 로컬로 연결하거나 구성된 공식 원격 액세스를 사용하십시오.

    02 / THE WORKBENCH

    작은 화면에서 채팅하는 것 이상의 기능을 제공합니다.

    채팅, 파일 및 도구가 하나의 작업대에 함께 제공됩니다. 모바일 웹, Android, iOS 및 데스크톱 브라우저는 각 화면에 맞게 세션을 공유합니다.

    01 / FILES

    프로젝트 파일을 손쉽게 이용할 수 있습니다.

    먼저 휴대폰에 다운로드할 필요 없이 메시지에서 직접 프로젝트 폴더와 참조 호스트 파일 또는 폴더를 찾아보세요. 마크다운, 소스 및 이미지 미리보기 코드 블록에 대한 구문 강조 및 정확한 복사를 통해 요청 시 Claude 및 DSH 기록 이미지를 로드합니다.

    채팅 다운로드 제한을 실시간으로 조정하세요. 파일 탭의 명시적 다운로드에는 이 제한이 사용되지 않습니다.

    02 / TERMINAL

    상태를 유지하는 터미널입니다.

    작업 디렉터리, 환경 및 대화형 상태를 유지합니다. 사용자가 구성한 셸(일반적으로 macOS에서는 zsh, Linux에서는 bash, Windows에서는 COMSPEC)을 사용합니다. 전화기에서 여러 회선을 작성한 다음 명시적으로 보냅니다.

    탭을 전환하면 세션이 유지됩니다. 터미널을 닫으면 종료됩니다.

    03 / GIT

    변경사항을 검토하세요. 커밋을 하세요.

    휴대폰에서 차이점을 검토하고 그래프를 커밋하고 파일을 준비하고 커밋 메시지를 작성하세요. 로컬 브랜치를 생성 또는 전환하고, 로컬로 병합하고, 병합을 중단합니다.

    원격 푸시, 기록 다시 쓰기 또는 강제 삭제가 없습니다.

    04 / SIDE CHAT

    Codex 보조 채팅에서 생각을 탐색해 보세요.

    기존 Codex 보조 채팅을 네이티브 상위 항목 아래의 탭으로 엽니다. 메시지를 계속 보내고, 사용 가능한 모델을 선택하고, 지원되는 요청을 처리하세요. 탭을 닫으면 네이티브 채팅이 유지됩니다.

    사용 가능한 작업은 네이티브 클라이언트 및 연결에 따라 다릅니다. 데모에는 v2.0.0 상호 작용 예제가 유지됩니다.

    05 / SPLIT VIEW

    넓은 화면으로 업무를 처리하세요.

    왼쪽에 기본 채팅을 유지하고 오른쪽에 파일, Git, 터미널 또는 보조 채팅을 유지합니다. 탭을 드래그하여 구분선을 분할하고 크기를 조정하세요. 세부 창에는 높이 조절이 가능합니다. 전화기와 좁은 화면은 하나의 창을 유지합니다.

    분할 보기는 사용 가능한 공간에 따라 채팅 창 너비가 720px 이상인 경우 사용할 수 있습니다.

    06 / SUBAGENTS

    Codex 하위 에이전트를 팔로우하세요.

    현재 채팅에서 생성된 하위 에이전트를 검사합니다. 기본 대화를 종료하지 않고도 최근에 저장된 입력, 응답 및 도구 기록을 열 수 있습니다.

    읽기 전용 기록; 하위 에이전트 생성, 메시징 또는 중지는 사용할 수 없습니다.

    v2.0.0 분할 화면 인터페이스 보기

    03 / MADE FOR YOUR PHONE

    하나의 앱. 컴퓨터가 연결되었습니다.

    Mac, Windows 또는 Ubuntu 게이트웨이를 스캔하고 저장한 다음 컴퓨터 목록에서 전환하세요. 앱별 읽지 않은 배지는 선택한 클라이언트로 직접 연결됩니다.

    01

    연결 및 로그인

    하나의 컴퓨터 카드에 그룹 LAN, 고정 HTTPS 및 임시 HTTPS 경로가 있습니다. 대기 시간을 검사하고, 채팅, 초안 및 읽기 위치를 유지하면서 자동으로 경로를 선택하거나 전환하세요. 데스크톱에서 장치를 취소합니다.

    02

    일상적인 상호작용

    자세한 내용, 이름 변경, 고정 및 프로젝트 구성을 보려면 채팅 제목을 길게 누르거나 마우스 오른쪽 버튼으로 클릭하거나 탭하세요. 네이티브 작업은 클라이언트 지원에 따라 다릅니다. Bridge 전용 카테고리에는 명확하게 라벨이 지정되어 있습니다.

    03

    필요한 기능을 갖춘 메시지 입력창

    채팅을 만들기 전에 모델과 추론 수준을 선택하고 이후에도 해당 선택을 유지하세요. 기술, 권한, 첨부 파일 및 지원 모드를 사용합니다. 보류 중인 다른 답변을 잃지 않고 개별 Codex 비동기 질문을 건너뜁니다.

    04

    모양, 언어 및 업데이트

    채팅 내용을 변경하지 않고 UI 언어를 전환하세요. 모바일 설정에서 밝음, 어두움 또는 시스템 모양을 선택하세요. Android에서는 현재 네이티브 설정에 적용되지만 채팅 모양은 별도로 구성됩니다. 앱 업데이트를 수동으로 확인하세요.

    모바일 앱 다운로드 ↗Android APK · iOS IPA(자체 서명 필요)

    STAY IN THE LOOP

    진행 상황을 놓치지 마세요.

    Android는 선택적 배경 알림을 제공하며 기본적으로 꺼져 있습니다. 별도의 이벤트는 별도의 알림을 유지하므로 한 채팅의 승인 및 완료 미리 알림이 더 이상 서로를 대체하지 않습니다. 연결당 소스를 선택하세요. iOS는 전경 알림을 지원합니다. Bark, ntfy 및 PushPlus도 사용할 수 있습니다.

    iOS 다이나믹 아일랜드 & 라이브 액티비티

    실행, 승인, 연결 상태를 확인한 후 탭하여 채팅으로 돌아갑니다. 채팅 내용은 비공개로 유지됩니다. 비활성 앱은 마지막으로 알려진 상태를 표시할 수 있습니다.

    iOS 배경 및 잠금 화면 제공은 아직 보장되지 않습니다. 라이브 활동은 백그라운드 푸시가 아닙니다. Android 백그라운드 알림은 시스템 권한 및 배터리 정책에 따라 다릅니다.

    01 / WALKTHROUGH

    실제로 확인해 보세요.

    게이트웨이 시작부터 다른 장치에서 채팅 계속까지 실제 인터페이스를 따르십시오.

    실제 인터페이스 · 샘플 데이터 · 한국어 및 영어 자막 영상 열기 ↗

    02 / GET STARTED

    작업을 선택하는 4단계.

    로컬 네트워크에서 시작하십시오. 필요할 때 외부 연결을 추가하세요.

    1. 1

      앱을 다운로드하고 엽니다.

      필요한 클라이언트를 설치하고 로그인한 다음 운영 체제에 맞는 Codex Mobile Bridge를 엽니다.

    2. 2

      게이트웨이를 시작하세요

      클라이언트 및 연결에서 앱을 스캔하고 선택합니다. LAN 액세스를 활성화한 상태로 유지하고 저장한 다음 게이트웨이를 시작합니다.

    3. 3

      주소를 스캔하거나 열어보세요

      휴대폰에서 로그인 코드를 스캔하거나 다른 컴퓨터에서 주소를 열고 게이트웨이 자격 증명을 사용하세요.

    4. 4

      채팅을 선택하고 계속하세요

      기존 채팅을 열거나 새로 만드세요. 진행 상황을 따르고, 메시지를 보내고, 지원되는 승인에 응답하세요.

    매일 LAN를 사용하려면 Python, Node.js 또는 배포 에이전트가 필요하지 않습니다. QR 코드는 로그인을 처리합니다. 네트워크에 계속 연결할 수 있어야 합니다. 각 로그인 코드는 수명이 짧고 일회용입니다.

    ACCOUNTS 및 PROVIDERS

    데스크탑에서 설정하세요. 두 장치 중 하나에서 전환하십시오.

    공식 계정과 커스텀 API가 한 곳을 공유합니다. 전환하기 전에 활성 작업을 완료하세요. Codex는 게이트웨이가 온라인 상태를 유지하는 동안 다시 시작됩니다.

    03 / CAPABILITIES

    손이 닿는 곳에 완전한 워크플로우가 있습니다.

    채팅, 승인부터 읽기, 알림까지 워크플로에 필요한 도구를 찾아보세요.

    설정된 Codex 워크플로는 계속 사용할 수 있습니다. Claude 및 DeepSeek는 자체 클라이언트에서 지원하는 작업을 노출합니다.

    01

    채팅 및 프로젝트

    • 채팅을 계속하세요. 프로젝트 없이 프로젝트 채팅 또는 Codex 채팅 만들기
    • 원래 환경과 로컬 및 SSH 채팅
    • 최근 활동, 프로젝트 그룹 및 검색
    • 최신 메시지를 편집하거나 새 분기에서 이전 메시지를 편집하세요.
    • 완료된 회전에서 분기합니다. 완전한 응답 및 코드 복사
    02

    작업 및 승인

    • 후속 조치 보내기, 진행 중인 작업 조정 또는 작업 중지
    • 다음 메시지를 대기열에 추가하거나 취소하세요.
    • 명령, 파일 및 질문 카드에 응답합니다. 지원되는 컴퓨터 사용 승인 범위 선택
    03

    계획 및 목표

    시청 장치에 동일한 OpenAI 계정이 필요합니까?

    아니요. 게이트웨이에는 자체 로그인이 있습니다. 모델 요청은 원래 Codex 채팅의 공급자와 인증을 유지합니다. 공식 로그인, API 또는 맞춤 서비스는 원래 앱에서 이미 작동해야 합니다.

    휴대폰, 태블릿 또는 다른 컴퓨터를 사용할 수 있나요?

    최신 브라우저를 사용하여 게이트웨이에 접근하세요. 호스트 앱 패키지는 macOS, Windows 및 실험적인 Ubuntu x64/ARM64에서 사용할 수 있습니다. 보기 장치는 동일한 운영 체제를 사용할 필요가 없습니다.

    호스트를 끈 후에도 작동합니까?

    아니요. 호스트를 깨우고 연결하여 원래 Codex 앱 및 게이트웨이를 실행하세요. SSH 작업에는 호스트와 연결도 사용 가능해야 합니다.

    채팅 알림을 어떻게 활성화하나요?

    귀하의 설정에 따라 요청 및 완료 알림을 받습니다. 컴퓨터 목록에는 앱별 읽지 않은 개수가 표시됩니다. Android 백그라운드 알림은 선택이 필요하며 시스템 권한 및 배터리 정책에 따라 달라집니다. iOS는 주로 포그라운드에서 동기화됩니다. 연결당 소스를 선택하거나 Bark, ntfy 또는 PushPlus를 구성합니다.

    계정이나 API 연결을 어떻게 전환하나요?

    현재 안정 릴리스를 사용하고 브라우저를 새로 고치십시오. Bridge 데스크톱 앱의 계정에서 연결을 추가하거나 가져온 다음 데스크톱이나 웹에 저장된 연결을 전환하세요. 활성 작업을 먼저 완료하세요. 전환하면 Codex가 다시 시작되고 Bridge 게이트웨이는 온라인 상태로 유지됩니다.

    macOS가 개발자를 확인할 수 없거나 앱이 손상되었다고 말하면 어떻게 되나요?

    릴리스 SHA-256을 확인한 다음 시스템 설정 → 개인정보 보호 및 보안에서 앱을 허용해 보세요. 자세한 단계는 사용 가이드의 첫 번째 실행 섹션을 따르세요.

    데스크탑이 여전히 필요한 요청은 무엇입니까?

    복잡한 MCP 양식, 인증 문제 및 일부 요청에는 여전히 데스크톱이 필요합니다. Claude는 일반 채팅이 아닌 코드 및 Cowork를 지원합니다. 자동 연결은 macOS / Windows를 지원합니다. 첫 번째 초기화에는 잠금 해제된 데스크톱 및 시스템 권한이 필요할 수 있습니다. Linux는 아직 실험적입니다.

    자세한 지침을 업데이트하거나 찾으려면 어떻게 해야 합니까?

    앱에서 애플리케이션 업데이트를 확인하세요. 이전 업데이트 프로그램이 실패하는 경우 데이터 디렉터리를 유지하면서 새 패키지를 수동으로 설치하세요. README는 네트워킹, 로그인, 알림 및 호환성을 다룹니다.
