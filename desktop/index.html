꺼짐

사이

기본적으로 꺼져 있습니다. 선택한 어댑터의 IP 변경 사항을 따르고 실패한 임시 HTTPS 연결을 복구합니다. 변경 사항은 즉시 저장됩니다. 다시 시작할 필요가 없습니다.

온라인 가이드

자동 모드는 물리적 어댑터에 개인 LAN 주소를 게시합니다. 액세스를 제한하려면 어댑터를 선택하세요. IP 변경 사항을 따르려면 네트워크 복구를 활성화하세요.

온라인 가이드

끄면 로컬 URL이 숨겨지고 로컬 브라우저 액세스가 차단됩니다. 데스크탑 상태 확인 및 HTTPS 터널은 내부 루프백 연결을 유지합니다.

추가 연결

LAN, 임시 Cloudflare 및 여러 고정 항목을 함께 실행할 수 있습니다. 모든 항목은 동일한 컴퓨터 게이트웨이에 도달하고 동일한 로그인을 사용합니다.

게이트웨이가 실행 중입니다. 연결을 추가하거나 변경하기 전에 개요에서 중지한 다음 저장하고 다시 시작하세요.

온라인 가이드
추가 HTTPS 주소(고급)

게이트웨이의 주소 허용 목록입니다. HTTPS 역방향 프록시 또는 터널이 https://codex.try2love.com.와 같이 다른 곳에 이미 구성되어 있는 추가 도메인에만 사용하십시오. URL를 추가해도 터널이 생성되지 않고, DNS를 구성하거나 인증서가 요청되지 않습니다. 프록시는 도메인의 호스트 헤더를 보존해야 합니다. 연결 카드의 고정 도메인은 자동으로 추가됩니다. LAN 또는 임시 Cloudflare 액세스만 사용하려면 이 항목을 비워 두세요.

로그인 인증

일반 웹 로그인은 기본 12시간이며, 0을 입력하면 웹 로그인 만료를 사용하지 않습니다. 로그인 상태를 유지하면 사용할 때마다 갱신되며 7일간 접속하지 않으면 만료됩니다. 모바일 앱 로그인과 페어링은 로그아웃하거나 해당 기기의 인증을 철회할 때까지 유지됩니다. 계정이나 로그인 방식을 바꾸면 모든 로그인이 철회됩니다. 비밀번호 변경 시 이미 연결된 휴대폰의 인증은 유지할 수 있습니다.

장기간 활동이 없으면 브라우저는 로그인 쿠키를 제거할 수 있습니다. 자동 만료가 없다는 것은 게이트웨이가 만료 기한을 설정하지 않음을 의미합니다.

로그인 변경 사항은 다음에 게이트웨이가 시작될 때 적용됩니다.

로그인 보안 알림

기본적으로 활성화되어 있습니다. 활성화된 알림 채널을 사용합니다. 알림을 꺼도 자동 차단이 비활성화되지는 않습니다. 데스크톱 앱의 로그인 장치에서만 IP 차단을 해제하세요.

게이트웨이 시작 및 진입 알림

비밀번호나 로그인 토큰 없이 활성화된 PushPlus, Bark 및 ntfy 채널을 통해 액세스 링크를 보냅니다. 채팅 알림과 무관합니다.

휴대폰 알림을 테스트하기 전에 설정을 저장하고 게이트웨이를 시작하세요. 알림에는 활성화된 LAN 주소, 고정 도메인, 준비된 임시 접속 주소가 포함됩니다. LAN 링크는 같은 네트워크에서 사용할 수 있습니다.

최초 설정 및 테스트

  1. 전화 알림 서비스를 선택하세요

    iPhone에서는 Bark를 사용하고 Android에서는 ntfy를 사용하세요. 시스템 및 잠금 화면 알림을 허용합니다. 두 채널을 함께 활성화할 수 있습니다.

  2. 알림 대상을 입력하세요

    Bark: 전화 앱 홈 화면의 푸시 URL에서 서버 URL 및 장치 키를 입력합니다. ntfy: 임의의 주제를 생성하고 휴대폰에서 동일한 서버 및 주제를 구독합니다.

  3. 저장한 후 테스트 알림 보내기

    필요한 채널을 활성화하고 설정을 저장한 다음 각 채널을 테스트하세요. 휴대폰으로 영수증을 확인하세요. 서버 승인은 배송을 확인하지 않습니다.

  4. 채팅 알림 활성화

    게이트웨이를 시작하고 전화 페이지를 새로 고치고 채팅을 엽니다. 알림을 열고 채팅 알림을 활성화한 후 저장하세요. 그런 다음 Codex에게 선택 사항을 제시하도록 요청하세요. 휴대폰을 잠그고 알림을 확인하세요.

채팅 알림 테스트용 프롬프트

질문 도구를 사용하여 ”계속 테스트” 또는 ”테스트 완료”를 선택한 다음 답변을 기다립니다. 명령을 실행하거나 파일을 변경하지 마십시오.

테스트 알림은 전화 배송만 확인합니다. 채팅 알림에는 컴퓨터, 게이트웨이, 원본 Codex 앱 및 온라인 상태를 유지하는 데 필요한 SSH 연결도 필요합니다.

알림이 없거나 채팅이 열리지 않습니까?
  • Bark 서버 및 장치 키를 확인하거나 ntfy 서버, 주제 및 토큰을 확인하세요. 자체 호스팅 Bark의 경우 해당 서버에 전화기를 등록하십시오.
  • 서버가 알림을 수락했지만 전화기가 무음 상태인 경우 알림 권한, 집중 모드 및 연결을 확인하세요. Android는 또한 ntfy가 백그라운드에서 실행되도록 허용해야 합니다.
  • 알림을 눌러도 채팅이 열리지 않으면 게이트웨이가 실행 중인지 확인하세요. LAN 링크는 같은 네트워크에서 사용할 수 있으며, 외부 접속에는 휴대폰에서 접근할 수 있는 HTTPS 주소가 필요합니다.

Bark 알림 · iPhone

https://api.day.app/YOUR_KEY,와 같은 푸시 URL의 경우 https://api.day.app를 서버로 사용하고 YOUR_KEY를 장치 키로 사용합니다. 공식 및 자체 호스팅 서버가 지원됩니다. 키를 비공개로 유지하세요.

PushPlus

WeChat으로 PushPlus에 로그인하고 해당 서비스 계정을 팔로우한 후 실명 확인을 완료하고 프로필에서 토큰을 복사하세요. 활성화하고 저장한 후 테스트 알림을 보낸 다음 팔로우하려는 채팅에 대한 알림을 켜세요.

PushPlus에는 CNY 3.90부터 유료 실명 확인이 필요합니다. 인증된 사용자는 회원가입 없이도 기본수당을 사용할 수 있습니다. 현재 가격은 공식 페이지를 확인하세요.

일반 검증된 사용자의 경우 WeChat 채널은 하루에 200개, 분당 5개의 요청을 허용하며 시간당 최대 3개의 동일한 메시지를 허용합니다. 실패한 요청도 포함됩니다. 한도를 초과하면 배송이 중단될 수 있습니다.

수동으로 입력한 클릭 URL가 우선순위를 갖습니다. 게이트웨이 주소를 자동으로 선택하려면 비워 두세요. LAN 링크에는 동일한 네트워크가 필요합니다. 오래된 임시 링크는 만료될 수 있습니다.

시작 및 데이터 디렉터리

컴퓨터에 로그인할 때 게이트웨이를 자동으로 시작합니다.

이 디렉터리에는 게이트웨이 설정, 알림 토큰, 로그인 자격 증명 및 로그가 저장됩니다.

Cloudflare 구성요소

데스크탑 앱에는 임시 및 고정 터널용 cloudflared가 포함되어 있습니다. 네트워크 아래에 연결을 추가하고 로그인하세요.

고급: 맞춤형 프로그램 및 수리

Cloudflare의 공식 GitHub에서 매칭 프로그램을 다운로드하고 SHA-256을 확인한 후 게이트웨이 데이터 디렉터리에 설치합니다. 관리자 권한이나 시스템 PATH 변경이 없습니다. 다운로드하는 데 몇 분 정도 걸릴 수 있습니다. 제한 시간은 3분입니다.

다운로드 또는 연결에 실패했나요?

GitHub에 연결할 수 없는 경우 네트워크 또는 시스템 프록시를 확인하고 다시 시도하세요. 또는 공식 가이드를 사용하여 일치하는 빌드를 다운로드하세요. Mac에서는 압축을 풀고 cloudflared를 선택합니다. Windows에서 cloudflared.exe를 선택합니다. 프로그램을 확인하고 저장하세요.

프로그램이 준비되었지만 터널에 장애가 발생한 경우 런타임 로그에서 Cloudflare 섹션을 확인하세요. 네트워크는 아웃바운드 TCP 7844를 허용해야 합니다. 게이트웨이가 시작되면 LAN 액세스는 독립적으로 작동합니다.

고급 경로(일반적으로 변경이 필요하지 않음)

Codex 실행 파일과 IPC 주소는 자동으로 검색됩니다. 사용자 정의 환경에 대해서만 또는 검색이 실패한 경우에만 이를 변경하십시오.

네트워크 설정이나 프로그램 경로를 변경하기 전에 게이트웨이를 중지하십시오. 모델, 제공자 및 기술은 원래 Codex 채팅을 따릅니다.

로그인된 기기

각 항목은 브라우저 로그인입니다. 취소하려면 다시 인증이 필요합니다. IP를 차단하면 새 로그인을 포함하여 해당 IP를 사용하는 모든 장치가 거부됩니다.

자동으로 차단된 IP

다시 시작한 후를 포함하여 5번 연속 비밀번호 오류가 발생하면 IP가 영구적으로 차단됩니다. 차단을 해제하면 5번의 시도가 복원됩니다. 허용 목록은 자동 차단을 우회하지 않습니다.

웹 페이지는 네트워크 MAC 주소를 읽을 수 없습니다. 전화기는 개인 MAC 주소를 사용할 수 있으며 IP는 네트워크에 따라 변경될 수 있습니다. 공용 IP를 공유하는 장치는 동일한 IP 규칙의 영향을 받습니다.

IP 액세스 규칙

차단 목록이 우선순위를 갖습니다. 저장하면 규칙이 즉시 적용되고 제외된 로그인이 취소됩니다. 데스크탑 관리는 계속 사용 가능하므로 여기에서 제한 사항을 제거할 수 있습니다.

프록시 IP 설정(고급)

NAS 또는 기타 HTTPS 역방향 프록시의 경우 게이트웨이에 직접 연결되는 IP를 입력합니다. 프록시는 X-Forwarded-For를 덮어쓰거나 추가해야 합니다. 로컬 HTTPS 터널은 자동으로 신뢰됩니다. 전달하지 않으면 목록에 프록시 IP가 표시됩니다. 이를 차단하면 해당 프록시를 사용하는 모든 장치에 영향을 미칩니다.
