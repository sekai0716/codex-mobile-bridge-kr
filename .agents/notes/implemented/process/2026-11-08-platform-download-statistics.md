# Agent Note: 플랫폼별 공개 설치된 자산 다운로드 통계

Status: implemented

## 문제

GitHub 총 다운로드 배지에는 업데이트 메타데이터와 확인 파일이 포함되어 있으며 설치된 자산의 다운로드를 나타내지는 않습니다. 플랫폼 자산 이름은 버전에 따라 변경됩니다.，Shields 의 GitHub 다운로드 인터페이스는 전체 파일 이름으로 일치하며 와일드카드는 기록 버전을 요약하는 데 사용할 수 없습니다.。

## 결정

`scripts/build-download-stats.py` 페이징 읽기 공개 Release，미리보기를 포함하고 초안을 제외하며 플랫폼 태그 및 허용된 파일 접미사를 기준으로 자산 다운로드를 집계합니다.。Android 통계 APK；iOS 통계 특수 소스 코드 ZIP 및 IPA；Linux 통계 DEB 및 AppImage；macOS 통계 DMG 업데이트로 ZIP；Windows 통계 EXE 및 ZIP。고쳐 쓰다 JSON、YAML、서명, 확인 파일 및 blockmap 개수를 입력하지 않습니다. 자산별 ID 중복 제거, 통계 없음 GitHub 자동 생성된 창고 소스 코드 아카이브。

기존의 Pages 워크플로는 릴리스 후 또는 수동으로 실행할 때 매일 5개의 복사본을 생성합니다. Shields endpoint JSON 그리고 요약. 배포만 `main` 제품 웹사이트, 소스 코드를 다시 작성하지 않음, 통계 스냅샷을 제출하지 않음, 빌드하지 않음 App。요청이 실패하면 이 배포가 실패하게 됩니다. 잘못된 0 값 게시를 방지하기 위해 이전의 전체 웹사이트와 개수가 유지됩니다. 생성된 데이터에는 플랫폼 수, 통계 구경 및 시간만 포함되며 내보낼 수 없습니다. Release 텍스트, 진단, 계정 또는 현지 승인 데이터。

## 기존 기록 확인

누르면“다운로드 통계, 다운로드 시간、download stats”동일한 회계 메커니즘 없이 활성 메모, 문서 및 작업 흐름을 검색합니다.。App 다운로드 및 업데이트 프로그램은 배포 및 서명 확인을 처리하며 이 프로세스에 의해 수정되지 않습니다.。

## 대안

GitHub 전체 다운로드 배지에는 유지 관리가 필요하지 않지만, 빈번한 업데이트는 설치 횟수에 포함됩니다. 특정 파일 이름으로 배지를 추가하는 것은 쉽지만 릴리스마다 수정해야 하며 기록 자산을 집계할 수 없습니다. 서비스를 별도로 배포하거나 새 쓰기 통계 분기를 추가하여 개수를 업데이트하지만 기존 Pages 정적 제공 가능 JSON，따라서 신규 서비스나 소스코드 작성 권한은 없습니다.。

## 영향

README 5개 플랫폼의 누적 자산 다운로드 수를 표시하여 반복 다운로드 및 자동 업데이트 다운로드를 허용합니다. 이는 개별 사용자 수나 성공적인 설치 수를 나타내지 않습니다. 삭제 Release 자산은 누적 가치를 감소시킬 수 있습니다. 새로 고침에는 일일 예약 및 배지 캐시 지연이 있습니다. 가득한 API 쿼리 및 Pages 배포가 소폭 증가 Actions 복용량. 배지는 첫 번째 통합 및 배포 후에만 사용할 수 있습니다. 지역세대는 온라인이라고 할 수 없다.。

## 검증

표적 테스트에는 플랫폼 분류 및 메타데이터 제외가 포함됩니다.、iOS 소스코드와 IPA 합계, 초안 및 반복 ID、페이지 매기기 항목, 잘못된 계산 실패 및 텍스트가 없는 출력 필드입니다. 진실하고 개방적이다 Release 일치 범위를 확인하는 데에만 사용되는 매니페스트입니다. 배포되지 않음 Pages 또는 푸시 코드。
