# Agent Note: 일반적으로 활성화됨 ZCode 이 컴퓨터에 저장된 텍스트를 읽을 수 있습니다.

Status: implemented

## 문제

ZCode 데스크탑 창 및 작업 공간 host 진행 중인 과정을 통해 이전됨 MessagePort 의사소통。[원기](2026-10-31-zcode-native-session-prototype.md)로컬 디버깅 포트를 통해 원본 데이터 얻기 owner。일반 스타트업에서는 이 입구를 열지 않습니다.。ZCode 공식 원격 제어는 외부 릴레이를 사용하며 사용자는 로컬 게이트웨이를 통해서만 세션 데이터를 통과해야 합니다.。

## 결정

동일한 기본 구성 작업 인덱스에서 기본 액세스를 활성화했으며 CLI 읽은 텍스트를 녹음하세요. 인덱싱 작업은 로컬이어야 합니다. GLM 작업, 원래 세션 ID 작업 디렉터리와 일치해야 합니다. 그리고 VS Code 네이티브 owner 공유 디렉터리 비교 확인, 로컬 Windows 파일 시스템 ID를 사용하여 동일한 디렉터리의 다양한 쓰기 방법을 확인할 수 있습니다.。SQLite 읽기 전용을 사용하여 연결 URI，함께 WAL 현재 제출된 데이터를 읽습니다. 탈퇴 요청을 읽은 후 연결을 닫습니다. 데이터 파일과 사이드 파일은 심볼릭 링크를 통해 다른 구성을 가리킬 수 없습니다.。

인터페이스에 표시되는 기본 주석을 선택하는 사용자 및 도우미 텍스트만 읽습니다. 주자가 모델에게 제공한 숨겨진 지시 사항도 다음과 같이 끝날 수 있습니다. user 역할 저장, 역할만으로도 이러한 유형의 입력이 전화기에 노출됩니다. 이동 단말기는 기존의 과거 페이징을 재사용하고 현재 세션의 기본 메시지 식별자를 커서로 사용합니다. 작업 목록과 기록은 읽기 전용으로 표시됩니다. 내역 상태는 실행 중인지, 승인 대기 중인지, 안전하게 종료할 수 있는지를 증명하지 않습니다.。

## 대안

공식 리모콘을 재사용하면 원본을 작동할 수 있습니다. host，단, 동일한 계정을 페어링하여 외부 릴레이를 통해 전송해야 합니다. 독립적으로 사용 CLI 디스크 레코드를 로드하면 새로운 응답이 생성될 수도 있지만 현재 작업이 원래 창과 공유되고 있음을 증명할 방법은 없습니다. 일반 프로토타입의 명시적인 호환성 액세스를 유지합니다. App 네이티브 히스토리의 각 기능 경계。

## 영향

Mac 일반 네이티브 데이터 디렉터리에서 독립 수락 채팅을 읽고 페이지에서 사용자 메시지와 응답을 얻으며 숨겨진 모델 환경 프롬프트가 반환되지 않습니다. 테스트에는 동일한 이름, 원격 로깅, 삭제된 레코드, 아카이브, 세션 간 커서 및 다른 라이브러리에 대한 링크와의 디렉터리 소유권 충돌이 포함됩니다. 이 포털은 저장된 텍스트, 실시간 메시징, 중지만 제공하며 승인을 위해서는 원래 세션에 대한 확인 가능한 연결이 필요합니다. 이전 프로토타입의 실제 송수신 기록은 당시 검증된 연결 방식에만 적용 가능했습니다.。

데스크톱 프로젝트 트리에 아직 등록된 로컬 세션이 없을 수 있습니다. CLI 채팅 기록 라인. 선택한 경우 ID，세부 정보는 색인 항목과 빈 기록을 표시할 수 있습니다. 해당 레코드가 없으면 고아 메시지 행을 읽을 수 없으며 쓰기 권한이 부여되지 않습니다. 명시적 연속은 여전히 ​​원본에 의해 수행됩니다. App 확인항목、ID 그리고 구독. 해당 레코드가 삭제되거나 디렉터리가 일치하지 않거나 작업이 원격 끝에 속하는 경우 계속 거부합니다.。

각 어시스턴트 답변에 대한 모델/사고 장비는 동일한 세션과 동일한 응답의 모델 통화 기록에서 가져옵니다. 레코드가 누락된 경우 응답 및 명시적으로 연관된 입력 필드만 사용됩니다. Thinking Gear는 다른 모델 간에 이전되지 않습니다. 기본 스냅샷, 저장된 메시지 및 공유 렌더러는 동일한 표시 필드를 사용합니다.。

Windows 오래된 테스트 환경 SQLite 닫는 중 trusted_schema 거절할 때 ZCode 의 JSON 표현 지수. 네이티브인지 확인한 후 dwf_event_artifact_idx 부르다 json_extract 이 특정 오류가 발생하면 연속 항목이 읽기 전용 작업 인덱스로 변경되어 항목을 찾고 원본을 묻습니다. App 프로젝트 트리가 최종 구독과 다시 일치합니다. 이 다운그레이드를 사용하면 오프라인 세부 정보가 기록되지 않으며 데이터베이스 손상이나 기타 스키마 오류는 지속적인 증거로 간주되지 않습니다.。
