# Agent Note: 네이티브 소스를 기반으로 주입 컨텍스트 접기

Status: implemented

## 문제

Harness 사용자 입력과 플러그인 주입 내용을 모두 다음과 같이 기록합니다. `user/message`。이벤트 유형만을 기반으로 한 렌더링은 작업 공간 지침과 같은 컨텍스트를 일반 사용자 음성으로 처리합니다.。

## 결정

DSH 네이티브 기반 어댑터 `message.source.kind` 변환 내용: 명시적 및 비- `user` 생산자 소스는 공유 활동 메시지를 출력합니다.，`kind=context`、맥락에 대한 제목；`user` 또는 소스가 누락된 경우 이전 사용자 메시지를 계속 표시합니다. 본문 텍스트와 안정적인 메시지 식별자는 그대로 유지되며 본문 텍스트의 태그나 키워드를 기반으로 소스 추측이 수행되지 않습니다.。

인터페이스는 기본적으로 접혀 있고 새로 고친 후에도 확장된 상태를 유지하는 기존 활성 접기 구성 요소를 재사용합니다. 다른 Agent 나중에 공급자 분기를 추가하지 않고도 동일한 정규화된 콘텐츠를 출력할 수 있습니다. 이미지 참조도 기본 세션 바인딩을 유지합니다.。

본문 내 새로 고침 및 스크롤 시 노드 업데이트는 다음과 같이 유지됩니다.[공유 채팅 읽기 상태](../bug-fix/2026-10-30-shared-chat-reading-state.md)，공급자 페이지 내에 별도의 복구 규칙 세트를 작성하지 마십시오.。

## 대안

～에 따르면 context 태그 접기를 사용하면 이전 로그에 더 쉽게 적응할 수 있지만 사용자가 직접 입력한 텍스트를 잘못 접을 수 있으므로 기본 소스 필드만 신뢰할 수 있습니다. 또 다른 구축 DSH 특수 폴딩 UI 외관은 커스터마이징이 가능하지만, 기존 프로세스 디스플레이와 중복되어 사용되지 않습니다.。

## 시험

구문 분석 테스트에서는 사용자 소스, 누락된 소스, 작업 공간 지침 및 알 수 없는 플러그인 소스를 다루며 텍스트가 변경되지 않은 상태로 유지되는지 확인합니다. 인터페이스 테스트에는 확장을 유지하기 위한 기본 접기 및 새로 고침이 포함됩니다. 관련 사진/컨텍스트 파싱 5 아이템과 데스크탑 UI 166 항목이 통과됨。

## 영향

원본 텍스트를 삭제하거나 모델 입력 또는 일반 사용자 메시지에 영향을 주지 않고 식별된 주입 컨텍스트의 표시 형식만 변경합니다. 기본 소스가 누락된 이전 로그는 그대로 유지됩니다. 컨텍스트를 검색하고 레코드를 축소한 후 두 가지 모두 Claude 상황별 사용 기록은 계량 의미 체계에 속하며 중복되지 않습니다. 이는 역사적 결정을 대체하지 않습니다.。
