# 언어팩과 채팅 상태 표시

- 웹의 원문 중문·영문 메시지와 한국어 교정 결과를 같은 키의 세 언어팩으로 분리한다. 기존 한국어 호출 키는 별도 대응표로 유지한다. PC·모바일의 언어 선택은 `en`, `ko`, `zh`를 사용하며 저장된 값을 해석할 때 지역 코드를 허용한다.
- 네이티브 Android·iOS 문구는 공용 JSON에서 Java·Swift 데이터로 생성한다. 번역 엔진은 등록된 UI 메시지만 조회하며 사용자 데이터의 일괄 치환을 하지 않는다.
- 추론 요약은 활성 turn의 `summary`에서 마지막 유효 줄만 조회한다. 빈 요약이 오면 같은 turn의 기존 줄을 유지하고, 채팅·turn 변경이나 실행 종료 시 해제한다. 추론 `content`를 요약의 대체 자료로 쓰지 않는다. 상태줄은 한 줄 말줄임으로 표시하며 별도 추론 항목과 자동 펼치기 설정을 없앤다.
- 컨텍스트 압축의 수동·자동 종류와 진행·완료·실패·중지 상태를 구분하여 번역한다.
- 계정 한도는 기존 읽기 전용 계정 API와 5분 캐시를 사용한다. 계정·호스트 식별자와 요청 세대를 검사하여 이전 응답을 버린다. 확인된 기간만 표시하며 5시간 한도가 없는 계정은 주간만 표시한다. 0%는 유효한 값이며, 값이 없는 한도를 0%로 대체하지 않는다. 상세창은 초기화 시각 조회와 수동 새로고침만 제공한다.
- 검증: 언어별 동일 키·기존 선택값, JVM 언어 테이블, 활성 turn 요약 경계, 계정 응답 경합·캐시·주간 단독 한도, 브라우저의 좁은 화면·한 줄 요약·압축 상태·기존 전송 기능을 검사한다. iOS는 Linux에서 생성물과 Sources 등록만 검사하며 Xcode 빌드·실기기 검증과 구분한다.
