## 대안

각 클라이언트의 독립적인 메뉴를 유지하면 액세스 변경을 줄일 수 있지만 복사 피드백, 아카이브 확인 및 입장은 계속해서 포크되므로 실제 용량 제약에 맞게 공유 메뉴가 사용됩니다. 직접 채택 PR 수직 위험 확인 버튼 및 삭제 알림 입구가 확인된 행위에 따르지 않아 기존 계약이 유지됩니다.。

예상되는 분류 비교에만 의존하면 명시적인 충돌을 차단할 수 있지만, 오래된 스냅샷은 시간 초과 후에도 여전히 두 번째 쓰기를 트리거할 수 있으므로 지속성 수신이 추가됩니다. 보관 영수증 클래스를 직접 재사용하려면 분류를 부울 보관 상태로 위장해야 하며 이는 올바른 확인에 도움이 되지 않으므로 독립적인 분류 영수증 구현이 유지됩니다. 기존 개인 원자 파일 쓰기 기능을 재사용。
