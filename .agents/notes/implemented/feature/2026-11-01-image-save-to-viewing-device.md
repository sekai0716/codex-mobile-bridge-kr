# Agent Note: 현재 보고 있는 장치에 이미지 저장

Status: implemented

## 문제

공유 사진 뷰어는 대화를 미리 보고 추가할 수만 있으며 휴대폰 사용자는 휴대폰에 사진을 저장할 수 없습니다. 저장대상은 현재 시청 중인 기기이며, 게이트웨이 호스트는 사용자 기기로 간주할 수 없습니다. 버튼을 추가한 후 좁은 화면 도구 모음도 전체 버튼 텍스트를 수용해야 합니다.。

## 결정

이미지 뷰어는 저장 및 재사용을 위한 로컬 항목을 제공합니다. Web、iOS、Android 기존 파일 다운로드 및 시스템 저장 프로세스입니다. 작업 공간 사진은 재사용 및 다운로드됩니다. URL；채팅 사진은 세션 ID로 확인된 원본 사진 인터페이스에서 다운로드됩니다. 원본 파일명은 그대로 유지되며 썸네일이나 스크린샷은 원본 사진으로 사용되지 않습니다. 기본 다운로드는 확인된 이미지 경로와 명시적 다운로드 매개변수만 추가하며 어떠한 것도 허용하지 않습니다. URL、교차 사이트 주소 또는 data URL。

뷰어와 도구 모음은 구현을 공유합니다. 항상 상단에 한 줄로 정렬“닫기, 파일 이름, 참조”，긴 파일 이름은 생략됩니다. 저장 항목은 하단에 배치된 액세스 가능한 이름의 다운로드 아이콘을 사용합니다.“화면에 적응”오른쪽 마지막 위치입니다. 휴대폰은 여전히 ​​시스템 파일 위치에 저장되어 있으며 이번에는 앨범 권한이 추가되지 않았습니다. 다운로드는 프리패치나 폴링 없이 사용자 클릭에 의해서만 시작됩니다.。

## 감사 관련 결정

[원주민 역사 사진](../../implemented/feature/2026-10-29-shared-native-history-images.md)이 제안과 부분적으로 중복됩니다. 세션 바인딩 및 소스 파일 재검증을 계속 사용하고 승인된 이미지의 다운로드 사용을 늘립니다. 수동 읽기가 세션을 활성화할 수 없다는 제한은 변경되지 않습니다. 기존 다운로드 및 이미지 미리보기 테스트는 해당 경계를 수용하기 위한 기초로 계속 사용됩니다.。

## 대안

미리보기를 브라우저로 변환 Blob 다운로드 방법은 매우 간단하지만 휴대폰의 기존 다운로드 관리를 우회하게 되며, 썸네일을 저장하거나 원본 파일명이 손실될 수도 있으므로 인증된 원본 파일을 사용합니다. URL。앨범을 직접 저장하면 사진을 더 쉽게 찾을 수 있지만 새로운 플랫폼 권한 및 포크 프로세스가 도입됩니다. 이번에는 기존 시스템 파일 저장 입구를 사용합니다.。

## 검증

공유 다운로드 확인 18 항목, 데스크탑 사진 HTTP 조사하다 8 개、Codex 업로드 및 활동 확인 25 항목이 통과되었습니다. 원시 바이트 범위, 첨부 파일 이름, 세션 격리 및 교차 출처, 중복 매개변수, 릴레이 범위 거부。Android Java 및 iOS Swift 프로덕션 다운로더가 컴파일되고 원본 전송 픽스처가 전달되며 이미지 항목 경계가 추가됩니다. 브라우저 구성 요소는 320、390、844、1280 각 픽셀이 통과합니다. 31 동시에 표시되는 두 개의 작업 버튼을 포함한 항목，390 픽셀 스크린샷이 확인되었습니다. 그림 설비에는 실제 그림 내용이 포함되어 있지 않으며 스크린샷은 도구 모음 레이아웃만 증명합니다. 결정적인 Mac Test zcode11 의 HTTPS 페이지가 실제로 독립적으로 업로드되었습니다. 68 바이트 PNG，프로덕션 이미지 뷰어와 공유 다운로더에 의해 저장되면 바이트 단위로 일관성이 유지되며 원본 파일 이름이 유지됩니다.。iOS 및 Android Test build 42 서명이 다시 컴파일되었습니다.；Android 서명 및 기존 Test 일관된. 사용자가 아직 연결되지 않았습니다. iPhone，휴대폰 커버리지 설치 및 시스템 파일 저장이 아직 승인되지 않았으며 브라우저 결과로 대체할 필요가 없습니다.。

## 영향

툴바는 중국어, 영어 및 320、390、844、1280 각 픽셀이 통과합니다. 47 검사 및 검증 390 픽셀 스크린샷; 상단에는 줄 바꿈이 없고 하단의 아이콘이 표시되며 넘치지 않습니다. 저장 링크, 파일 이름, 기본 다운로더는 변경되지 않으며 기존에 통과한 전송 테스트는 반복되지 않습니다.。

기본 이미지를 다운로드하려면 휴대폰 케이스가 새 경로를 인식해야 합니다. 오래된 전화 케이스는 지원되는 것으로 간주될 수 없습니다. 이미지 인터페이스가 분할된 응답을 제공하지 않는 경우 중단점 재개를 잘못 보고하지 않으며 기존 중단이 유지되고 프롬프트가 재발행됩니다.。
