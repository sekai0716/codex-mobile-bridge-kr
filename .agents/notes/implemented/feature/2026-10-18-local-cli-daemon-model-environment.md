# Agent Note: 현지의 CLI 모델 디렉토리는 기본 데몬 환경을 사용합니다.

Status: implemented

## 문제

휴대폰 게이트웨이는 다른 단말기에 의해 시작될 수 있으며 환경 변수가 다를 수 있습니다. Codex CLI 악마. 쿼리할 게이트웨이 환경을 읽어보세요. API 모델 디렉터리입니다. 잘못된 엔드포인트나 자격 증명이 선택되었을 수 있습니다. 환경을 사용할 수 없는 것으로 처리하면 일반 환경 변수 기반이 발생합니다. CLI 모델을 수동으로 입력해야 하는 계정인 것 같습니다. ID。

## 결정

로컬 모델 디렉터리는 유효한 네이티브만 구문 분석합니다. provider 구성에 사용되는 변수 이름입니다. 플랫폼 리더는 동일한 사용자를 확인합니다. PID 기록, 프로세스 생성, 실행 파일 및 기본 홈 디렉터리를 기록한 다음 프로세스에서 선택한 시작 변수를 읽습니다. 원래 값은 모델 카탈로그 요청에만 사용됩니다. 영구 모델 ID에는 기존 구성 및 계정 ID 외에도 이러한 값 및 프로세스 생성에 대한 요약이 포함됩니다. 원래 자격 증명은 저장되거나 반환되지 않습니다. 인증 실패로 인해 실행 가능한 디렉터리 오류가 발생하고, 이전에 인증된 환경의 디렉터리는 재사용할 수 없습니다.。

모델 가용성은 업스트림에 따라 결정됩니다. API 모델 목록이 결정됩니다. 토종의 `model/list` 모델에 한해 업스트림 목록을 성공적으로 검색한 후 수행되는 선택적 2초 메타데이터 쿼리입니다. ID 일치하는 용어는 추론 능력을 보완합니다. 구성된 기본 디렉터리는 데몬 모델 목록을 계속 사용합니다.。

## 대안

게이트웨이 환경으로 새롭게 시작하세요 CLI 명령은 더 간단하지만 데몬이 실행되는 환경을 이해할 방법이 없습니다.。`command/exec` 환경 변수를 필터링하고 수동 모델에 대한 실행도 읽을 수 있습니다. shell 작동하다. 게이트웨이에서 관리하는 환경 스냅샷은 일반 터미널에서 시작된 데몬을 포함할 수 없습니다. 전체 프로세스 컨텍스트를 반환하면 관련 없는 값이 노출되므로 리더는 요청된 변수 이름만 선택합니다.。

## 영향

macOS 제한된 사용 `KERN_PROCARGS2` 읽다，Linux 제한된 사용 `/proc/PID/environ` 읽다，Windows x64 과정을 통해 API 제한된 읽기 UTF-16 조각. 생성 확인은 네이티브를 사용합니다. PID 메타데이터. 운영 체제가 읽기를 거부하는 경우，UI 데몬 시작 환경을 확인할 수 없음을 보고합니다. 인증서 및 구성된 디렉터리 경로를 저장하는 데 필요한 불필요한 환경 변수가 없습니다. 합성 동일 사용자 하위 프로세스 테스트 적용 범위 값 격리 및 만료된 신원 거부；Windows x64 이미 격리 중 Windows 10 자식 프로세스 확인。
