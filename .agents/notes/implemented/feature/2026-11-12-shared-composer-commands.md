# Agent Note: 공유 입력 상자 슬래시 작업 메뉴

Status: implemented

## 문제

#154 입사를 희망합니다 `/` 그런 다음 채팅 명령을 선택하십시오. 원본 입력 상자는 이러한 유형의 텍스트를 일반 전송 프로세스에 전달하며 기존 모델 및 권한을 직접 입력할 수 없습니다.、Skill 채팅 관리 인터페이스. 설치됨 Codex App 이러한 항목을 프런트엔드 작업으로 등록하세요. 토종의 TUI 독립도 있고 slash dispatcher，모두가 그렇다고 가정할 수는 없다. `/xxx` 모두 모델이거나 app-server 규약。

## 결정

공유됨 `ComposerCommands` 기존 기능에 대한 입력 포털만 제공합니다. 주인 Codex 및 `DesktopSessionsView` 동일한 컴포넌트를 사용하면 기본 사이드 채팅을 동일한 컨트롤러로 전송한 후 자연스럽게 재사용할 수 있습니다. 모델, 사고 강도, 권위、Skill、컨텍스트 및 모드는 현재 컨트롤의 기능 및 비활성화 상태를 직접 사용합니다. 이름 바꾸기, 보관, 삭제 등 원래 세션 메뉴 페이지를 엽니다. 여전히 기존 컨텍스트 팝업 창에서 압축을 확인해야 하며, 새로운 압축은 직접 제출되지 않습니다. RPC。

`/plan`、`/goal`、`/default` 작업 모드를 선택하면 동반 텍스트가 입력 상자에 남아 있으며 명시적으로 전송해야 합니다. 알려져 있지만 사용할 수 없는 명령어는 일반 전송에 속할 수 없습니다. 알 수 없는 맞춤 명령어 및 `/Users/...` 경로가 원래 처리를 계속할 때까지 기다리십시오. 메뉴는 중국어 검색 및 화살표 키를 지원합니다.、Enter、Tab 및 Esc；입력 방법 확인은 명령을 실행하지 않습니다. 클릭 시 현재 세션, 입장, 계정, 능력치가 재검증됩니다. 기존 메뉴에서는 새 채팅을 실행할 수 없습니다. 입력 상자의 명령 조각만 사용하고 첨부 파일, 참조 또는 기록 지우기 작업을 호출하지 마세요.。

이 배치는 모든 기본 명령을 재현한다고 주장하지 않습니다.。MCP、네이티브 공유, 메모리, 데스크탑 컴패니언, 리뷰, 초기화 등 기존 기능과 연결되지 않은 항목은 메뉴에 추가되지 않습니다. 동적 Skill 기존을 통해 `/skills` 선택기를 사용하고 원래 디렉터리와 캐시를 유지하세요.。

## 대안

슬래시 텍스트를 모델에 직접 보내면 로컬 작업을 안정적으로 수행할 수 없으며 실수로 관리 지침을 보낼 수도 있습니다. 모델, 권한 및 세션 관리 페이지 세트를 복제하면 유효성 검사 규칙 및 캐싱이 포크되므로 기존 컨트롤 및 메뉴를 사용하십시오.。

## 영향

공유 프런트엔드, 컨트롤러 후크 2개, 세션 메뉴 초기 페이지 매개변수 및 리소스 조합만 변경되며 백엔드 또는 클라이언트 프로토콜은 추가되지 않습니다. 중국어 메뉴는 중국어 간체로 통일되어 있습니다. 명령 이름은 입력 가능한 영어 로고를 유지합니다.。

여섯 개의 새로운 Node 확인하고 20개의 세션 메뉴 회귀를 통과했습니다. 공전 URL 리소스 매핑 확인이 통과되었습니다. 현실 Chromium 프로덕션 중간 리소스가 성공적으로 시작되고 두 컨트롤러 모두 실제로 구성 요소에 바인딩되며 입력 방법, 키보드, 초안, 기능 오류, 세션 간 늦은 클릭 및 경로 보존 검사가 통과됩니다. 전체 규모 관련 이전 인터페이스 검사에는 여전히 14개의 오류가 있습니다. 11개의 이전 파일 고정 장치에는 새 호스트 경로 계약이 부족하고 3개의 이전 전송 고정 장치에는 선언된 기능이 없습니다. 추가 검증 및 수정은 전체 그룹을 통과할 수 없습니다. 최종 설치 패키지와 휴대폰은 아직 후속 승인을 기다리고 있습니다.。

기본 구현 비교: 설치됨 App `26.1106.51428` 의 slash 동작을 등록하고,[공식적인 TUI slash dispatcher](https://github.com/openai/codex/blob/main/codex-rs/tui/src/chatwidget/slash_dispatch.rs)。공식적으로 운영되지 않음 App 아니면 모델을 불러주세요。
