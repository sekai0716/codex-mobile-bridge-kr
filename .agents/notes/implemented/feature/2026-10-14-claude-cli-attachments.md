# Agent Note: 현지의 Claude Code CLI 충수

Status: implemented

## 문제

공유 입력 상자 및 개인 업로드 원장이 지원됩니다. Claude Desktop 사진을 업로드했지만 Claude Code CLI 채팅에는 아직 첨부파일을 첨부하는 기능이 없으며 업로드된 파일을 첨부할 수 없습니다. CLI 메시지 보내기。

## 결정

기존의 인증된 채팅 범위 업로드 원장을 유지합니다.。HTTP 전송 경로는 선택한 세션을 읽은 다음 업로드를 구문 분석합니다. ID。현지인으로 명시적으로 식별된 사람만 Claude CLI 세션은 이미지가 아닌 파일 경로를 받을 수 있습니다.；Desktop、DeepSeek 그리고 미래의 원격 CLI 세션은 원격 전송이 구현될 때까지 기존 이미지 전용 경계를 유지합니다. 클라이언트는 구문 분석된 바이트 또는 로컬 경로를 직접 제출할 수 없습니다.。

Bridge 현지에서 개최 CLI 네이티브를 통해 stream-json 이미지 콘텐츠 블록은 이미지를 수신합니다. 명시적으로 복원하는 경우，`--add-dir` 원주민에게만 부여됨 Read 이 도구에는 채팅의 비공개 업로드 디렉터리에 액세스할 수 있는 권한이 있습니다. 선택한 세션은 그대로 유지됩니다. cwd 그리고 구성. 이미지가 아닌 파일에 대한 메시지에는 원장에 의해 확인되고 필요한 절대 경로가 포함되어 있습니다. Claude 읽다. 텍스트 없이 첨부 메시지 허용。UUID 영수증 원장은 알 수 없는 결과가 있는 쓰기의 재생을 계속 방지합니다. 저장 기록은 기존 레코드 리더를 계속 사용하여 기본 이미지 블록을 이미지 마커로, 파일 참조를 텍스트로 렌더링합니다.。

## 대안

기존 기록 문서 재사용 업로드 원장, 기본 이미지 블록 및 제한된 디렉터리 Read 디렉토리 액세스가 허용되지 않을 때 읽기 거부에 대한 구현 및 실제 측정 독립적인 첨부 파일 전송 방식의 비교는 문서화되어 있지 않습니다. 이 기록 공백은 여기에 보존되며, 실현되지 않은 원격 전송은 당시 거부된 솔루션으로 기록되지 않습니다.。

## 영향

현지의 CLI 텍스트 첨부가 없는 메시지를 포함하여 사진 및 파일 인용문을 보낼 수 있습니다. 능력은 네이티브에 따라 다름 Read 채팅의 비공개 업로드 디렉터리에 대한 승인 다른 클라이언트나 원격 세션에 대한 파일 경로 권한을 확장하지 않습니다. 기록에는 이미지 태그와 파일 텍스트 참조가 계속 표시되며, 알 수 없는 결과가 포함된 쓰기는 영수증 원장에 의해 보호됩니다. 다음 기본 검증은 로컬에만 적용됩니다. macOS，다른 시스템과 SSH 전송은 이 증거를 상속받을 수 없습니다.。

## 인증 및 제한사항

Claude Code 2.1.287 격리 루프백 시뮬레이션 서비스를 도킹할 때 해당 모델 요청은 정확히 동일한 유효 PNG 바이트. 아니요 `--add-dir` 시간，Read 도구 거부 cwd 업로드 경로가 지정된 디렉터리 외부에 있습니다. 제한된 디렉터리를 추가한 후 업로드된 테스트 파일의 바이트가 반환됩니다. 사용자 프로비저닝, 채팅 또는 유료 모델 엔드포인트가 사용되지 않음。Python 계약과 HTTP 테스트 업로드 및 첨부 파일 공유 UI 모든 테스트가 통과되었습니다. 기본 검사는 로컬을 확인합니다. macOS 행동；SSH 파일 전송 및 기타 운영 체제는 여전히 별도로 처리해야 합니다.。
