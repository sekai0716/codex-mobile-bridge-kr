인터페이스에서는 타사 예측이 개인 할당량을 나타내지 않으며 알림에서 재설정 문이 타사 소스에 귀속된다고 설명합니다. 카드 알림은 기본적으로 꺼져 있으며, 계정 알림을 위한 타사 채널이 사용됩니다. 휴대폰 알림이 추가되지 않거나 실제 알림이 자동으로 활성화됩니다. 알림 기능을 켜면 현재 시간을 기준으로 이전 이벤트가 재발행되지 않습니다. 원래 계정 할당량 쿼리와 표시는 여전히 독립적으로 실행됩니다. 벨 옆에 표시“알림 켜짐/알림 꺼짐”，구성 상태를 나타내며, 채널이 구성되지 않은 경우 전달이 보장되지 않습니다. 미리 알림 목록은 확인란에서 상속한 입력 상자 여백과 패딩만 지워서 텍스트의 세로 중앙에 배치됩니다.。

## 대안

실제 테스트 직전에 직접 통합 main 분기 전환을 줄일 수 있지만 사용자는 먼저 기능의 값을 판단해야 하므로 독립적인 경험 분기가 먼저 유지됩니다. 경험을 완료한 후 사용자의 명시적인 동의 및 승인으로 이 단계가 종료됩니다. 교체 없이 스크린샷만 표시 Test，그러나 실제 새로 고침 및 데이터 품질을 확인할 수 없으며 실무 경험에 대한 요구 사항을 충족하지 않습니다.。

## 영향
