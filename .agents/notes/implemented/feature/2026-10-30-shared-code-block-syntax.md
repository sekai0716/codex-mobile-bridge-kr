# Agent Note: 채팅 코드 블록 주석 언어 및 재사용 소스 코드 강조 표시

Status: implemented

## 문제

모바일 채팅용 코드 블록에는 오른쪽에 복사 버튼만 있습니다.，Python 코드에 언어 태그와 색상이 누락되었습니다. 파일 미리보기가 이미 로컬에 존재합니다. Prism，다른 강조 라이브러리를 도입하거나 다른 클라이언트에 대한 구현을 복제하면 리소스 및 유지 관리 비용이 증가합니다.。

## 결정

`web/shared/code-syntax.js` 언어 별칭, 표시 이름, 크기 제한 및 안전한 토큰 렌더링을 통합합니다. 채팅 기반 Markdown fence 첫 번째 언어 필드는 유형을 식별합니다. 언어는 왼쪽에 표시되고 복사 버튼은 오른쪽에 예약되어 있습니다. ”일반 텍스트”는 표시되지 않거나 알 수 없는 유형에 대해 텍스트를 기반으로 추측하지 않고 표시됩니다. 인라인 코드 및 완료 Mermaid 차트는 기존 경로를 계속 사용합니다. 파일 미리보기는 확장자 선택, 줄 번호 및 원본 텍스트 복사본을 유지하며 제한된 단어 분할만 재사용합니다.。

로컬 상속 PrismJS 1.30.0 라이브러리를 추가하지 않고 기존 언어 컬렉션이나 CDN。작은 공유 도우미가 페이지와 함께 로드됩니다. 36 KB 의 Prism 독립하다 `syntax` 지연 로딩 그룹; 일반 텍스트와 큰 코드는 이를 요청하지 않으며 여러 코드 블록과 파일 미리보기가 단일 로드를 공유합니다. 비동기 완료 음영만 남음 DOM 내부 코드 노드는 메시지, 입력 상자 또는 초안을 다시 작성하지 않습니다. 실패 시 일반 텍스트를 유지하고 자동으로 반복 및 재시도하지 않습니다. 밝은 토큰 스타일과 어두운 토큰 스타일로 공유 파일 생성。

초과하다 65,536 문자 또는 4,000 줄은 단어로 구분되지 않습니다. 강조 표시는 텍스트 노드를 사용하고 `span`，모델 콘텐츠를 다른 사람에게 양도하지 마세요. HTML 분석하다. 원본 완문 읽기 기능을 통해 복사가 계속되며, 언어 태그, 컬러링에서는 읽을 수 없습니다. DOM 또는 디스플레이 접합을 자릅니다.。

## 대안

- 채팅에서 직접 모든 것을 로드하세요. `files` 그룹에서는 로딩 항목을 덜 변경할 수 있지만 동시에 도입됩니다. PDF 및 HTML 미리보기 및 기타 관련 없는 구성요소를 통해 하이라이트 리소스를 분리하고 공유합니다.。
- 첫 화면에서 바로 불러오기 Prism 색상을 동기화하는 것이 가장 쉽지만, 코드가 없는 목록과 일반 텍스트 채팅도 다운로드 및 구문 분석 부담을 부담하므로 요청 시 로드됩니다.。
- 새로운 자동 언어 감지 라이브러리는 표시되지 않은 조각에 색상을 지정할 수 있지만 잘못된 터미널 출력을 추측하여 종속성과 계산을 증가시킵니다. 이번에는 모델에서 명시적으로 표시된 언어만 사용됩니다.。

## 영향

동일한 행동 범위 세트 Web、iOS、Android 다양한 고객과 채팅하세요. 엑스트라 없음 API 쿼리, 백그라운드 폴링 또는 쓰기. 공유 도우미는 작은 동일 원본 스크립트를 추가합니다.，Prism 아직 사본은 1개뿐입니다. 알 수 없는 언어 및 제한 초과 코드는 색상이 없지만 라벨링, 읽기, 복사가 가능합니다. 기본 클라이언트의 메시지 스타일은 이 문서의 범위에 속하지 않습니다.。

적용 범위 확인 Chromium 및 WebKit 넓고 좁은 화면：Python 별명、HTML 리터럴 콘텐츠, 왼쪽 및 오른쪽 버튼 순서、300px 컨테이너, 밝은 색상과 어두운 색상, 원본 텍스트 복사본, 파일 간 미리보기, 단일 리소스 로드, 너무 긴 코드, 닫히지 않음 fence、리소스 오류 및 이전 노드 교체 총 4개 그룹 12 항목이 통과되었습니다. 소스 코드 보기 12 아이템, 시작/Markdown 파일 모드 등 36 항목이 통과되었습니다. 첫 번째 Chromium 해당 항목이 설치되지 않아 실행 headless shell 시작되지 않았습니다. 기존 제품을 사용하세요.
