# Agent Note: SSH CLI 업스트림 모델 디렉토리

Status: implemented

## 문제

네이티브 CLI 이전에 경로가 모두 거부됨 SSH API 모델을 수동으로 채워야 하는 카탈로그 ID，선택한 원격 런타임의 업스트림 디렉터리를 사용할 수 없습니다.。

## 결정

조인된 데몬 프로세스에서 효과적인 구성을 읽고 동일한 프로세스에서 실행합니다. SSH 호스트는 디렉터리 검색을 수행하고 로컬 게이트웨이 인증을 대체하지 않습니다.。

대상 작업자는 지정된 동일한 사용자의 인증된 데몬에서만 읽습니다. provider 환경 변수. 대상 플랫폼 리더 확인 PID 생성, 실행 파일 및 CODEX_HOME。작업자는 정규화된 공개 모델 메타데이터와 불투명 ID 요약을 반환하지만 시작 자격 증명이나 인증 파일 콘텐츠는 반환하지 않습니다. 기존의 config/read 스냅샷 통과 SSH stdin 명령 매개변수나 임시 파일 전송 없이 원래 호스트로 다시 보내기。

호스트, 원격 홈 디렉토리、cwd、provider、구성, 계정 번호, 인증 파일 다이제스트 및 선택한 환경이 결합되어 캐시된 ID를 형성합니다. 업스트림 모델로 ID 승리할 것이다; 기본 메타데이터는 정확히 일치하는 경우에만 사용됩니다. ID 추론의 힘을 보완하십시오. 스크래핑 전후에 신원을 다시 확인하십시오. 동일한 ID가 실패하면 최근에 성공한 결과와 타임스탬프가 유지됩니다. ID가 변경되면 결과를 재사용할 수 없습니다. 기존 매뉴얼과 12 시간별 새로 고침 정책 보존。

소스 코드 패키지에는 두 가지가 포함되어 있습니다. POSIX 플랫폼 리더 및 종속성으로 고정 패키징 가능 Windows/Mac 게이트웨이를 쿼리할 수 있습니다. Linux 목표. ～을 통해 SSH 입장 Windows 기존에 속하지 않습니다. POSIX SSH 계약을 실행합니다. 현지의 Windows CLI 기본 리더 사용。

独立 SSH 目录源码显式去掉本机 Windows 安装库存指纹方法，保留不依赖包导入的空指纹实现；两种 SSH 目录组装复用同一处理。本机 Windows 仍使用真实库存指纹。SSH 每次请求重新发现并显式传入目标运行时，不需要该本机持久库存；原生 CLI 的进程、环境和账号身份核验保持不变。资源回归同时执行 AST 包导入检查和隔离解释器定义检查，防止以后新增本机依赖悄悄进入远端源码。

지원됨 SSH 대상은 응답을 노출하기 위해 자격 증명을 게이트웨이로 다시 가져오지 않고도 업스트림 모델 메타데이터를 반환할 수 있습니다. 캐시에는 완전한 ID 제한이 적용되며 ID가 변경된 후에는 이전 결과를 재사용할 수 없습니다. 실패한 새로 고침은 동일한 ID를 가진 성공한 레코드만 유지합니다. 기능은 여전히 ​​대상 네트워크에 의해 제한되며 POSIX SSH 계약상의 제한을 시행하여 경제적 이익을 지원하지 않습니다. SSH 관리하다 Windows。
