## 문제

Mobile 인터페이스와 Bridge 채팅 인터페이스를 통합하고 액세스 플러그인을 독립적으로 설치할 수 있도록 처리합니다. Harness 앱 이름으로 식별되는 전용 적응이 아닌 플러그인。

### 휴대폰 연결 목록 및 상단바

DSH Mobile 및 Bridge 게이트웨이는“내 컴퓨터”가장 최근에 오픈한 시간을 기준으로 정렬합니다. 양쪽 끝은 기본 기본 설정에만 로그인됩니다. `last-opened:dsh:<opaque-id>` 시간이 완전하지 않음 Mobile 게이트웨이 주소, 프로브 또는 백그라운드 알림 수집에 참여하기 위한 링크입니다. QR 코드를 스캔하여 확인하고 저장된 연결을 열면 시간이 업데이트됩니다. 기존 항목에 대한 시간 기록이 없는 경우 원래의 결정적 정렬이 사용되며 첫 번째 재개 이후 가장 최근 주문이 입력됩니다. 연결을 제거하고 시간 기록을 제거하십시오。

DSH 카드는 수평 및 동일한 너비의 연결 및 제거 버튼을 사용하여 게이트웨이를 따르는 위험한 색상을 제거합니다. 접근성으로 표시된 컴퓨터와 새로 고침 아이콘은 상단 표시줄 양쪽에 사용되며 제목은 중앙에 배치됩니다.。iOS 웹페이지를 뒤로 계속 밀어넣기，Android 시스템에서 반환된 웹페이지의 처리 기록을 보존합니다. 이 변경 사항은 원본을 변경하지 않습니다. DSH 웹페이지 자체의 제목, 콘텐츠 또는 알림。

현재 공식 시장에 대한 기본 지수는 없습니다. 표준 형식 1 지원하다 npm 또는 고정 제출 Git 소스를 설치합니다. 이번 라운드에서는 먼저 패키지의 작성자, 웨어하우스 및 작동 지침을 개선하고, 무시된 디렉터리에 초안 인덱스를 생성하고, 검증된 코어의 공식 파서를 사용하여 설치 대상을 확인합니다. 초안 타임스탬프 0 로컬 검증 자리 표시자일 뿐이며 게시된 패키지의 실시간 시간은 실제로 게시될 때 읽어야 합니다. 아직 게시되지 않음 npm、공개적으로 색인화하거나 원격으로 푸시하고 준비 완료를 시장에 출시된 것처럼 표현하지 않습니다. 소스 코드에서 `plugin/` 내보내는 동안 병합이 누락되었습니다. host 라이센스를 사용하면 내보낸 전체 패키지를 게시해야 합니다.。

## 대안

- 큰 그림을 편하게 생각하세요 `GatewayURL` 더 적은 코드로 링크를 허용하지만 외부 페이지에 혼합됩니다. Bridge 의 Cookie、기본 인터페이스 및 배경 감지 경로. 따라서 두 가지 유형의 명시적 연결이 사용됩니다.。

- 계속해서 정확한 소스 파일을 일치시키면 게이트웨이와 플러그인이 완전히 동기화되지만 독립 실행형 플러그인 릴리스에는 적합하지 않습니다. 새로운 시리즈는 명시적 버전과 프로토콜 핸드셰이크를 사용합니다. 이전 시리즈는 여전히 알려진 해시를 유지합니다.。
- 코어 범위를 모든 후속 버전으로 즉시 확장하면 설치가 더 쉬워지지만 개발 프리뷰 코어에서 인터페이스 변경이 중단된다는 증거가 부족합니다. 따라서 실제 테스트 코어만 선언하고 새 버전이 반환되면 완화될 예정입니다.。
