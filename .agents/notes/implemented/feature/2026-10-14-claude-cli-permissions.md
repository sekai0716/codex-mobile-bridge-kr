# Agent Note: Claude Code CLI 기본 권한 모드

Status: implemented

## 문제

복원됨 Claude CLI 세션은 기본 권한 선택을 제공하고 사용자가 요청한 모드와 기본 프로세스에서 실제로 유효한 모드를 구별해야 합니다. 전체 액세스는 사용자가 명시적으로 확인해야 하며 세션을 시작하거나 재개해도 자동으로 활성화될 수 없습니다.。

## 결정

명시적으로 복원됨 CLI 세션은 기본 제공 default、acceptEdits、plan、dontAsk、auto 및 bypassPermissions 옵션. 시작 시 나중에 선택 허용 bypassPermissions，그러나 저장된 모드는 그대로 유지됩니다. 전체 액세스에는 옵션을 명시적으로 선택해야 하며 서버에서 확인하는 확인 필드가 제공됩니다. 실행 경로가 자동으로 선택되지 않습니다. 기본 제어 응답만 명시적으로 요청된 모드를 반환합니다. Bridge 어댑터는 보류 프로세스가 상태 이벤트를 통해 유효 모드를 보고한 후에만 성공적인 수정을 보고합니다. 불일치 또는 누락된 보고서가 있는 경우 조치가 확인되지 않은 상태로 유지됩니다.。

닫힌 기록은 여전히 ​​권한 옵션을 제공하지 않으며 알 수 없는 저장 권한은 여전히 ​​복구를 방해합니다. 원래 구성、cwd 유지하도록 소스를 설정합니다.。

## 대안

원본 기록에는 기본 권한 제어, 전체 액세스 확인 및 유효한 상태 보고가 명확하게 유지되지만 다른 권한 관리 솔루션의 비교 프로세스는 기록되지 않습니다. 자체 구축된 권한 레이어 또는 기타 대체 구현이 평가되었다는 증거가 없으므로 그러한 기록은 다시 작성되지 않습니다.。

## 영향

권한 선택은 명시적 복구에만 영향을 미치며 다음에 의해 결정됩니다. Bridge 유지된 CLI 프로세스; 마감 내역은 여전히 ​​​​통제를 열지 않습니다. 기본 제어 응답은 유효 상태와 일치해야 하므로 조직 정책이 거부하거나 상태가 누락되거나 일치하지 않는 경우 작업은 확인되지 않은 상태로만 유지될 수 있습니다. 원래 구성、cwd 옵션을 열어도 설정 소스가 변경되지 않습니다.。

## 검증

설비 테스트 적용 범위 모드 옵션, 전체 액세스 검증 및 기본 제어 라우팅。`python -B -m unittest tests.test_claude_cli` 및 `node --test tests/desktop-sessions-ui.test.cjs` 통과하다. 기본 에이전트는 설치된 것을 사용합니다. Claude 2.1.287 및 격리 시뮬레이션 API 승인을 통해 6개 모드 모두에 대한 제어 응답과 유효한 기본 상태가 확인됩니다. 기본 프로세스가 조직 수준 제한으로 인해 수정을 거부하는 경우에도 여전히 승인되지 않은 것으로 보고됩니다. 미사용 비용 지불 API。
