# Agent Note: 와이드스크린 채팅 목록 접기

Status: implemented

## 문제

#165 기존 대화, 초안 및 작업대 탭을 유지하면서 채팅을 위한 더 많은 공간을 제공하는 태블릿 및 데스크탑 와이드스크린을 기대하세요.。

## 결정

의존하다 ClientNavigation 채팅 목록 축소 기본 설정 저장，Codex 다른 클라이언트와 제어를 공유합니다. 기존 병렬 레이아웃이 다음을 초과하는 경우에만1100px목록이 축소되었습니다. 확장 버튼은 목록 외부에 배치되며 빈 환영 페이지도 복원할 수 있습니다. 스위치 레이아웃만class，목록을 반환하거나 채팅 또는 워크벤치를 다시 빌드하기 위한 호출은 이루어지지 않습니다. 목록이 축소된 후 더 이상 키보드 포커스를 허용하지 않습니다.。

## 대안

뒤로 버튼을 재사용하려면 새로운 컨트롤이 필요하지 않지만 현재 채팅 선택이 지워집니다. 누르는 것Agent별도로 접기를 수행하면 논리가 중복되고 일관되지 않은 기본 설정이 생성됩니다. 따라서 공유 탐색 및 크기 레이어를 재사용하여 중간 및 좁은 화면의 기존 동작을 유지합니다.。

## 검증

66항목 탐색, 레이아웃 및 리소스 확인을 통과했습니다. 현실Chrome및WebKit절연 설비 커버1440、844、390너비，Codex/Claude/DSH초안 및 원본 상태 객체 접기, 복원, 유지, 영어 라벨，2항목이 통과되었습니다. 스크린샷을 확인했습니다. 합성 세션을 사용하고 실제 전화 확인을 주장하지 마세요.。

## 영향

와이드 스크린에 하나 추가하고 철회/확장된 가장자리 버튼의 경우 클라이언트를 전환할 때 기본 설정이 유지됩니다. 좁은 화면에서는 기본 설정이 무시되고 확대 후에는 복원됩니다. 기존 공유 채팅 읽기 상태 메모와 부분적으로 관련되어 있지만 탐색 및 스크롤 복구 의미는 변경되지 않습니다.。

## Mac Test 실제 페이지 확인

새 버전에서는8788연결된 채팅의 임시 초안 입력 후 접기/현재 채팅을 확인하려면 목록을 확장하세요.、host、워크벤치 객체는 초안과 일관성을 유지합니다. 그런 다음 원본 초안이 복원됩니다. 기존의Chrome/WebKit세션을 다시 작성하거나 모델을 호출하지 않고도 좁은 화면 중단점이 유지된 회귀 결과。
