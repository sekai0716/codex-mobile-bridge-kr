# Agent Note: 설치됨 Claude Code CLI Skills

Status: implemented

## 문제

모바일 버전 Claude CLI Skill 선택 항목은 선택한 기본 프로세스에서 실제로 로드한 명령과 일치해야 하며 플러그인 활성화, 프로젝트 범위 및 사용자 호출 가능 제한 사항을 유지해야 합니다. 하나만 알아요 Skill 파일이 존재하며 프로세스의 사용 가능한 명령 디렉터리를 대체할 수 없습니다.。

## 결정

복원됨 CLI 원래 구성 디렉터리, 작업 디렉터리 및 사용자를 유지합니다./프로젝트/로컬 설정 소스。Skill 선택기는 실제 로드된 명령에 대해 기본 초기화를 사용하고 내장 명령을 제외합니다. 기본 플러그인 활성화 상태, 프로젝트 범위 및 사용자 호출 가능성 제한에 따라 사용 가능한 옵션이 결정됩니다. 게이트웨이는 두 번째 파일 시스템 파서 세트를 유지하지 않습니다.。

선택된 CLI Skill 에서 Bridge 프로세스를 기본으로 유지 `/name` 공식적인 통화。CLI 메시지는 하나만 선택할 수 있습니다. Skill，기본 호출 형식과 일치합니다. 보내기 전에 서버는 보유 프로세스의 디렉터리를 기반으로 선택을 확인합니다. 닫힌 내역은 읽기에 수동적이며 제공되지 않습니다. Skill 선택하다。

## 대안

원본 레코드는 기본 초기화 디렉터리를 명시적으로 선택하고 두 번째 파일 시스템 파서 세트를 명시적으로 유지하지 않습니다. 옵션은 기본 플러그인, 범위 및 호출 가능성 제한에 따라 결정됩니다. 두 번째 파서 세트를 제공하지 않은 시험 또는 기타 후보 비교에 대한 문서는 이 경계를 완료된 솔루션 평가로 확장하지 않습니다.。

## 영향

선택 과목 Skill 현재 보유 프로세스에 따라 서버는 전송하기 전에 다시 확인합니다. 가격은 기본 초기화 디렉터리와 각 항목에 따라 기능이 달라진다는 것입니다. CLI 메시지는 하나의 기본만 지원합니다. Skill 부르다. 닫기 내역은 수동적으로 읽은 상태로 유지되며 디스플레이 선택기에 대한 프로세스가 시작되지 않습니다.。

## 검증

고정 장치 테스트 적용 범위가 로드된 사용자/프로젝트/플러그인 명령 필터링 및 기본 슬래시 명령 입력. 기본 에이전트는 설치된 것을 사용합니다. Claude 2.1.287、격리 구성 및 루프백 시뮬레이션 API 수락, 검증된 네이티브 Skill 확장하다; 이미지가 있는 입력의 경우 기본 Skill 도구에는 선택한 명령, 정확한 이미지 바이트 및 업로드된 파일의 바이트가 전달됩니다. Read 결과. 미사용 비용 지불 API。
