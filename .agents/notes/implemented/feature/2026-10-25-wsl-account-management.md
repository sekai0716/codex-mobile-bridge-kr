# Agent Note: 환경에 의해 격리됨 WSL 계정 관리

Status: implemented

## 문제

게이트웨이 제어 가능 WSL Codex 및 Claude Code 세션이지만 Codex 계정 관리에서는 여전히 외부 작업만 허용됩니다.，Claude 아직은 제한적 Desktop。～에서 Windows 동일한 자격 증명을 복사한다고 해서 공유 구성이나 지속적인 동기화가 발생하는 것은 아닙니다. 네이티브 재사용 Desktop 전환하면 잘못된 환경을 가리키며 기존 작업 및 초안을 방해할 수 있습니다.。

## 결정

등록된 WSL 디스트로/사용자/디렉터리 ID를 구성하면 환경별로 격리된 계정 관리가 제공됩니다. 기존 계정 재사용 UI 독립적인 요청 라우팅 및 대상 측 개인 자격 증명 트랜잭션으로 구현된 모델 캐싱 전략이 있습니다. 기존 네이티브를 모두 유지 Desktop、현지의 CLI 및 SSH 길. 읽기 계정은 릴리스, 데몬, 스레드 또는 모델 요청을 시작해서는 안 됩니다. 명시적인 데스크탑 관리 및 인증 Web/전화 관리는 선택한 환경에만 쓸 수 있습니다. 비밀번호가 없는 요청은 런타임을 저장, 가져오기, 편집, 삭제, 전환 또는 복원할 수 없습니다. 일반 지역 Desktop/CLI 계정 라우팅은 변경되지 않습니다.。

중지된 등록 환경은 공유 계정 패널에서 제공됩니다.“시작 및 연결 WSL”。명시적인 클릭만 원본을 전달합니다. WSL stdin 보조 경로는 지정된 배포 및 사용자를 시작한 다음 환경 계정을 다시 읽습니다. 시작하지 않는다 Codex/Claude daemon，채팅은 생성, 복원 또는 전송되지 않습니다. 요청만 허용됩니다. provider、entry、action，등록 ID 및 활성화 상태를 다시 확인하고 로그인을 유지하십시오.、CSRF 비밀번호가 필요 없는 제한사항입니다. 깨어나지 않고 새로 고침 및 스캔 계속 WSL。이 항목은 중지된 환경에서 사용자에게 페이지를 떠나 수동으로 시작하라는 메시지만 표시할 수 있고 기록 캐시를 현재 실행 상태로 간주하지 않는 문제를 해결합니다.。

Toggle preflight는 현재 ID, 실제 런타임 상태, 대기 중인 메시지 및 알 수 없는 수신을 확인합니다. 상태를 알 수 없거나 메시지를 불분명하게 녹음하거나 재생하는 경우 차단합니다. 명시적으로 승인됨 Codex 핸드오버 중에는 즉시 확인이 유휴 상태가 된 후에만 신원 검증 공유 서비스가 정상적으로 중지될 수 있습니다. 강제 종료 폴백은 사용되지 않습니다. 원자 파일 업데이트는 독립적인 설정과 기록을 보존하고, 예상 ID를 다시 확인하며, 외부 작성자가 파일을 변경하지 않은 경우에만 원본 콘텐츠를 정확하게 복원합니다. 저장된 기본 자격 증명은 반환 경로를 제공합니다. 시스템 키체인 등은 소스가 충실하게 표시되는 것을 지원하지 않으며 자동으로 복사되지 않습니다.。Magpie 그리고 관리하다/겹치는 구성은 보호된 상태로 유지됩니다.。

모델 결과와 초안은 여전히 ​​게이트웨이에 바인딩되어 있습니다./provider/환경/계정 신원. 승인을 통해 캐시 재사용을 수정할 수 없습니다. 기밀 요청은 비공개로 전달됩니다. stdin 소유자가 읽을 수 있는 파일 전송만 가능하며 비밀은 공개 스냅샷이나 버그에 표시되지 않습니다.。

- 재사용 Desktop 전환: 재사용 가능한 성숙한 롤백/UI，하지만 그럴 것이다 Linux 타겟 글쓰기 Windows 자격 증명 및 재부팅 가능 Desktop，따라서 독립적인 경로를 유지하세요.。
- 자동 미러링 Windows 자격 증명: 중복 구성을 줄이지만 명확한 의도 없이 환경 전반에 걸쳐 계정을 변경할 수 있습니다. 대신 선택한 지원 항목의 명시적 가져오기 제공 API 설정。

## 영향

네이티브 Windows 계정 패널, 로컬 CLI 동기화 및 SSH 라우팅은 기존 운송을 보존합니다.。WSL 패널은 정확한 등록 대상에 대해 쓰기 전용 자격 증명을 허용합니다. 계정 스냅샷은 저장된 자격 증명을 반환하지 않습니다. 새로운 대상 스토리지와 소규모 개인 작업자를 구현합니다. 다른 기본 인증 체계에 대한 추가 지원에는 독립적인 증거가 필요하며 자동으로 롤백될 수 없습니다.。

첫 번째 스위치 스냅샷에는 동일한 영구 저장소 쓰기의 기본 ID가 포함되어 있습니다. 쓰기가 원본 파일을 정확하게 복원하지 못하는 경우 사용자는 명시적으로 다시 전환할 수 있습니다. 롤백이 불완전하거나 외부 작성자가 파일을 변경하는 경우 ID 보호는 계속 차단하고 자동으로 재시도하지 않습니다.。

Claude 요청이 다음을 가리키는 것으로 알려진 경우에만 WSL 선택사항 추가 시 `request_scopes` 보조 테이블. 묻다 ID、지문, 상태, 확인 및 재시도 동작은 변경되지 않습니다. 범위가 지정되지 않은 기록 영수증은 되돌릴 수 없는 해시에서 속성을 추론할 수 없습니다. 그들은 그대로 유지되며 모든 외부 상황을 차단하지 않습니다. 활성 상태이거나 소유권을 알 수 없는 생존 프로세스는 여전히 차단됩니다. 향후 영수증 변경에는 이러한 구분이 유지되어야 합니다.。

API 모델 검색은 기존 파서를 재사용하고 TLS 전략. 업스트림 이전에 결과 캐시 I/O 반납 및 신원확인 협조、singleflight 및 12 시간별 타이머; 중지되거나 비활성화된 환경에서는 시작되지 않습니다. 새로 고침이 실패하면 동일한 ID를 가진 성공적인 결과만 유지됩니다. 웹 스크래핑은 레지스트리나 제어 잠금을 유지하지 않습니다. 관리자 취소 타이머를 종료하고 캐싱 및 진행 중인 응답 게시를 방지합니다.。

Python 3.9/3.10 목표가 누락되었을 뿐 TOML 사용된 파서는 수정되지 않은 상태로 프로젝트와 함께 운반되며 MIT 허용됨 Tomli 2.0.1 소스 코드. 소스 코드 stdin 대상 설치 패키지가 아닌 메모리에 전송되어 로드됩니다. 라이센스 및 소스 코드 해시는 다음 위치에 있습니다. `bridge/vendor/wsl_tomli/`，동결된 리소스 포함。

공식 로그인 등록, 키체인 자격 증명, 관리되는 구성 및 지원되지 않는 사용자 정의 provider 라우팅은 여전히 ​​원본에 의해 수행됩니다. CLI 관리하다. 구성 스위치 보고 `activeVerified: false`：파일을 저장한다고 해서 업스트림 로그인이 유효한지 증명되는 것은 아닙니다. 기존 채팅, 초안 및 대기열은 새 계정으로 자동으로 마이그레이션되지 않습니다. 다음은 명시적인 Claude WSL 계속은 알려진 원본 스레드와 전송되지 않은 초안에 대한 제한된 예외입니다. 대기 중이거나 불확실한 커밋은 마이그레이션되지 않습니다.。

## Claude WSL 명시적으로 계속

명시적인 스위치만 유휴 상태를 끌 수 있습니다. stream-json 액추에이터 stdin。출시하기 전에 관리자, 등록, 원격 및 영수증 확인을 통과하세요. 토종의 ID、원천、cwd 준비 프리플라이트는 선택한 환경과 일치해야 합니다.。EOF 확인하기 전에 인스턴트 계정 ID와 선택한 구성을 확인하세요. 게이트웨이는 신호를 보내거나 Executor를 강제 종료하지 않고 자연 종료를 기다리며, 타임아웃 이후에는 계정 파일을 쓰지 않습니다. 대상 측 프로세스 검사는 여전히 나머지 외부 기본 클라이언트를 거부합니다. 알려진 내용에 대해서만 읽기 전용 자격 확인“프로세스가 실행 중입니다.”차단 이유는 차단 이유를 시도하고 유지하는 기능을 반환합니다. 이는 외부 클라이언트가 종료되었음을 의미하지 않습니다.。

Claude 기본 구성 소스에는 구성 및 인증 지문이 포함되어 있으므로 기본 기록 파일만 보존하면 게이트웨이 세션이 보존되지 않습니다. ID。명시적인 거래 기록의 출처가 알려져 있음 ID，새로운 사전 및 사후 작업 구성을 확인하고 ID를 정확하게 구성하며 기본 ID、cwd、모델, 권한 모드, 프로젝트 구성 및 기록 파일 장치 번호/inode。게이트웨이 개인 데이터 디렉터리에 정확한 내용을 원자적으로 저장“새로운 소스→기존 ID”별명. 일반적인 외부 계정 변경 사항은 이 승인과 일치하지 않으며 여전히 격리되어 있습니다. 목록을 새로 고치거나 게이트웨이를 다시 시작하면 정확한 승인 별칭만 유지됩니다.。

별칭은 최대 32 자격 증명이 없는 이전 초안 계정의 해시입니다. 새로운 세부정보 응답은 현재 기본 세션과 초안 소유자가 별칭과 일치하는 경우에만 이 기록 연관성을 노출합니다. 관리자 및 공개 토글 응답은 입력 상자와 동일하게 사용됩니다. WSL/provider/연결이 끊긴 클라이언트가 명시적으로 승인된 데스크톱 전환 후 전송되지 않은 초안을 유지할 수 있도록 하는 환경 초안 네임스페이스입니다. 대기 중인 요청 ID、영수증 및 대기 중인 메시지는 포함되지 않습니다.。

계정 파일 전환에 성공했지만 기본 확인에 실패한 경우 응답을 보고합니다. `continuationPending`，중복 계정을 작성하지 마십시오. 개인 보류 레코드는 적용된 정확한 구성된 ID를 보유합니다. 이후 새로 고침에서는 신원이 여전히 원래 기록 증거와 일치하는 경우에만 승인된 거래를 완료할 수 있습니다. 적용된 ID에 대한 준비 작업이 아직 완료되지 않았습니다. 읽는 동안 별칭을 만들 수 없습니다.。

인증 다시 로드 메커니즘으로 바이트 릴레이만 끄는 것을 거부하고 이름으로 프로세스를 종료하거나 강제 폴백과 함께 데몬 중지 명령을 사용하는 것을 거부합니다. 이러한 바로가기는 소유권 증명을 설정하거나 활성 작업을 보호하거나 기존 기본 스레드가 사용할 계정을 증명하지 않습니다.。
