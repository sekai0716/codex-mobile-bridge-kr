# 한국어 표시 문구 교정과 대기열 직접 편집

- 공통 번역 사전 전체와 웹·PC 화면의 고정 번역 호출, `data-i18n` 속성을 대조한다. 기존 API 오류 키와 영어 문구를 보존하고 한국어 표시값을 별도로 교정한다. 채팅 본문, 명령 출력, 모델 ID, 파일명과 사용자 입력은 번역 대상으로 추가하지 않는다.
- 사용자 지정 용어를 우선한다: 명령을 실행함, 나 대신 승인, Codex 생각 중, 스티어링함, 자동검토중, 사이드 채팅, 터미널. 채팅 이름 안내는 ‘비워 두면 에이전트가 채팅 이름을 자동으로 정합니다.’로 표시한다.
- 메뉴, Git·터미널, 스킬, 컨텍스트, 계정과 사용 한도, 알림, 파일 작업의 직역 표현과 문장 부호를 교정한다. 뜻이 일정한 용어는 등록된 UI 문구에서만 통일하고 조사도 함께 처리한다. 사전 밖의 문자열은 그대로 반환한다. 타임라인 활동 제목은 생성과 언어 전환 모두에서 공통 번역을 사용한다.
- 참고: [OpenAI의 Codex 안내](https://help.openai.com/ko-kr/articles/11369540-using-codex-with-your-chatgpt-plan). 공식 도움말에도 기계 번역 표시가 있으므로 문장을 그대로 복제하지 않고 기능 문맥과 사용자 지정 표현을 적용한다. 원본 앱 전체 UI와 동일하다고 단정하지 않는다.
- 대기열 카드의 철회 버튼을 ‘다시 편집’으로 교체해 기존 메시지 관리 편집기로 바로 연결한다. 최신 계정·대기열을 조회한 후 해당 ID를 선택하며, 다른 메시지의 저장된 편집 내용은 덮어쓰지 않는다. 저장 시 원래 ID·순서·첨부·스킬·전송 설정을 유지한다. 현재 입력 중인 채팅 초안은 편집 버퍼로 사용하지 않는다. ‘지금 보내기’와 메시지 관리 안의 대기열 삭제 동작은 유지한다.
- 워크벤치는 새 한국어 표시값도 번역 문구로 인식한다. 언어를 전환해도 UI 문구가 고정되지 않으며 `raw()`로 표시한 파일명은 바꾸지 않는다.
- 첨부 크기 제한 해제 커밋 `393ed472`를 main과 PC 게이트웨이에 먼저 반영한 뒤 이 작업을 이어간다. 이 작업은 별도 단기 브랜치에서 검증 후 main에 병합한다. Android 네이티브 파일은 변경하지 않으며 APK 재빌드는 필요하지 않다. PC 제어판에 포함된 공통 번역 리소스와 게이트웨이의 웹 리소스를 갱신한다.
- 검증: 공통 사전 3,940개 문구의 용어·자리표시자와 기존 영어 3,918개의 보존을 대조했으며 한국어 362개를 교정했다. 고정 번역 호출·마크업의 미등록 문구 9개를 보완한 뒤 재검사한 미등록 문구는 0개다. 전체 프런트엔드 128파일은 등록 테스트 1,643개 중 1,642개 통과, Windows 전용 1개 건너뜀이며 직접 assertion 파일 5개도 성공했다. 리소스·패키징·모듈 경계 17개와 Chromium의 서로 다른 화면 검사 18개를 확인했다. 최종 워크벤치 언어 전환 검사는 양쪽 화면에서 다시 통과했다. 실제 Android 기기는 연결되어 있지 않아 휴대폰 조작 검증은 수행하지 않았다.
