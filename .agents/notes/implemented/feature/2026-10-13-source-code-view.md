# Agent Note: 읽기 전용 소스 코드 미리보기는 원본 텍스트와 독립적인 줄 번호를 유지합니다.

Status: implemented

## 문제

Workbench 파일 미리보기는 텍스트를 Workbench에 직접 입력합니다. `pre/code`，일반적인 소스 파일에는 구문 색상과 줄 번호가 없습니다. 후속 조치 HTML 소스 코드 전환에도 동일한 읽기 전용 렌더링 세트가 필요하며 강조 표시된 태그나 줄 번호를 변경하여 콘텐츠를 복사할 수 없습니다.。

## 결정

`BridgeSourceView.create({name, text})` 삽입 가능한 미리보기를 반환합니다. DOM 마디. 확장만 결정 Prism 통사론; 알 수 없는 유형은 원본 텍스트를 표시합니다. 줄 번호는 선택할 수 없는 별도의 열에 있고, 코드 노드의 텍스트는 서버에서 반환된 원래 문자열로 유지되며, 복사 버튼은 해당 문자열에서 복사됩니다. 줄번호 누르기 LF、CRLF 아니면 혼자 CR 세다；Tab 교체가 없습니다. ”자동 줄 바꿈”과 ”원래 줄 너비”는 소스 코드 구성 요소에서 전환할 수 있습니다. 기존 읽기 방법을 유지하기 위해 원래 선 너비가 기본적으로 유지됩니다. 이 버튼은 글로벌 설정을 추가하지 않고 현재 인터페이스 언어에 따라 중국어와 영어를 표시합니다.。

각 원래 줄은 코드 노드의 줄 요소에 해당하며 원래 줄 바꿈은 보이지 않는 줄 끝 텍스트에 저장됩니다.；Prism 단어 요소가 한 줄을 넘으면 표시 노드만 분할되고 소스 코드 문자는 분할되거나 정규화되지 않습니다. 코드 라인과 독립된 라인 번호 열이 동일하게 입력됩니다. CSS Grid 따라서 부드러운 줄 바꿈으로 추가된 높이는 해당 줄 번호에 동기화되며 공백이 없는 매우 긴 줄도 컨테이너 너비 내에서 줄 바꿈될 수 있습니다. 실행할 태그 선택 `copy` 원본 텍스트의 이벤트와 DOM 브라우저를 피하기 위해 선택 경계에서 텍스트를 다시 작성하십시오. CRLF 정규화 LF；이미 ”코드 복사” 버튼이 있는 경우 원본 텍스트가 직접 복사됩니다.。

PrismJS 1.30.0 의 core 첫 번째 필수 언어 구성 요소와 함께 기본 스크립트로 배포됩니다.，MIT 아래 라이선스 `web/vendor/prism/LICENSE`。언어 컬렉션에는 다음이 포함됩니다. markup、CSS、C-like、JavaScript、Python、TypeScript、JSX、TSX、JSON、YAML、TOML、Bash、PowerShell 및 Batch。스크립트는 전체 페이지의 자동 강조 표시를 끕니다. 소스 코드 보기 전용 호출 `Prism.tokenize(text, grammar)`，토큰을 재귀적으로 다음으로 변환합니다. DOM 텍스트 노드 및 색상 `span`。통과하지 못하다 HTML 분석하다，CRLF、홀로 CR 및 NBSP 소스 코드 노드에 문자가 남아 있을 때까지 기다립니다. 초과하다 65,536 문자 또는 4,000 실행 시 일반 텍스트를 표시합니다. 초과하다 10,000 엄청난 생성을 피하기 위해 실행할 때 줄 번호 열을 생략하십시오. DOM 그리고 레이아웃 작업. 작업공간이 이미 존재합니다. 512 KiB 상한 미리보기, 더 크거나 그렇지 않음 UTF-8 파일에 이유가 표시되고 다운로드 링크가 유지됩니다.。

공개 스크립트 URL 에서 `web/assets.json` 및 `bridge/api/assets.py` 동기식，HTML 보장하다 Prism、소스 코드 보기와 워크벤치가 순서대로 로드됩니다.。`scripts/gateway-resources.json` 스크립트 및 권한 통합；SSH 주입은 여전히 ​​원래 8개만 보냅니다. Python 소스 모듈은 브라우저 스크립트에 의존하지 않습니다.。

## 기존 메모 감사

[채팅 공유 하이라이트](2026-10-30-shared-code-block-syntax.md)공유 단어 분할, 색상 일치 및 독립성 확보 `syntax` 지연 로딩 그룹; 이 기사의 줄 번호, 정확한 텍스트 및 파일 보기 동작은 계속 적용됩니다.。

이 저장소에서 활성 노트를 검색해도 동일한 소스 코드 보기가 결정되지 않습니다. 승인된 로컬 제안에는 터미널 색상과 커서도 포함됩니다. 소스 코드 부분은 이 노트에 의해 구현되며 터미널 부분은 다음 라운드를 위해 예약되어 있습니다.。

## 대안

- 정상적으로 유지 `pre/code`：리소스가 적고 렌더링이 빠르지만 필수 구문 색상과 줄 번호가 부족합니다.。
- Prism 줄 번호 플러그인: 줄 번호를 빠르게 생성할 수 있지만 줄 번호를 코드 블록 레이아웃과 연결합니다. 독립 열을 사용하면 선택 및 복사 시 줄 번호가 혼합되지 않도록 더 쉽게 확인할 수 있으며 대용량 파일의 비용을 개별적으로 제한할 수 있습니다.。
- 두 개의 병렬로 `pre` 직접 설정 `pre-wrap`：변경 사항은 거의 없지만 코드가 소프트 래핑된 후에도 줄 번호는 여전히 한 줄만 차지하며 원래 줄과 잘못 정렬됩니다.。
- `Prism.highlight` 의 HTML 문자열: 호출하기 간단하지만 쓰기 `innerHTML` 지나갈 것이다 HTML 구문 분석, 아마도 정규화 CRLF 및 NBSP；토큰과 텍스트 노드를 직접 사용하여 원본 문자 저장。
- ～에서 CDN 짐 Prism：로컬 리소스 인벤토리를 추가하지 않지만 오프라인 및 SSH 게이트웨이 페이지는 외부 네트워크의 영향을 받습니다. 게이트웨이와 함께 배포된 고정 구성요소 세트 중에서 선택하세요.。

## 영향

일반적인 소스 파일은 구문과 줄 번호를 인식할 수 있으며 알 수 없는 언어는 여전히 원본 텍스트를 읽을 수 있습니다. 좁은 화면에서는 자동 줄 바꿈으로 자동 전환할 수 있습니다. 스크립트 강조 표시 36 KB；임계값을 초과하면 색상이 손실됩니다. 10,000 줄 번호는 여전히 생략되지만 줄 바꿈을 전환하고 원본 텍스트를 보고 복사할 수 있습니다. 원래 라인으로 디스플레이 노드 증가 생성 DOM 따라서 대용량 파일에서 일반 텍스트를 계속 보존하고 행 번호의 여러 줄 생략으로 인해 퇴화됩니다. 이 모듈은 읽기 전용 소스 코드 표시만 담당하고 터미널을 처리하지 않습니다.
