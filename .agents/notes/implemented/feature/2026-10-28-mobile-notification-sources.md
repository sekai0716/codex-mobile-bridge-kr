# Agent Note: 연결 주소에 따라 휴대폰에서 작업 알림 소스를 선택하세요.

Status: implemented

## 문제

공식 버전을 저장하고 Test 랜、HTTPS 4개의 항목을 입력하면 각 주소는 받은 편지함을 독립적으로 읽으며 동일한 작업으로 4개의 시스템 미리 알림이 생성될 수 있습니다. 사용자는 이러한 연결 채널을 개별적으로 켜거나 끌 수 있는 알림을 요청합니다.。

## 결정

전화 설정에 추가“알림 소스”，저장된 컴퓨터 이름과 전체 주소를 나열하고 하나씩 전환하며 기본적으로 켜진 상태로 유지합니다. 규칙은 휴대폰에 로컬로만 존재하며 게이트웨이 알림 구성, 타사 알림 또는 기타 휴대폰을 변경하지 않습니다.。Android 전면 및 후면 받은 편지함 알림 및 선택 사항 FCM 렌더링은 이 스위치를 따릅니다.；iOS 기존 포그라운드 작업 미리 알림 애플리케이션에 대해서도 동일하게 선택하고 구성되지 않은 애플리케이션에 커밋하지 마십시오. APNs 백엔드 기능。

끄더라도 채팅, 연결 및 받은편지함 동기화는 계속 유지됩니다. 소스를 전환하면 이전 읽기가 무효화되고 다시 열 때 처음으로 성공한 읽기가 기준을 설정하고 종료 중에 메시지를 다시 로드하지 않습니다. 기존 인증에 대한 주소 복구 마이그레이션을 통해 이 항목 선택을 유지하면서 연결 정리 기본 설정을 제거했습니다. 컴퓨터 이름이나 도메인 이름을 기준으로 여러 포털이 자동으로 병합되지 않습니다.。

기존 기록 검색：[Android 백그라운드 알림](2026-10-27-android-background-notifications.md)、[iOS 프런트 데스크 알림](2026-10-28-ios-theme-and-foreground-notifications.md)일부 겹치는 부분이 있습니다. 이 문서에서는 주소 수준 선택을 추가하고 원래 인증, 중복 제거 및 플랫폼 제한 사항을 유지합니다.；[배달 검역](../bug-fix/2026-10-28-notification-delivery-isolation.md)보완적이므로 게이트웨이 스캐닝 및 전달을 변경할 필요가 없습니다. 제목 및 제3자 알림 기록은 대체되지 않습니다.。

## 대안

게이트웨이 수준 종료는 가장 간단하지만 모든 휴대폰과 게이트웨이의 여러 항목에 동시에 영향을 미치며 동일한 휴대폰의 주소 선택을 충족할 수 없습니다. 이름이나 도메인 이름별 자동 중복 제거로 작업을 줄일 수 있지만 공식 버전은 Test 이름은 같을 수도 있고 입구가 다를 수도 있습니다. 이를 기반으로 신원이나 사용자 선호도를 추론할 수 없습니다.。

## 영향 및 검증

4개의 주소 HTTP 회귀 수신: 먼저 이전 구현에서 모든 미리 알림을 재현한 다음 선택한 주소 미리 알림, 자동 주소 커서 및 받은 편지함만 계속 업데이트되는지 확인하고, 서비스 재구성 및 복구 기본 설정, 비활성화된 경우 전송 중 응답 실패, 빠른 전환 및 기준선 다시 시작을 확인합니다.。iOS 프로덕션 동기화 기능은 대기열에 있는 콜백 픽스처를 사용하여 동일한 선택, 세대 보호 및 프런트엔드 경계를 확인합니다. 이 설비는 알림 시스템 유형을 대체하며 시스템이 실제로 전달되었다는 증거로 사용되지 않습니다.。

Android API 35 격리 시뮬레이터는 4개의 실제 스위치, 기본 설정 지속성, 다시 열기, 밝은 색상과 어두운 색상을 확인하고 시스템 알림 렌더링 항목을 호출할 때 4개의 소스에서 하나의 알림만 생성됩니다.。iOS 18.2 격리 시뮬레이터는 4개의 주소 스위치, 저장 및 다시 열기, 테마 상속을 확인합니다. 양쪽 끝의 스크린샷이 확인되었습니다.。Android 처음으로 UI 픽스처는 대화 상자 애니메이션보다 먼저 읽기를 완료하고 대신 통과하기 전에 실제 컨트롤과 화면이 안정화될 때까지 기다렸습니다. 제품 타이밍은 테스트를 위해 수정되지 않았습니다.。

이동하다 Node 54 항목, 권한、iOS 라우팅 및 연결 회귀 전달；Android APK、iOS 서명되지 않은 패키지 및 시뮬레이터 빌드 패스 모듈 경계 확인 통과。iOS 새로운 복귀 조인을 기존에 추가하세요. macOS CI 작업, 이번 라운드에는 원격이 실행되지 않습니다. CI。증거물과 설치 패키지는 다음 위치에 저장됩니다. `.tmp/notification-sources-20261028/`，제출되지 않았습니다. 이번 라운드에서는 아직 사용자의 실제 컴퓨터에서 스위치를 수락하지 않았습니다.。
