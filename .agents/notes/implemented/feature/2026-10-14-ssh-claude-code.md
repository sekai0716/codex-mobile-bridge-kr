## 네이티브 프로세스 ID

읽기 전용 검사가 설치됨 Claude Code 2.1.287，레지스트리를 찾아보세요 `procStart` 의존하다 `LC_ALL=C TZ=UTC ps -o lstart= -p <pid>` 생성하다。Linux 의 `pidDomain` ～을 위한 `darwin:<machine-id>:<pid namespace link>`，macOS ～을 위한 `darwin`。복원 전 작업 절차 확인 PID、시작 시간 및 도메인을 처리하고, 증거가 누락되거나 일치하지 않으면 거부합니다. 기존 제한 Linux SSH 호스트에 대한 읽기 전용 프로브 확인，`/etc/machine-id`、`/proc/self/ns/pid` 그리고 UTC/C `ps` 예상대로 사용할 수 있고 형식이 지정되었습니다. 이는 네이티브로 구성되지 않습니다. ## 대안

원본 기록에서는 로컬 게이트웨이 업로드 경로를 원격 파일로 참조하는 것을 명백히 금지하고 있으며 로컬을 허용하지도 않습니다. Claude 설정 또는 자격 증명이 대상에 복사됩니다. 원격 호스트의 자체 구성과 전송된 원격 파일이 실행의 기초가 됩니다. 이 기록은 다른 원격 실행 아키텍처와의 비교 프로세스를 제공하지 않으며, 문서화되지 않은 후보자 또는 거부 이유를 적지 않습니다.。

## 영향

휴대폰 선택 가능 SSH 호스트는 호스트, 구성 및 세션 ID 경계를 유지하면서 기본 세션을 계속합니다. 파일 전송에는 대상 측 개인 파일 전송이 추가됩니다. 후속 작업을 수행하려면 호스트 별칭과 구성이 변경되지 않은 상태로 유지되어야 합니다. 직접 SSH 하위 프로세스의 수명 주기는 게이트웨이 연결에 따라 다릅니다. 연결 해제 후 불확실한 쓰기는 자동으로 복원하거나 재생할 수 없습니다. 사용자는 명시적으로 계속하기 전에 기록을 확인해야 합니다. 다음 루프백 수락은 어떤 것도 대체하지 않습니다. Linux 호스트 또는 실제 유료 모델 수락。
