# Agent Note: SSH 호스트의 기본 CLI Goal

Status: implemented

## 문제

이미 가입했습니다 CLI 어댑터가 기존 인증을 통과했습니다. app-server 대리인으로 보내기 Goal RPC，하지만 Bridge 및 Web 모두에게 SSH 호스트가 거부함 Goal。이로 인해 호환 가능한 런타임을 원격으로 실행하는 기능이 숨겨집니다. CLI 검증된 작성자이므로 작동할 수 없습니다. Goal 수명주기。

## 결정

오직 SSH 채팅에 대한 인증된 실행 런타임이 기본으로 연결됩니다. CLI，그리고 동일한 데몬이 지원되는 것으로 확인되었습니다. Goal 경우에만 제공 Goal。수동적 읽기는 런타임에 참여하지 않습니다.。Goal 읽기, 쓰기 및 활성화 라운드 사용이 추가되었습니다. CLI 길; 호스트별 Bridge 데이터 디렉토리는 운영 원장을 유지 관리합니다. 데스크탑 App 유지된 SSH 아직도 채팅이 안 돼요 Goal 따르기 때문에 통제하다 IPC 아니요 Goal 작성방법. 원격 Goal 읽기는 게이트웨이 로컬로 돌아가지 않습니다. Goal 데이터베이스 또는 보조 작성자。Web 로컬 레거시 보기 동작을 유지하면서 명시적인 원격 기능 필드가 필요합니다.。

만능인 Goal 명령 흐름은 여전히 ​​예상 상태를 확인하고, 작성하기 전에 의도를 기록하고, 기본 상태를 확인하고, 전달이 불확실할 때 재생 없이 알 수 없는 상태로 유지됩니다. 활성화 생성 및 복원은 스레드의 경로를 유지하면서 기존 전송 경로를 사용합니다. provider、인증, 작업 디렉터리 및 권한 설정。

화합을 유지하라 SSH 금지는 원격 버전 차이를 방지하지만 기본 데몬 지원이 추가되는 것을 방지합니다. Goal API。～을 위한 SSH 멀티플렉싱 게이트웨이 로컬 Goal 작업자 프로세스는 잘못된 홈 디렉터리를 가리키며 보조 작성자를 생성할 수 있습니다. 오른쪽 SSH Desktop 베스팅 프로세스가 공개되었습니다 Goal，존재하지 않는 후속 쓰기 작업을 커밋합니다.。
