# Agent Note: 파일 읽기 글꼴 크기는 채팅 및 터미널과 무관합니다.

Status: implemented

## 문제

파일 텍스트와 소스 코드에 대한 통합 글꼴 크기 제어가 없습니다. 채팅 및 터미널 글꼴 크기는 파일 읽기 기본 설정을 표현할 수 없습니다.。

## 결정

파일 미리보기 도구 모음은 터미널의 감소, 값 및 증가 제어 모드를 따르며 독립적으로 저장됩니다. bridge-file-font-size，범위 6–24px，기본 14px。열려 있는 모든 텍스트 파일과 향후 텍스트 파일은 글꼴 크기를 공유합니다.；CSS 변수는 텍스트, 소스 코드 및 파일을 읽는 파일에만 적용됩니다. Markdown 코드 블록. 소스 코드 줄과 줄 번호는 여전히 동일한 글꼴 크기이며 Grid 이동 중。

태그 닫기 및 작업 공간 정리 등록 제어 해제。HTML 소스 코드에는 글꼴 크기가 표시되고, 격리된 페이지 미리 보기에는 기본값을 기준으로 한 배율 비율과 동일한 기본 설정이 표시되어 외부 레이어만 배율 조정됩니다. iframe，브라우저가 내부 뷰포트를 계산하고 샌드박스를 읽지 않도록 백분율 너비와 높이를 상속합니다. DOM、원본 텍스트 또는 메시지 계약에는 변경이 없습니다.；PDF 사진에는 ​​이 컨트롤이 표시되지 않으며 실제 크기 조정이 유지됩니다. 창문 storage 이벤트 동기화 파일 글꼴 크기, 채팅 또는 터미널 기본 설정을 읽고 쓸 수 없습니다.。

## 기존 메모 감사

기존 소스 코드 보기 메모는 독립적인 줄 번호와 정확한 사본 결정을 유지합니다. 터미널 글꼴 크기 구현은 상호 참조이며 이번에는 터미널 동작이 수정되지 않습니다. 활성 파일 메모 검색에는 전역 파일 글꼴 크기가 결정되지 않습니다.。

## 대안

- 공유 채팅 또는 터미널 글꼴 크기: 하나의 상태를 저장하지만 다른 읽기 장면이 서로 간섭합니다.。
- 사용 CSS transform 모든 파일 미리보기 확대: 사진과 HTML，하지만 텍스트가 올바르게 리플로우되지 않고 글꼴이 다음과 혼합됩니다. PDF、이미지 줌。
- 쪽으로 HTML 샌드박스의 새로운 확대/축소 통신: 페이지 미리보기를 조정할 수 있지만 독립적인 프로토콜이 추가됩니다. 외층 iframe Zoom은 기존 소스를 유지합니다.、CSP 샌드박스 경계. 수동 역방향 너비 및 높이 분할은 표시되는 프레임을 다시 줄입니다. 브라우저에서 실제 테스트를 수행한 후 원래 비율의 너비와 높이가 사용됩니다.。

## 영향

글꼴 크기를 변경하면 소스 코드 및 줄 번호의 줄 바꿈을 포함하여 텍스트가 자연스럽게 재배열됩니다.。PDF 이미지는 원래 크기 동작을 유지합니다.；HTML 미리보기에는 실제 페이지 확대/축소와 동일한 전역 기본 설정이 표시됩니다. 브라우저가 로컬 저장소를 거부하는 경우에도 이 페이지를 조정하고 다시 로드하여 기본값을 복원할 수 있습니다.。
