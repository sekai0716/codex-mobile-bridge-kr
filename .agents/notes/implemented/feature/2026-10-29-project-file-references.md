# Agent Note: 현재 프로젝트 파일 및 디렉토리 참조 재사용 워크벤치

Status: implemented

비교적 Markdown 초안 및 중간 첨부 파일 대화 상자가 해결되었습니다.[네이티브 프로젝트 첨부 파일 복구](../bug-fix/2026-10-29-native-project-attachments.md)부분 교체. 당시의 사유와 검증범위는 아래와 같습니다. 프로젝트 내의 액세스 경계와 재사용된 파일 페이지는 계속해서 유효합니다.。

2026-11-12 사용자 패스 #160 승인하다[읽기 전용 호스트 디렉터리 탐색](2026-11-12-host-file-navigation.md)，파일 페이지의 읽기 전용 보기에 대한 아래 프로젝트 제한 사항을 재정의합니다. 인용, 업로드 등을 보냅니다. Git 원래 프로젝트 범위 유지。

## 문제

사용자는 모바일 채팅에서 컴퓨터 파일과 디렉터리를 참조하고 메시지에서 파일 페이지나 미리 보기를 입력하기를 원합니다. 파일 탭, 서버 디렉터리 경계, 이미지 미리보기, 파일 메뉴가 이미 있으므로 호스트 파일 브라우저를 만들 필요가 없습니다.。

## 결정

사용자는 이 라운드를 현재 세션 항목으로만 명시적으로 제한합니다. 채팅 페이퍼클립 혜택“로컬 컴퓨터에서 업로드”및“참조 호스트 프로젝트 파일”。후자는 워크벤치 디렉터리 목록과 메타정보 인터페이스를 직접 재사용하여 콘텐츠를 다운로드하지 않고도 파일이나 현재 폴더를 선택합니다. 원본 파일 하위 페이지“메시지 인용”또한 예약되었습니다. 두 항목 모두 파일 메타 정보를 다시 읽고, 세션이 여전히 원래 세션인지 확인하고, 이스케이프된 상대를 변환합니다. Markdown 링크는 기존 초안에 추가되며 입력 영역이 확장되며 자동으로 전송되지 않습니다.。Codex、Claude 및 DSH 동일한 구성요소를 재사용합니다. 입력이 비활성화되거나 세션 전환 시 삽입되지 않음。

기본 기록의 사용자 텍스트 링크 및 Files mentioned 기본 첨부 파일 헤더는 기존 파일 참조 색인에 통합됩니다. 첨부파일 메타정보는 전체 경로를 유지하며, 이름은 경로에 따라 승인된 파일과 정확히 일치합니다. basename 추측하다. 프로젝트 내의 이름은 기존 다운로드 임계값 및 위치 지정 메뉴를 엽니다. 프로젝트 외부의 이름이나 만료된 이름을 클릭하면 짧은 프롬프트만 표시되고 내용을 읽을 수 없습니다. 사용자 링크는 프로젝트 루트의 실제 파일과 디렉터리에만 권한을 부여하며 사용할 수 없습니다. Codex visualizations 루트 또는 기호 링크는 액세스를 확장합니다. 이미지 재사용 원본 미리보기 및 확대/축소 기능。

## 대안

프로젝트 외부의 파일 참조는 더 많은 시나리오를 다루지만 추가 디렉터리 인증이 필요합니다. 사용자는 아직 이 작업을 수행하지 않기로 선택했습니다. 새로운 첨부 파일 유형을 추가하고 컴퓨터 파일 콘텐츠를 업로드하면 모델 첨부 파일 식별이 향상될 수 있지만 원래 세션 프로젝트에 이미 파일을 반복적으로 업로드하고 프로토콜을 확장하므로 이번 라운드에서는 명확한 경로 참조를 사용합니다.。

## 영향

초안은 원본 텍스트와 편집 가능한 인용문을 유지하며 사용자가 보낸 경우에만 제출됩니다. 파일 사본이 업로드되지 않으며 새 파일 권한이 생성되지 않습니다. 모든 모델이 자동으로 참조 파일을 읽는다는 보장은 없습니다. 프로젝트 상대 경로를 받습니다.。

대상 검증에는 프로젝트 파일, 디렉토리, 중국어 및 특수 문자, 디렉토리 순회 및 외부가 포함됩니다. visualizations、Symlink가 이스케이프되고 세션이 전환되며 자동으로 전송되지 않습니다. 프론트엔드 완성 1303 통해、1 항목을 건너뜁니다. 쿼드 레이아웃 브라우저 120 항목이 통과되었습니다. 백엔드 초기 실행 완료 2818 항목에는 두 개의 오래된 계약 주장이 나타났습니다: 오래된 플러그인 소스 코드 지문과 식별되지 않은 사용자 파일 링크; 수정 후 관련 56 항목이 통과됨，38 소스 코드 모드에서는 항목 플랫폼 고정 장치를 건너뜁니다.。

검색 작업 공간 위치 지정, 파일 복사 및 기본 역사적 그림 메모: 모두 여전히 독립적인 책임을 갖고 있으며 이러한 변경 사항은 재사용되지만 의사 결정을 대체하지는 않습니다. 사진 기록 읽기에 대해서는 참조 [네이티브 역사적 이미지 공유](2026-10-29-shared-native-history-images.md)。

후속 클립 보충 검증 범위에서 직접 디렉토리를 선택합니다./파일, 초안 보관, 메타 정보만 요청, 세션 전환 및 지연 응답, 기본 첨부 파일 클릭 및 다운로드 임계값. 사용자가 이전 버전을 제공함 Excel 첨부 파일은 실제로 프로젝트 외부에 있습니다. 짧은 프롬프트가 예상되며 액세스 범위를 확장하지 않습니다.。
