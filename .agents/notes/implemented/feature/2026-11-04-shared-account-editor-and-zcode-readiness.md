## 대안

복사 Codex 스타일은 모양을 빠르게 개선할 수 있지만 계속해서 모델 획득, 초안 취소 및 규칙 저장을 분기하여 실제 공유 구성요소를 추출합니다. 안정적인 레이아웃을 위해 모든 기록 기능을 사용 가능한 기능으로 직접 표시하지만 확인되지 않은 쓰기 권한이 늘어나므로 표시 기능이 실행 기능과 분리됩니다. 공식 연결이 실패하면 사용자는 원본을 수동으로 열어야 합니다.
