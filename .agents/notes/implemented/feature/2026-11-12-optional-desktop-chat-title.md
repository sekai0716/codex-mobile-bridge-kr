# Agent Note: 기본 새 채팅 선택적 이름

Status: implemented

## 문제

#161 기본적으로 채팅 이름은 비워두어야 합니다. 원래 작성된 공유 데스크톱 클라이언트 양식“새 세션”비어 있지 않은 항목이 필요합니다.，Claude 또한 어댑터는 동일한 이름의 기본값을 추가하여 원래 클라이언트가 이름을 결정하지 못하도록 합니다.。

## 결정

공유 양식 이름을 비워두고 중국어 간체 자리 표시자 프롬프트를 사용하세요.“비워두면 됩니다. Agent 자신의 이름을 지정하십시오”；명시적으로 채워진 경우에만 이름을 제출하십시오. 사용자 정의 이름을 지원하지 않는 기본 첫 번째 메시지, 모델, 프로젝트 및 액세스 기능을 유지하십시오.。Code、Cowork 더 이상 기본 이름이 없습니다.；Code 이름이 없으면 기본 사용 `generateTitleViaCli`，이름을 맞춤설정할 때 이 플래그를 전달하지 마세요.。DSH 원래는 비어 있지 않은 이름에 대해서만 호출되었습니다. rename，별도의 네이밍 프로세스를 만들 필요가 없습니다.。

## 대안

입력 상자를 지우기만 해도 어댑터가 기본 이름을 채우게 됩니다. 기본 자동 제목 모델 호출을 복제하면 비용과 또 다른 명명 프로세스가 추가되므로 이미 존재하는 기능만 사용하십시오.。
