# Agent Note: Claude 상황별 사용법 읽기

Status: implemented

## 문제

기본 레코드에는 요청별 입력 볼륨, 누적 사용량 및 자리 표시자 값일 수 있는 출력 볼륨도 포함됩니다. 상황별 표시는 이러한 측정 구경을 구별해야 합니다. 기본 창 용량이 없는 경우 모델명만으로는 백분율을 계산할 수 없습니다.。

## 결정

Claude Code CLI、SSH CLI 및 Claude Desktop 기록 롤백에는 가장 최근의 기본 루프 도우미 요청이 표시됩니다. `input_tokens + cache_creation_input_tokens + cache_read_input_tokens`。이러한 요청별 수는 가장 최근에 관찰된 모델 입력을 설명합니다. 결과 수준 `usage` 및 `modelUsage` 누적 수량이므로 현재 문맥 읽기로 사용할 수 없습니다. 어시스턴트 `output_tokens` 자리 표시자 값일 수 있으므로 제외됩니다. 토종의 `compact_boundary` 후속 사용 요청이 있을 때까지 이전 판독값이 무효화됩니다. 0은 유효한 측정입니다. 누락되거나 잘못된 금액은 알 수 없는 것으로 간주됩니다.。

32 픽셀 링은 기본 레코드가 긍정적인 컨텍스트 창 용량을 제공하는 경우에만 파란색 채우기 백분율을 표시합니다. 모델명만으로는 상한선을 입증할 수 없으며, 특히 API 호환 가능 provider。네이티브 `result.modelUsage[latestAssistantModel].contextWindow` 용량은 제공되지만 누적 token 무시된 번호。Desktop 커넥터는 결과에서 모델 ID와 컨텍스트 창 크기만 전달합니다. 가능한 경우 기존 컨텍스트 요약이 여전히 우선적으로 적용됩니다. 주입 커넥터 개정 번호는 그에 따라 변경되어 이전 렌더링 클로저가 새 필드를 자동으로 누락하는 것을 방지합니다.。

## 대안

원본 기록은 두 가지 판독 소스를 명시적으로 제외합니다. 결과 수준 누적 사용량은 가장 최근 요청의 현재 입력 볼륨을 나타낼 수 없습니다. 모델명이 증명할 수 없습니다 API 호환 가능 provider 창 용량. 보조 출력은 자리 표시자 값일 수도 있으므로 입력 판독값에 포함되지 않습니다. 이는 원본 문서에 문서화된 측정 절충 사항이며 문서화되지 않은 추가 실험이나 후보 구현을 의미하지 않습니다.。

## 영향

판독값은 마지막 실제 입력의 증거를 유지하고 캐시된 입력을 포함합니다. 신뢰할 수 있는 용량이 없으면 백분율이 표시되지 않습니다. 압축 후부터 다음 사용 이벤트 사이에는 알 수 없음이 표시되며, 누락된 값은 0으로 처리되지 않습니다.。Desktop 커넥터는 용량 필드를 전달하기 위해 개정 번호를 업데이트해야 합니다. 가능한 경우 기존 기본 다이제스트가 여전히 우선 적용됩니다.。

## 검증

Fixture 테스트는 최신 및 누적 사용량, 캐시를 다룹니다. token、측면 분기, 압축, 알 수 없는 용량 및 0 값, 로컬 적용 범위/SSH 세부 경로、Desktop 대체 및 삭제된 커넥터 필드를 로깅합니다. 브라우저 UI 테스트 범위에는 측정값이 있습니다. token 수는 있지만 용량은 없습니다. 실제 채팅이나 유료 모델 요청을 사용하지 않음。
