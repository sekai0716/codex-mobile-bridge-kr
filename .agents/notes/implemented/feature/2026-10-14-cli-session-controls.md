## 문제

이전에 집 경로 복구를 수행하여 출발지가 발생했습니다. CLI chat은 쓰기 가능하지만 여전히 모든 구성을 소스 전용으로 설정합니다. Desktop 임계값 이후。App 인수된 채팅은 소유 프로세스가 지원했던 통제력을 잃습니다. 토종의 CLI 기본적인 채팅 조작만 제공됩니다. 단순히 연결됨을 표시하는 것만으로는 필수 사항을 수용하기에 충분하지 않습니다. CLI 작업 흐름。

## 결정

모델을 결합하고 Skill 접근성이 뛰어나고 더 넓어졌습니다. Desktop 권한을 별도로 구성하세요. 확인했습니다 Desktop 프로세스에 속하는 CLI 소스 채팅, 기존 모델 재사용、Skill、계획적이며 지역적이다 Goal 작동하다. 이미 네이티브에 가입했습니다. CLI 채팅은 동일한 데몬을 사용하여 모델을 가져옵니다./Skill 목차, 선택한 설정, 협업 모드、Skill 입력 및 지원 Goal RPC。출처는 프레젠테이션 메타데이터로만 사용되며 컨트롤은 런타임 및 검증된 기능에 따라 결정됩니다. 광범위한 태그를 활성화하여 관련 없는 권한을 열거나 이름을 바꾸거나 편집할 수 없습니다./포크 또는 사이드 채팅 기능。

기본 경로가 유지됨 provider、인증 및 cwd，요청된 스레드별 설정만 수정됩니다. 수동 디렉터리 확인은 세션을 활성화하지 않습니다.。Goal 작업은 기존의 지속적인 의도 원장, 예상 상태 확인 및 알 수 없는 결과 동작을 유지합니다. 모델 회전은 명시적인 사용자에 의해서만 작동되거나 사용자에 의해 명시적으로 생성됩니다./복구 대상 프로세스가 실행됩니다.。Goal 만들다/활성화 재개는 기본 공동 작업 모드를 명시적으로 사용하므로 이전 계획 모드가 실행을 차단하는 것을 방지합니다. 선택 과목 Goal 정책 오류로 인해 베이스가 차단되지 않음 CLI 첨부된. 불확실하게 쓴 후 다시 재생하지 마십시오. 실제 연결/능력이 도착하면，UI 사용할 수 없음에서 준비됨으로 전환하고 잠시 연결이 끊어지는 동안 보류 중인 선택 사항을 유지합니다.。

## 대안

모두 비활성화 CLI 컨트롤은 어댑터 작업을 줄이지만 사용자 흐름을 만족시키지 않습니다. 모두에게 CLI 소스채팅 오픈 canConfigure，어댑터에 의해 구현되지 않은 외부 작업도 활성화됩니다. 다른 사람을 통해 Desktop/기본 계정은 일치하지 않는 모델을 제공할 수 있는 기본 디렉터리를 읽습니다. Skill；다음과 같이 추가해야합니다 CLI 작동 중 자체 성능에 따라 달라질 수 있습니다.。
