# Codex 실행 활동 묶음

## 표시 기준

설치된 공식 데스크톱 앱 26.1111.21308의 활동 분류·그룹화·명령 렌더러를 참고했다.
`app.asar`의 `NQNw`, `udV3`, `I3PO`, `NKAf` 모듈에서는 활동의 그룹화 가능 여부와 본문 경계를 구분하고, 묶음 내부의 명령은 실제 명령문과 개별 상세 출력으로 표시한다.
공식 번들 코드를 복사하거나 데스크톱 앱을 변경하지 않는다.

Bridge에서는 현재 타임라인이 제공하는 `kind`, `role`, `turnId`, `status`, 첨부 메타데이터로 표시 단위를 결정한다.
명령·파일 변경·웹 검색·도구 사용·진행 중인 자동 검토가 연속하면 같은 turn 안에서 하나로 묶고 기본으로 접는다.
항목이 하나이면 기존 독립 행을 사용한다.
본문과 진행 설명, 이미지·첨부, 거절된 작업·검토, 시스템 오류, 알 수 없는 종류는 묶음을 나누는 독립 행이다.
숨겨진 추론 요약은 그룹 경계에 영향을 주지 않는다.
명령 문자열이나 번역된 제목으로 도구 종류를 추측하지 않는다. 공식 앱의 세부 명령 분석 분류 전체를 재현하는 기능은 아니다.

## 펼침과 읽기 상태

묶음 머리글에는 포함된 종류와 활동 수를 표시하고, 진행 중인 항목이 있으면 진행 상태도 표시한다.
묶음 안의 명령은 원문 첫 줄을 한 줄로 표시하며 긴 줄은 말줄임한다.
첫 줄이 비어 있으면 기존 활동 제목을 사용하고, 명령 출력으로 대체하지 않는다.
각 명령을 펼치면 기존 상세 조회로 전체 명령과 출력을 읽는다. 묶음을 펼치는 것만으로 상세 본문을 요청하지 않는다.
이미 개별 출력을 펼쳐 둔 경우에는 접힌 묶음 안의 변경을 미리 읽지 않고, 다시 펼쳐 드러날 때 최신 출력을 읽는다.

개별 행 노드와 상세 캐시는 기존 타임라인이 유지한다.
그룹 표시 계층은 원래 순서를 유지하며, 과거 기록이 앞에 붙으면 겹치는 행이 있는 기존 그룹 노드를 재사용한다.
그룹이 나뉘어도 키가 겹치지 않으며, 기존에 펼친 목록과 개별 출력의 스크롤을 보존한다.
펼친 그룹 안에서는 개별 행으로 스크롤 기준점을 잡는다. 그룹 머리글을 누를 때는 해당 머리글을 기준으로 유지한다.
필터와 언어 전환은 그룹과 원문 명령의 펼침 상태를 보존하고, 새 타임라인에서는 상태를 초기화한다.

## 범위와 검증

공통 웹 활동 도우미, Codex 타임라인, 기존 스타일 및 한국어·영어·중국어 언어팩을 변경한다.
세션 시작·재개, 전송·승인, 원본 세션 소유권, 인증·권한, 백엔드 프로토콜을 변경하지 않는다.
Android·iOS 네이티브 소스 변경이나 APK 재빌드는 필요하지 않다.

`tests/activity-groups.test.cjs`는 종류·turn·본문 경계, 이미지·거절·오류 경계, 명령 첫 줄의 원문 보존을 확인한다.
`runChatActivityGroupChecks`는 실제 타임라인과 CSS에서 지연 조회, 실시간 갱신, 과거 기록 추가, 그룹 분할, 개별 출력 스크롤, 필터·세 언어 전환, 320px 한 줄 표시를 확인한다.
기존 채팅 읽기 상태 검사도 함께 실행한다. 실제 Android WebView 조작 검증과 브라우저 픽스처 검증은 구분한다.
