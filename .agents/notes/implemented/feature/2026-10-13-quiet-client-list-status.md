# Agent Note: Claude 및 DSH 목록 상태는 주의가 필요한 결과만 표시합니다.

Status: implemented

## 문제

폴링이 성공할 때마다 클라이언트 목록이 표시됩니다.“데스크톱이 연결됨”，이미 캐시된 세션이 있는 경우 반복적으로 표시됩니다.“채팅 읽기”。이 두 가지 정상 상태는 목록 공간을 차지하지만 사용자에게 새로운 작업 정보를 제공하지 않습니다.。

## 결정

세션을 통한 일반적인 목록 읽기가 완료되면 목록 상태가 지워집니다. 캐시된 세션이 있으면 다시 읽을 때 대기 중인 복사본이 표시되지 않습니다. 캐시가 없는 첫 번째 읽기에서는 여전히 대기 상태가 표시됩니다. 빈 목록에는 채팅 메시지가 표시되지 않습니다. 연결 초기화, 연결 끊김, 실패 및 실행 가능한 재시도 프롬프트는 기존 연결 상태 프로세스에 의해 계속 표시됩니다.。

## 대안

예약하다“데스크톱이 연결됨”글꼴 크기를 줄이는 것만으로도 연결 확인이 계속 제공되지만 모든 성공적인 폴링 후에도 계속 유지되며 실제 예외가 더 눈에 띄지 않습니다.。

## 영향

목록은 더 조용해지고, 빈 목록과 조인 예외는 여전히 명확하게 설명됩니다. 성공적인 연결 자체는 더 이상 목록의 영구 복사본이 아닙니다. 연결 상태는 여전히 클라이언트에서 관리되며 세션 세부 정보는 별도로 표시됩니다. 데스크톱 세션 UI 회귀에는 정상, 빈 목록, 실패 및 초기화 상태가 포함됩니다.。
