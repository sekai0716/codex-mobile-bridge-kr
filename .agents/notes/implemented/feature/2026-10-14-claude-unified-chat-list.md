# Agent Note: 통일된 Claude 채팅 목록

Status: implemented

## 문제

분리된 Code、Cowork、CLI 그룹화하면 시간별로 탐색이 중단됩니다. 또한 사용자는 시간순을 잃지 않고 혼합 목록을 신속하게 필터링해야 합니다.。

## 결정

기본적으로 동일한 최근 목록에 모두 표시됩니다. Claude 채팅 유형. 읽을 수 있는 전체 목록에 두 개 이상의 유형이 있는 경우 해당 유형의 실제 발생 항목만 표시됩니다. All/Code/Cowork/CLI 선택기를 사용하여 각 제목 옆과 원래 날짜 위에 컴팩트 태그를 배치하세요. 선택기는 시간순 목록 내에서 필터링합니다. 검색, 아카이브 가시성, 항목 그룹화, 활동 표시 및 선택 동작은 계속 사용할 수 있습니다. 단일 유형 목록 숨겨진 선택기. 채팅 유형 선택을 독립적으로 관리하기 위한 대화 상자 만들기。

공유 대화 목록은 동일한 초를 밀리초 단위로 변환하여 날짜를 정렬하고 표시합니다.。Desktop 활동 타임스탬프는 밀리초, 로컬 및 SSH CLI 역사적 사용법 Unix 초; 원시 숫자를 직접 비교하면 CLI 세션 순위가 더 오래됨 Desktop 세션 후. 변환은 목록 표시 계층에 속하며 기존 백엔드 타임스탬프와 소비자 계약을 유지합니다.。

## 대안

축소 가능한 유형 그룹화로 인해 시간별 탐색 활동이 더 어려워집니다. 선택적 선택기는 유형별로 그룹화하지 않고 혼합 목록을 필터링할 수 있습니다. 항목 그룹화는 여전히 명시적인 표시 선택이며 여러 유형에 걸쳐 항목별로 그룹화될 수 있습니다.。

## 영향

선택한 유형의 프레스 provider 구하다; 유형이 전체 목록에서 사라지면 재설정됩니다. All。검색 및 아카이브 가시성은 선택기 표시 여부를 결정하지 않습니다. 기존 프로젝트 축소 기본 설정이 프로젝트 그룹화에 계속 적용됩니다.。DOM 시간별 테스트 커버리지 혼합, 적응형 필터링, 아카이빙/검색, 그룹 항목 및 provider 비녀장; 통합 시 검증된 반응형 외관。

혼합 시간 단위 DOM 회귀는 전역 순서를 확인하고 표시됩니다. CLI 유형, 검색, 프로젝트별로 필터링한 후 날짜, 순서입니다. 실제 실행했다고 주장하지 않습니다. Claude Desktop 또는 SSH 통합。
