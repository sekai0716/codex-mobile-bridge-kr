# Agent Note: ZCode 공식 계정에는 모델별로 구분된 일일 할당량이 표시됩니다.

Status: implemented

기본 제어 채널에 대한 액세스가 설정되었습니다. 누르다[다음과 공유된 계정 ZCode 상태 기록](2026-11-04-shared-account-editor-and-zcode-readiness.md)계정에 바인딩된 기본 한도 쿼리를 사용하세요. 이 문서의 로그 수신은 계속해서 엄격한 귀속 폴백이며 시간 액세스 제어는 완화되지 않습니다.。

## 문제

ZCode 무료 계정 GLM-5.3 및 GLM-5.3-Flash 다양한 일일 할당량을 할당합니다. 기존 계정 페이지에서는 할당량 창을 표시할 수 있지만 ZCode 어댑터가 확인할 업스트림 값을 제공하지 않았습니다.。

## 결정

게이트웨이는 요청 시 현재 로컬 머신을 읽습니다. ZCode 기존 App 공식 청구 영수증을 획득하고 공식 문의 시간을 표시합니다. 현지 네이티브만 허용 host 공식 성공 쿼리, 구독별, 모델별, 일일별 entitlement 유효 기간과 남은 기간 및 전체 기간과 관련된 token。계정 페이지는 기존 신용 카드, 남은 진행 상황 및 새로 고침 입구를 공유합니다. 수동 새로 고침은 기본 영수증을 다시 확인합니다. 로그인 변경 후 이전 캐시를 삭제합니다. 귀속 영수증이 없으면 데이터가 누락됩니다.。

영수증 자체에는 사용자가 없습니다. ID。어댑터는 단일 공식 로그인 소스를 확인할 수 있는 경우에만 작동합니다. 공식 자격 증명 파일의 최신 변경 시간을 기준으로 마지막 로그인에 속할 수 있는 영수증은 제외됩니다. 동일 세대 로그인은 읽기 전후에 검토되며, 만료되었거나 확인할 수 없는 데이터는 표시되지 않습니다. 게이트웨이는 원본을 해독하지 않습니다. App 로그인 자료. 이 기능은 세션 디버그 포트와 관련이 없습니다.。

## 대안

원본을 보자 App 사적인 host 서비스는 즉시 공식에 다시 쿼리하여 최신 판독값을 얻을 수 있지만 정상적인 시작은 ZCode 이 항목은 로컬 외부 클라이언트에 대해 열리지 않습니다. 세션 통계를 사용하여 남은 크레딧을 추정하면 다른 장치의 소비가 반영되지 않으며 독립 모델 크레딧 버킷을 정확하게 처리할 수 없습니다.。

## 영향

Mac 기존 App 무료 계정 영수증은 이 기계의 판독 결과와 일치합니다.，GLM-5.3 및 Flash 두 할당량 버킷은 독립적으로 유지됩니다. 사용 사례에는 잔액 제로, 로그인 전환, 오류가 포함됩니다. host、유효기간, 링크 경계, 공유 계정 페이지가 표시됩니다. 검사는 모델 요청을 생성하지 않습니다. 원래의 App 게이트웨이는 쿼리되지 않았거나, 당일 영수증이 만료되었거나, 로그 읽기 범위를 벗어난 경우 현재 값을 제공할 수 없습니다. 이전에[계정 현황 및 전환](2026-10-31-zcode-shared-capabilities.md)권한 경계。
