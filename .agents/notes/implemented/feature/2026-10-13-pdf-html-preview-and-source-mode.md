- 페이지 넘김 버튼을 사용하여 단일 페이지를 유지하면 렌더링 리소스가 절약되지만 휴대폰 읽기는 반복적으로 클릭해야 하고 높이를 차지합니다. 계속해서 읽을 수 있도록 보이는 페이지만 표시하도록 변경하고 와이드스크린 버튼은 유지합니다.。

- 전체 복사본을 캐시하세요. PDF 재생 중에 다시 그리기를 줄일 수 있지만 페이지 수에 따라 메모리가 늘어납니다. 총 픽셀 예산 내에서 제한된 인접 페이지 캐싱을 사용합니다.。
