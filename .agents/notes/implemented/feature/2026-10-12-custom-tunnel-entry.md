# Agent Note: 사용자가 제작하고 침투 가능 HTTPS 접근 입구

Status: implemented

## 문제

사용자가 침투를 구성한 후에는 공개 주소만 등록하면 됩니다. 기존의 NAS 이 모드는 LAN을 강제로 열고 비루프백 업스트림을 채웁니다. 서버 모드에는 다음이 포함됩니다. SSH 구성이 루프백 서비스로 전달하는 데 적합하지 않습니다.。

## 결정

`accessMode=external` 사용자 관리를 나타냅니다. HTTPS 입장, 요청만 가능 `publicUrl`。데스크탑의 기본 양식에는 해당 항목이 표시됩니다. HTTP 루프백 대상; 고급 위치 옵션이 기존으로 전환됨 `nas` 모드에는 여전히 LAN과 동일한 포트의 비루프백 업스트림이 필요합니다. 오래된 NAS 구성이 루프백 구성으로 마이그레이션되지 않으며 네트워크 카드가 자동으로 열리지 않습니다. 연결 방법 영역은 기본적으로 확장되며 기존 연결은 축소된 상태로 유지됩니다.。

고정된 진입 감지 결과는 해당 연결 카드 및 요약에 유지되며, 성공하면 이전 실패를 덮어씁니다. 자동 새로 고침 및 언어 전환은 최신 결과를 유지합니다. 연결 구성이나 게이트웨이 인스턴스가 변경되면 이전 결과가 지워집니다. 이전 요청이 늦게 도착하면 새 대상을 덮어쓰지 않습니다. 반복해서 클릭하면 기존 사용중 잠금이 상속됩니다.。

사용자 관리 침투 프로세스 및 계정、DNS 그리고 인증서. 게이트웨이가 설치되지 않거나 시작되지 않습니다. frpc，외부 역방향 프록시는 호스팅되지 않습니다. 입구는 신뢰할 수 있음을 받아들입니다. HTTPS 루트 주소 및 선택적 포트, 하위 경로, 자격 증명, 쿼리 매개변수 또는 조각은 허용되지 않습니다. 읽기 전용 감지 `/api/auth`，로그인 자격 증명을 가지고 다니지 말고, 리디렉션을 따르지 말고, 우회하지 마십시오. TLS 확인하다; 공개하다 `instanceId` 현재 프로세스로 전달되는지 확인하는 데에만 사용됩니다.。

외부 HTTPS 입구 조인 기존 Host/Origin 컬렉션, 페어링 주소, 알림 주소가 허용됩니다. 제공요청 Origin , 요청은 다음과 같아야 합니다. Host 해당 프로토콜과 주소는 정확히 동일하며 허용되는 두 항목을 교차하여 사용할 수 없습니다. 요청을 계속하려면 요청을 작성하세요. Origin、유효한 로그인 및 CSRF。소켓을 닫을 때 명시적으로 전송된 응답 거부 `Connection: close`，클라이언트 또는 업스트림 프록시가 닫힌 연결을 재사용하지 못하도록 방지합니다. 로컬 웹 페이지 액세스가 꺼져 있어도 루프백은 여전히 ​​공용 네트워크를 허용합니다. Host 구성된 HTTPS 앞으로, 일반 로컬 웹 페이지 입구를 다시 열지 마십시오.。

저장된 주소에 따라 기본 바인딩이 계속 복원되며 기존 바인딩만 유효한 것으로 확인됩니다. Cookie，리디렉션을 비활성화합니다. 이전 바인딩을 기반으로 교차 주소 검색이 계속됩니다. Cookie 의 HMAC 공개 프로세스 ID에 대해 자격 증명을 마이그레이션할 수 없다는 증거입니다. 포털 비활성화는 공유 세션 테이블에서 여전히 수행되는 장치 취소와 동일하지 않습니다.。

## 기존 메모 감사

현지 검토에서 같은 이름의 제안이 이 기록으로 이어집니다.。[바인딩 복구](2026-10-13-native-binding-recovery.md)및 [Cookie 격리](../bug-fix/2026-10-13-gateway-cookie-namespace.md)부분적으로 중복되어 기본 보안 저장소와 지속적인 명명 결정을 각각 유지합니다. 동일한 시스템에 대한 다른 자체 구축 침투 구성 결정은 발견되지 않았습니다. 상호 참조 [DSH Remote Web UI](https://github.com/DamonKoy/dsh-web-ui/tree/main/packages/dsh-remote-web-ui) 의 `publicBaseUrl`，인증 규칙이나 소스 코드를 재사용하지 마십시오.。

## 대안

- 재사용 NAS 양식에는 저장 모드가 하나 줄어들 수 있지만 필수입니다. LAN 루프백이 아닌 업스트림은 동일 시스템 침투를 잘못 표현하므로 계속 유지하십시오. NAS 교차 장치 의미 체계 및 통합 인터페이스로 제공。
- 자동 설치 및 관리 frpc 단계를 더 줄일 수 있지만 프로세스, 계정 및 업데이트 책임은 사용자가 구성한 침투 범위를 넘어 확장됩니다.。
- 안심하다 HTTP、인증서 또는 Origin 구성 오류를 줄일 수 있지만 장기 자격 증명의 노출이 확대되므로 기존 경계를 유지하고 오류 메시지가 개선됩니다.。

## 영향

사용자 구성에서는 루프백 수신만 신뢰할 수 있습니다. HTTPS 수신 액세스; 연결 가능성은 외부 침투 및 인증서에 따라 달라집니다. 소스 코드 테스트 및 격리 TLS 대리 확인은 별도로 기록됩니다. [VERIFICATION.md](../../../../VERIFICATION.md)，이는 실제 제3자 노드, 휴대폰 셀룰러 네트워크 및 다양한 운영 체제의 수용을 대체할 수 없습니다. 전경 채팅 스트림, 파일 및 터미널을 사용하려면 상담원이 긴 연결과 데이터 전송을 유지해야 하며 홈페이지를 사용하지 않아야 합니다. 200 사용 가능한 모든 기능을 나타냅니다.。
