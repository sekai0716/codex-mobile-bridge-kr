# Agent Note: 통합 로컬 Codex 계정

Status: implemented

## 문제

Desktop 및 CLI 공유 저장됨 Codex 하지만 두 개의 목록과 선택적인 확인 확인란은 별도의 신원인 것처럼 보입니다.。

## 결정

UI 저장 목록을 표시하고 알림 전에 독립적으로 배치 API 편집자。Desktop 전환 후 항상 확인 CLI 설정。Desktop 기존 보호 사용 중지 CLI 거래가 시작되지 않았습니다. Desktop。공식 로그인은 여전히 ​​컴퓨터에서만 이루어집니다.；Claude 원격 환경으로 현재 범위를 유지。

## 대안

두 개의 목록을 유지하면 기존 컨트롤이 유지되지만 공유 계정 홈 디렉터리가 잘못 표시됩니다. 숨다 CLI 유지하지 않고 목록을 작성 API 편집기 및 모델 감지, 유용한 기능이 손실됩니다.。

## 영향

Desktop 및 CLI 다양한 성공 결과가 보고될 수 있으며 일부 성공 피드백은 유지되어야 합니다.。[이전에는 선택적 동기화 결정](../../implemented/feature/2026-10-14-local-cli-account-sync.md)부분적인 중복은 역사적인 이유로 유지됩니다. 활성 계정 동기화 및 WSL 이 좁은 지역의 메모 Codex 결정 이후에도 적용 가능。

대상 계정 UI、CLI 편집자、WSL 범위 및 백엔드 계정/동기식/이 동작을 확인하려면 픽스쳐에 액세스하고 개인 계정 전환이나 모델 요청을 수행하지 마십시오.。

[계정 표시 및 플랫폼 범위 수정](../bug-fix/2026-10-26-account-ui-and-platform-scope.md)지원되지 않는 게이트웨이에서 대체 데스크톱 편집기 배치 및 건너뛰기 WSL 초기화; 계정 목록 및 엔드포인트 ID 계약 유지。

[관리됨 CLI 계정 동기화](../bug-fix/2026-11-10-managed-cli-auth-sync.md)보충제는 다음과 동일합니다. provider API 조건에 따른 라이브 서비스 인증 캐시 동기화 및 알 수 없는 수신 확인; 다른 유지 관리 경로와 함께 유지되는 단일 계정 목록。
