# Agent Note: 명확한 확인 후 수정됨 DSH 삭제된 액세스 디렉터리

Status: implemented

## 문제

Windows 오래된 Test 의 DSH 구성에는 여전히 게이트웨이 플러그인이 포함되어 있지만 참조된 이전 빌드 디렉터리와 액세스 파일은 삭제되었습니다. 구성은 원래 디렉터리의 확인 가능한 소유권을 유지하지 않습니다. 평범한 discover_existing 그것은 거부되어야 합니다. 스캔을 반복하거나 정상적으로 종료해도 누락된 액세스가 다시 설정되지 않습니다. 오직 기반으로 marker 플러그인이 신뢰할 수 있다고 가정하면 외관과 소유권이 혼동됩니다.。

## 결정

사용자가 클릭할 때만“복원 및 다시 연결”、선택된 Harness 데이터 디렉토리와 설치 ID가 결정되고 프로세스가 없는 경우 독립적인 구성 복구 확인을 제공합니다. 고유하고 완전한 인서트, 고정 플러그인만 허용됩니다. ID、엄격한 분야, 지역 file URI、같은 디렉토리에 mobile-host.mjs/connection.json、desktop-sessions/deepseek 접미사와 전체 이전 디렉토리가 실제로 누락되었습니다. 링크, 재분석 지점, 액세스 실패, 중복 또는 추가 플러그인 필드, 여전히 존재하는 이전 디렉터리 및 알 수 없는 새 디렉터리는 거부됩니다.。

미리보기에는 이전 디렉터리와 영구 대상 디렉터리가 표시됩니다. 확인은 분명히 전체 구성을 백업하고 실패한 삽입물을 교체하는 것을 의미하지만 이전 플러그인의 소유권을 인수한다는 의미는 아닙니다. 바인딩 소스 확인 patch 바이트 다이제스트, 대상으로 준비된 파일 다이제스트 및 원본 프로세스 스냅샷 추가 확인 플래그 없이는 수정되지 않습니다. 새로운 token、엔드포인트 및 installation 레코드는 기존 프로토콜에 따라 생성되며 전체 백업은 지속 가능한 대상 디렉터리에 개인 권한으로 보관됩니다. 원래 삽입된 문자 범위만 바꾸고 다른 텍스트와 줄 바꿈은 유지합니다. 실행하지 않는다 YAML，이전 경로를 삭제하거나 계정이나 채팅을 변경하지 마세요.。

쓰기 전에 프로세스가 종료되었는지, 이전 디렉터리가 없는지, 그리고 patch 변하지 않은。token 수정 전 소모되며, 실패 시 자동으로 재생되지 않습니다. 완전히 준비되었으며 기본 레코드가 현재 대상 및 데이터 디렉터리와 일치하는 파일은 새로운 미리 보기를 통해 계속할 수 있습니다. 그들은 회전되지 않습니다 token。부분 준비 실패, 백업 유지 및 암시적 채택 거부, 컴퓨터에서 확인해야 함。manager 다시 시작하기 전에 새 액세스 디렉터리를 저장하세요. 시작에 실패하더라도 복원된 연결 파일을 찾을 수 있습니다.。

실행 중이지만 사용할 수 없는 플러그인이 있는 클라이언트는 정상적으로 복원할 수 없습니다. 먼저 정상적으로 종료하거나 기존의 명시적 강제 확인을 사용합니다. 하지 마십시오 unknown 언제 idle，추가적인 배경 살해는 없습니다.。

## 대안

자동으로 삭제 marker 재검색 후 작업 빈도는 낮지만 알 수 없는 소스 구성은 사용자 검토 없이 덮어쓰여집니다. 사용자만 수동으로 편집할 수 있도록 허용 YAML 보수적으로 복원은 가능하지만 기존을 완성할 수는 없음“복원 및 다시 연결”입구. 이전 임시 빌드 디렉터리를 부활시키면 이동식 설치 디렉터리에서 실행 중인 종속 항목이 계속 번들화되므로 이를 현재 게이트웨이 영구 디렉터리로 이동합니다.。

## 영향

중지된 잘못된 액세스는 동일한 관리 페이지, 기타 구성 바이트 및 기본 계정을 통해 복원할 수 있습니다./역사 보존. 상태를 입증할 수 없거나 아직 진행 중인 경우 계속 거부합니다. 일반 종료 경로가 없는 버전에서는 여전히 사용자가 종료 방법을 선택해야 합니다. 파일 및 프로세스 확인은 작성 전 즉석 확인이며 외부 편집자 또는 기타 프로세스의 모든 동시 변경 사항을 잠글 수 있다고 주장하지 않습니다.。

## 검증

9 격리 파일/상태 확인에는 성공적인 백업이 포함됩니다. CRLF 보관, 추가 확인, 활동 또는 신규 프로세스, 구성 변경, 중복/추가 필드, 기존 디렉터리가 여전히 존재함, 알 수 없는 대상, 심볼릭 링크, 교체 실패 후 새 미리 보기, 준비 중 편집, 대상 자격 증명 변경 등이 있습니다. 원래 복구 모듈 31 개、manager 4 아이템 방향과 UI 5 항목이 통과되었습니다. true 호출되지 않음 DSH、모델 또는 유료 서비스. 목표 Windows 실제 구성 복구 및 최종 설치 패키지는 여전히 독립적으로 승인되어야 하며 시뮬레이션 프로세스 스냅샷은 실제 시스템으로 종료될 수 없습니다.。
