# Agent Note: 에서 Claude 전면 콘솔에서 직접 제출

Status: implemented

## 문제

전경 초기화는 Enter 긴 콘솔 초안을 명시적으로 탐색하여 접근성 텍스트를 캡처합니다. 소스코드는 로컬에서 생성되었지만 Chromium 통해 AX/UIA 뷰포트 조각만 노출될 수 있습니다. 따라서 전체 다시 읽기는 일반 연결 경로에서 커서를 반복적으로 이동하게 만들고 제한된 접근성 가시성을 불완전한 입력으로 잘못 해석합니다.。

## 결정

명시적 프런트엔드 이니셜라이저는 준비된 소스 코드를 한 번 작성하고 이를 전달합니다. Enter 한 번 실행되지 않음 Home、Down、End 또는 내비게이션을 선택하세요. 선택한 앱 ID, 창, 도구 설명 포커스, 취소 및 기존 초안 보호를 유지합니다. 제한된 비탐색 읽기 확인 편집기에 이 입력이 표시되었습니다.：macOS 정확한 값을 허용하거나 최소한 32 UTF-16 안정적으로 일치하는 단위 조각；Windows 정확한 문서를 즉시 수락하거나 짧은 안정화 기간 후에 호환 가능하고 고유하게 배치된 조각을 수락합니다./가상화 격차. 이러한 검사는 입력이 관찰되었음을 증명하지만 소스 코드가 완전하다는 것을 증명하지는 않습니다.。macOS 1초 대기 시간 읽기 허용 오차 예약；Windows 대부분은 기다려 1.2 초, 로컬 뷰 안정성 기간은 250 ms。

Enter 누르다/해제 후 프런트엔드 도우미 프로그램은 제출되었음을 보고하고 기존 소유권 프로세스는 현재 세대의 서명된 영수증을 기다립니다.。Mac 즉각적인 초점 변경이나 접근할 수 없는 빈 툴팁을 디스패치 실패로 해석하지 마세요.。Windows 핀 제거 700 ms 제출 후 기다리세요. 누락된 영수증은 연결되지 않으며 자동으로 다시 제출되지 않습니다. 신뢰, 소유권 양도, 활성 작업 및 요청 재생 규칙은 변경되지 않습니다. 무인 Windows 백엔드 경로는 엄격한 전체 문서 확인을 유지합니다.。

Mac Unicode 입력 폴백은 각 이벤트에 대한 포커스 확인을 유지하고 모든 청크가 분할된 후 한 번만 동일한 준비 확인을 수행합니다. 128 각 단위에는 완전한 것이 필요합니다. AX 다시 읽어봐。

## 대안

이전에 [Mac 미리 다시 읽어보세요](2026-10-16-claude-early-console-readback.md)및 [Windows 적응형 수집기](2026-10-16-claude-adaptive-console-readback-windows.md)콘솔을 명확하게 탐색하면서 전체 커밋 전 텍스트 동일성을 유지합니다. 이 결정은 프런트엔드 인수 전략을 대체합니다. 거부된 선택된 텍스트 및 동적 로더 실험에는 여전히 값이 있습니다: 선택된 텍스트 API 지역 값도 반환하려면 다음을 사용하세요. eval 로더는 Claude CSP 거부하다. 클립보드 액세스를 도입하지 않습니다.、CSP 변경 사항, 새로운 권한 또는 동적 로더。

오직 SetValue 성공은 성공적인 연결로 간주됩니다. 거부됨: 플랫폼 할당이 스크립트 실행을 증명하지 않습니다. 기존의 서명된 연결 핸드셰이크가 최종 기반입니다. 탐색 대기 시간을 단축하는 것만으로 사용자가 보고한 성능 저하가 계속 유지됩니다.。

## 영향

일반 전경 제출 시 더 이상 전체 초안이 스크롤되지 않습니다. 부분적으로 표시되는 읽기는 모든 바이트가 존재함을 증명할 수 없으므로 여전히 Bridge 계약이 성공적으로 이행된 것으로 확인되었습니다. 입력 뷰를 읽을 수 없거나 관련성이 없으면 다음에서 중지하세요. Enter 전에; 하트비트가 없으면 연결이 성공하기 전에 중지됩니다. 네이티브 테스트 커버리지 스니펫/공백/보기 변경, 오류 내용, 발송 전 취소 및 초점 변경, 단일 Enter 그리고 재생을 금지합니다. 현실 Test 증거 및 설치 패키지 결과는 다음 문서에 기록됩니다. `.tmp/claude-direct-submit-20261016/acceptance.md`；자격 증명이나 실제 채팅 텍스트가 제출되지 않았습니다.。
