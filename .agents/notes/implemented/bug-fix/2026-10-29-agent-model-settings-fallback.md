# Agent Note: 기본 모델 디렉터리 ID 및 수동 설정

Status: implemented

## 문제

Claude Code/Cowork 디렉토리가 비어 있거나, 기본 디렉토리가 선택을 허용하지 않거나, 캐시 쓰기가 실패하면 모델 팝업 창이 누락됩니다. `cache.identity`，프런트엔드는 메타데이터가 부족한 것을 계정 전환으로 착각했습니다. 시간 노드 업데이트 CSS 수업명 `muted` 텍스트로 처리하세요. 디렉토리 목록은 설정 기능의 유일한 증거로도 사용되므로 기본 모델 설정 인터페이스와 연결된 세션이 모델을 수동으로 수정하거나 강도에 대해 생각하는 것이 불가능합니다.。

## 결정

Claude 네이티브 히스토리 디렉토리 및 현재 API 디렉터리가 병합되면 소스는 하나씩 유지되며 병합된 결과에 따라 프롬프트가 생성됩니다. 업스트림과 동일 ID 확인 증거는 역사적 출처보다 우선하며 기본 사고 강도 메타데이터는 그대로 유지됩니다. 데스크톱 구성은 업스트림 반환을 가장하지 않습니다. 안정적인 캐시 저장 `source` 및 `modelSourcesVersion`。이전 캐시를 읽을 때 동일한 계정의 기존 모델 캐시만 재사용하여 소스를 보완합니다. 복구 프롬프트에 대한 추가 네트워크 요청이 이루어지지 않고 목록이 지워지지 않으며 원래 캐시 시간이 수정되지 않습니다. 증거가 없는 오래된 항목은 표시됩니다. `cached-unverified`；공식계좌는 빌려주지 않습니다 API 목차. 새로 고침이 성공하면 자연스럽게 새 형식으로 다시 작성됩니다. 실제로 역사적 모델만 있는 경우 역사적 프롬프트는 여전히 유지되고 혼합 목록에서는 역사적 부분만 확인하면 된다는 메시지가 명확하게 표시됩니다.。

모델 카탈로그 응답은 항상 읽기 전후에 확인된 불투명한 ID를 전달합니다. 성공적으로 지속되는지 여부와 ID가 일치하는지 여부는 별도로 표시됩니다. 프런트 엔드는 실제 ID가 일치하지 않는 디렉터리를 계속 거부하며 계정 확인을 제거해도 빈 목록을 수정할 수 없습니다. 휴대시 팝업창 수동 설정 `modelCatalogIdentity`，게이트웨이는 기존 쓰기 보호 내에서 기본 요청을 발송하기 전에 다시 확인합니다. 디렉터리가 아직 대기 중인 동안 빠른 수동 채우기는 계정 전환 보호를 우회할 수 없습니다.。

Claude Desktop 세션 디렉터리 병합이 현재 진행 중입니다. API 계정 모델 결과, 기존 ID 캐시 재사용 및 계정 관리 경로 새로 고침 네이티브 같은 ID 기본적 사고 강도를 보존하기 위해 메타데이터가 우선시됩니다. 공식 계정은 혼합되지 않습니다 API 계정 모델，CLI/WSL/SSH 이 기계를 빌려주지 마세요 Desktop 계정. 검색 실패는 기본 목록을 유지하고, 수동 입력은 업스트림 읽기가 완료될 때까지 기다리지 않으며, 늦은 결과는 사용자가 편집한 필드를 유지합니다.。

`manualModels` 및 `manualEffort` 독립형 보고 기본 설정 기능. 검증된 실시간 기능은 이전 캐시의 누락되거나 만료된 수동 기능 필드보다 우선합니다. 목록은 수동 입력과 팝업 창을 공유하며, 직접 입력한 값을 다음과 같이 위장하지 않습니다.“업스트림에서 제공”。Claude Desktop 사용 `setModel`/`setEffort`，그후 `getSession` 실제값 확인；CLI 다음과 함께 기존 제어 요청을 사용합니다. `get_settings` 확인하다. 수동 모델 요청 건너뛰기 선택사항 Desktop 모델 디렉터리를 읽지만 세션 속성, 기본 인터페이스 기능 또는 결과 확인은 건너뛰지 않습니다. 알 수 없는 쓰기는 확인을 위해 기존 영수증으로 계속 표시되며 자동으로 재생되지 않습니다.。

DSH 계정 페이지와 세션 페이지 모두 동일한 기본 내용을 읽습니다. `sessionController.modelCatalog()`，계정 페이지는 구성된 자격 증명 참조로만 공개 소스를 필터링하고 다른 모델 목록은 유지하지 않습니다. 명시적 손으로 채운 모델을 건너뛰었습니다. Bridge 선택적 디렉터리 프리페치（기본 선택 인터페이스는 여전히 가용성을 확인함）。

DSH 프로토콜 작업을 추가하거나 회선 프로토콜 버전을 변경하지 않고 기능 필드를 추가합니다. 이전 플러그인은 디스크 패키지가 업데이트되었기 때문에 수동 입력이 표시되지 않으며, 실행 중인 액세스 플러그인을 업그레이드하라는 팝업 창이 표시됩니다. 손으로 작성 `provider/model` 생각의 강도는 여전히 `sessionController.selectModel`，네이티브 `selected` 요청과 일치해야 합니다. 공식 기본 인터페이스에서는 모델이 이 인터페이스에 속해야 합니다. provider 사용 가능한 디렉토리; 세션 이벤트나 계정 구성을 직접 수정하여 이 제약 조건을 우회하지 마십시오. 디렉터리가 만료된 경우 수동으로 입력을 시도할 수 있지만 기본적으로 지원되지 않는 모델이나 강점은 여전히 ​​오류를 반환합니다.。

## 대안

기록 프롬프트를 직접 삭제하면 오해의 소지가 즉시 제거될 수 있지만 실제로 기록 데이터만 있는 상황도 숨겨집니다. 이번에는 모델 소스를 기반으로 프롬프트가 다시 계산됩니다. 모든 캐시를 지우면 강제로 다시 가져올 수 있지만 오프라인 목록이 손실되고 대기 시간이 늘어나므로 원래 시간을 유지하는 읽기 호환성이 사용됩니다.。

프런트 엔드 신원 판단을 완화해야만 오류 메시지를 제거할 수 있지만 실제 계정 전환 보호 기능은 상실됩니다. 내장된 일반 모델과 사고력 목록을 강제하면 팝업창이 채워지지만, 존재하지 않는 능력이 사용 가능한 것으로 표시됩니다. 오른쪽 DSH 모델 선택 이벤트를 직접 작성하면 기본 디렉터리 제한을 우회할 수 있지만 타사 클라이언트 자체의 선택 규칙이 변경됩니다. 이번에는 공식적인 검증이 유지되며 사용자에게 실패가 명확하게 표시됩니다.。
