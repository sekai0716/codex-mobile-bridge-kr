# Agent Note: 항상 대화의 출처를 표시하세요.

Status: implemented

## 문제

만 포함 CLI 채팅 목록은 다음과 같습니다. Desktop 소스가 하나만 사용 가능한 경우 소스 탭이 사라지기 때문에 채팅이 발생합니다. 사용자는 어떤 런타임이 채팅을 계속할지 알 수 없습니다.。

## 결정

각 세션 행에는 날짜 위에 소스가 표시됩니다.：Codex APP/CLI/IDE、Claude Code/Cowork/CLI、DeepSeek Harness APP。알 수 없는 소스는 기존 현지화를 사용합니다.“다른 소스”상표. 소스 선택기는 사용 가능한 유형이 여러 개인 경우에만 표시됩니다. 가시성은 인라인 ID와 무관합니다.。

이 결정은 단지[통일된 Claude 채팅 목록](../feature/2026-10-14-claude-unified-chat-list.md)단일 유형에 대한 행 레이블을 표시하지 않는 규칙입니다. 연대순 순서, 필터링, 선택 및 프로젝트 그룹화는 여전히 이 메모를 따릅니다.。

## 대안

혼합 목록에 레이블만 표시하면 시각적 공간이 약간 절약되지만 단일 소스 사용자는 런타임을 식별할 수 없습니다. 필터링 옵션이 없을 때 각 목록에 선택기를 표시하도록 요구하면 컨트롤이 추가됩니다.。

## 영향 및 검증

모든 소스는 기존의 2열 행 레이아웃과 슬라이딩 안정성 규칙을 사용합니다.。DOM 단일 소스의 회귀 범위 Codex/Claude/DSH、오래된 Desktop 괜찮고 출처를 알 수 없습니다. 필터링 옵션이 없을 때 소스 선택기는 숨겨진 상태로 유지됩니다.。
