# Agent Note: 다시 덮다 Claude CLI 합성 이벤트에 대한 모델 태그 무시

Status: implemented

## 문제

Claude Code 절약할 수 있다 `message.model` ～을 위한 `<synthetic>` 어시스턴트 이벤트. 이 값은 선택적인 모델이 아닙니다. 현지의 CLI 어댑터는 이전에 마지막 도우미 모델을 선택할 때 이 센티널 값을 제외하지 않았습니다.。Windows 에 설치됨 npm `claude.cmd` 원본으로 `%*` 매개변수 전달；`--model <synthetic>` 될 것이다 CMD 리디렉션, 네이티브로 해석됨 CLI 확인 중 `initialize` 이전에 종료。

## 결정

이제 과거 모델 선택 저장을 건너뜁니다. `<synthetic>`。실제 보조 모델이 이전에 존재했다면 이 모델은 복구 중에 유지됩니다. 히스토리에 합성 보조 이벤트만 있는 경우 복원 시 생략하세요. `--model`，유하라 Claude 구성 및 프로젝트 설정은 기본 기본값을 선택합니다. 원래 구성、cwd、권한 모드, 소스 설정 및 작성자 보호는 변경되지 않습니다. 결과가 불확실한 복구 영수증은 자동으로 재생되지 않습니다.。

## 대안

원본 기록을 이전 기록과 비교합니다.“마지막 보조 모델을 직접 선택”컴포지션 마커를 건너뛰는 경로 및 현재 경로입니다. 이전 경로는 이벤트 유형을 구별할 필요가 없지만 선택사항이 아닌 구성 태그를 CMD，다음과 같은 재현 가능한 초기화 실패가 발생합니다. 다른 후보 솔루션과의 비교 과정을 기록하고, 이를 바탕으로 추가 선정 내역을 작성하지 않습니다.。

## 영향

실제 역사적 모델은 남아 있습니다. 이벤트를 구성하는 경우에만 모델 선택을 반환하여 구성 및 프로젝트 기본값을 복원하세요. 따라서 복구는 기본 구성이 아닌 기본 구성에 의존합니다. Bridge 대체 모델을 지정합니다. 원본 작성자, 권한 및 불확실한 영수증 보호는 변경되지 않습니다. 다음 비반올림 복구 수용은 모델 추론 수용과 동일하지 않습니다.。

## 검증
