## 대안

계속해서 친척을 사용하세요 Markdown 장점은 제출 데이터를 확장할 필요가 없다는 점이지만, 신뢰할 수 있는 첨부 파일 ID와 기본 클릭 동작을 유지하지 못하므로 교체하기로 결정했습니다. 링크를 절대 경로로 변경하는 것만으로는 기본 사이드바 미리보기를 보장할 수 없으며 첨부 파일 표시 문제도 해결되지 않습니다. 호스트 파일을 먼저 다운로드한 후 업로드하면 모든 업로드 로직을 재사용할 수 있지만 불필요한 전송 및 복사가 추가됩니다. 따라서 메타 정보와 전송 채널은 재사용되지만 콘텐츠 업로드는 재사용되지 않습니다.。
