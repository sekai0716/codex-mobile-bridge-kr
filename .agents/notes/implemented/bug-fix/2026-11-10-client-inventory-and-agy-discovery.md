# Agent Note: 설치 목록을 재사용하고 완료하세요. Antigravity 기본 검색 및 추가

Status: implemented

## 문제

게이트웨이가 시작되고 클라이언트 페이지가 새 창에서 처음으로 열릴 때마다 설치가 다시 열거됩니다. `discovered` 매니페스트는 다시 시작 시 디스플레이 캐싱을 담당하지 않습니다. 정상적인 연결 상태 폴링과 설치 검색은 혼동되기 쉽습니다.。Antigravity 자동 검색에만 들어가고 공유 추가 양식에는 액세스하지 않습니다. 공식 새 버전 CLI 에 설치됨 `.gemini/bin/agy`，IDE 2.6 같은 프로그램을 사용해서 hub 모드에서는 원래 파인더만 허용합니다. `language_server`，이 운영 양식이 누락됩니다.。

## 결정

기존에 저장된 검색 규칙 버전 및 비밀이 아닌 설치 입력이 포함된 설치 매니페스트 `desktop-sessions/settings.json`。시작 시 입력이 동일하고 규칙 버전도 동일하며 알려진 프로그램 경로가 여전히 존재하는 경우 목록이 재사용됩니다. 처음으로 목록이 없거나 규칙이 업그레이드되거나 등록 경로가 변경되거나 알려진 프로그램이 사라지거나 사용자가 다시 검색하면 목록이 재발견됩니다. 새 창은 기존 상태를 먼저 읽고 목록이 확실히 누락된 경우에만 처음으로 검색합니다. 게이트웨이를 닫은 후 로컬 관리도 이 유효 목록을 사용하는 데 우선순위를 갖습니다. 발견된 결과가 2초 동안 프로세스 또는 작업 증거가 아닙니다./작업을 계속하기 위해 쓰기 전 15초 동안 연결 상태 새로 고침, 알림 및 실시간 확인。

安装更新使用轻量文件指纹使清单失效，包括实际程序、稳定入口、Bundle 信息、Electron 资源、AGY 安装元数据及版本目录父根。Linux 保留符号链接和 desktop 文件来源。 Squirrel/MSIX 既有版本目录父根还保存排序后的一层子项名称；文件系统目录大小不变且时间戳相同的快速并存更新，也会使安装清单失效。只读取已有安装路径所指向的版本父根，不递归扫描或读取二进制内容，不改变检查频率。状态后台刷新与显式启用复用该检查；无变化不重新枚举安装，不清除已有展示缓存。自动扫描取得的 Codex 路径可随新清单更新，明确手动路径不作无身份依据的自动路径推断。旧记录缺少来源标记且其 Windows Store GUI 文件已消失时，仅在旧、新目录的包名称、发布者、架构、资源、相对 GUI 路径和安装父根均一致，当前 GUI 具有 Electron 资源与 package family/AUMID 时恢复安装身份；随后仍须由本轮注册安装发现唯一匹配同一 family/AUMID，才能采用新路径。仍存在的旧路径、明确 manual 路径、独立 CLI 和其他包均不走此恢复。

新路径出现时先重新核验旧精确程序路径的同用户进程；旧进程仍在则保留其安装行，将新安装放在 pendingInstallation，待旧进程消失才采用。进程检查失败保留原清单，不当作退出。旧文件被更新器删除时仍可检查其活进程，但不允许启动缺失程序。更新间隙的未安装结果保留旧入口和版本目录父根监视，文件重新出现后自动失效；不永久缓存这个临时负结果。安装切换保留原资料目录，显式新选资料目录始终优先，包括跨两轮等待旧进程退出的情况。

Antigravity 的 App、IDE、CLI 安装放在同一默认 provider 的 `installations` 中。共享 `default-application` 表单可以补录三类官方程序，保存路径按原生产品类型归类，不创建第二套用户资料、账号或执行 owner。启用中的接入先停用才能替换安装位置。App/IDE 使用原有 bundle/product 身份，agy 使用安装器的版本元数据、文件身份与匹配 SHA-512；相同文件身份下缓存摘要核验，程序或元数据变化重新校验。安装或历史存在均不自动授予发送能力。

ZCode 与 Antigravity 手动登记保留用户选择且通过验证的绝对路径作为发现来源，包括稳定符号链接；实际安装清单与进程核验仍使用规范化后的真实路径。否则登记时立即 resolve 并覆盖来源，会使更新器改指向新版后仍锁在旧文件。每次来源变化仍经过原安装身份验证；没有放宽非法安装、启用期间替换或用户资料隔离限制。两项真实符号链接重新指向测试先复现旧路径锁定，再验证新发现与原资料目录保留；相关注册、发现两文件 21 项通过，没有启动应用。

官方 IDE 2.6 的启动参数为 `agy --hub --hub-port=… --app_data_dir=antigravity --csrf_token=…`。hub 前端端口不作为 Language Server RPC 端口；原程序日志给出独立的原生 HTTP 监听，二进制内嵌说明确认原有 `LanguageServerService` 路径及 CSRF 头。发现器验证该监听属于同用户、同进程世代的官方程序，写入继续在请求前后核验。`app_data_dir=antigravity` 对应 App 资料根，即使展示来源是 IDE，也不能改投独立 IDE 目录。多个候选不能唯一归属时保持不可写。

비활성화되면 목록 표시만 사용하고 구성은 사용하지 않습니다. AGY 세션 어댑터. 활성화되면 기록 없이 기본 서비스도 확인됩니다. 채팅 목록 및 관리 스냅샷은 데이터 소스별로 엔드포인트 프로브에 병합되며 각 채팅에 대해 검색 프로세스가 반복되지 않습니다. 실제 전송은 여전히 ​​실시간 엔드포인트 확인을 거치며, 표시 결과는 대신 사용되지 않습니다.。

## 대안

单靠版本父根的 stat 开销最小，但已有 Linux CI 在新旧 MSIX 目录并存时未识别变化；同 stat 夹具也复现新增与删除遗漏，因此补充一层成员名称。给测试等待时间只能隐藏该遗漏，不能覆盖实际快速更新。

延长所有轮询间隔改动少，但会延迟断连、启动和重连反馈，也不能消除每次窗口首屏的安装枚举，因此只缓存安装资料。完全取消启动核验可以进一步减少读取，但会保留失效路径，因此明确的安装输入变化或路径消失仍触发发现。

직접 복구 PR150 헐렁한 available 보내기 버튼을 더 빨리 표시할 수 있지만“바이너리가 발견되어 준비됨”소스 바인딩이 아닌 엔드포인트는 원본을 증명할 수 없습니다. owner 이미 제어 가능하므로 사용되지 않습니다. ～에 따르면 hub 프런트엔드 포트는 새로 작성된 경로가 사용되지 않는 것으로 추측합니다. 공무원이 이미 제공한 기본 항목은 재사용됩니다. LS 모니터링 및 프로토콜. ～을 위한 AGY 또 다른 팝업창을 추가하면 공유 관리가 계속해서 포크되기 때문에 기존 기본 프로그램 항목이 확장되고, 확인되지 않은 독립 다중 구성은 열리지 않습니다.。
