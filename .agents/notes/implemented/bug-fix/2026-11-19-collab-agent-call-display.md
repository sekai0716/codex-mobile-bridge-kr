# 에이전트 요청의 전달 결과와 작업 상태 표시

브리지는 생성에 성공한 하위 에이전트의 행을 제공했지만, 그 뒤의 요청 전달·대기에는 협업 이벤트의 내부 이름을 표시했다. 저장된 대화를 로그에서 복구할 때는 협업 호출 중 생성 기록만 읽었다.

실시간 항목의 `tool`과 `status`로 동작과 호출 결과를 표시한다. `sendInput`의 완료는 요청 전달을 뜻한다. 에이전트별 마지막 작업 상태와 응답 본문은 `agentsStates`에서 읽는다. 응답 내용이 없는 `wait` 호출도 대기 종료로 표시한다. 대상 이름은 호출에 들어 있는 닉네임이나 현재 대화의 에이전트 목록에서 찾는다.

저장 로그의 `CollabAgentToolCall`은 같은 표시 형식으로 변환한다. 같은 대화·턴에서 동일한 호출 ID의 시작과 완료 기록을 한 행에 반영한다. 대상별 상태만 바뀌어도 행 버전을 갱신한다. 기존 에이전트 생성 행은 자식 ID로 묶는다.

백엔드 검사는 실시간·저장 기록의 일치, 중복·지연 이벤트, 여러 대상의 결과를 확인한다. 브라우저 검사는 요청 진행·성공·실패, 대화 다시 열기, 언어 전환, 에이전트 이름 조회와 하위 대화의 표시를 확인한다.
