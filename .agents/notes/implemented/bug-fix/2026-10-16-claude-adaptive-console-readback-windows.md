# Agent Note: Windows 더 일찍 완료됨 Claude 콘솔 리드백

Status: implemented

다음과 같은 프런트엔드 수집 전략이 제공됩니다.[직접 제출](2026-10-16-claude-direct-console-submit.md)대리자. 과거 측정값과 거부된 대안에는 여전히 참조 값이 있습니다.。

## 문제

Windows 보조 프로그램 버튼 Enter 전에 통과 UI Automation 체크섬 25 KiB 여러 줄의 Claude 콘솔 스크립트. 수집기는 각 뷰포트 이동 및 초점 확인 후에 고정적으로 기다립니다. 200 ms，탐색 키가 방출되자마자 렌더러가 안정화되기 시작합니다. 무해한 Test 작업 공간 진단에서 7가지 탐색 단계 각각은 50、100、150、200 ms 읽은 소스 코드 조각은 동일합니다. 이번 실행의 프롬프트 영역을 확인하는 데 걸리는 시간은 24–43 ms，텍스트 읽기 2–9 ms。

## 결정

각 탐색 키 호출이 반환된 직후 안정적인 타이밍이 시작됩니다. 정확하고 완전한 소스 코드 리드백 50 ms 그러면 당신은 성공할 것입니다. 부분 보기는 항상 키가 최소한 방출될 때까지 기다립니다. 200 ms 그래야만 소스 코드 적용 범위로 간주되거나 거부될 수 있습니다. 각 탐색 키가 유지되기 전에 초점을 확인합니다. 인접한 키 콜백 내의 중복 검사가 제거됩니다. 탐색 후와 각 읽기 전에 포커스 및 시간 초과 확인이 계속 수행됩니다.。18 단계 제한, 6초 컷오프, 적용 범위 규칙 및 단일 제출 규칙은 변경되지 않습니다.。

## 대안

Test 빌드가 다음에서 시도되었습니다. 50 ms 인접한 부분 조각만 얻은 후 다음 뷰포트로 이동했지만 독립적인 검토에 따르면 렌더러가 50 ms 짧은 유효 접두사 노출、200 ms 더 긴 접두사를 노출하면 사전 탐색 시 소스 코드를 건너뜁니다. 이 경로는 게시하기 전에 제거됩니다. 현실 Test 감지된 선택된 텍스트만 노출됩니다. 24,954 개인 UTF-16 단위로 7,577 이므로 빠른 경로도 거부됩니다. 무해한 Mac 콘솔은 다음을 감지합니다. App CSP 다음에 만난 `EvalError`，따라서 동적 짧은 로더는 더 이상 사용되지 않습니다.。

## 영향

조기에 정확하게 판독하면 완전한 소스코드 증명을 미리 완료할 수 있습니다. 모든 부분 읽기는 여전히 탐색 타이밍의 원래 최소값을 유지합니다. 200 ms 안정된 기간에는 초점 검사가 겹칠 수 있습니다. 전체 적용 범위 및 제출 금지 조건 외에도 기본 자체 점검에서는 조기에도 적용됩니다. 32 문자 접두어가 완전하고 안정되면 다음과 같이 커집니다. 1,500 캐릭터, 후속 연속 뷰포트 및 조기 완전하고 정확한 리드백. 마지막으로 수집기가 컴파일되어 기본 자체 테스트를 통과합니다. 24,954 성격 Windows Test 소스 코드 4.407 몇 초 안에 완전한 소스 코드 영수증을 받으세요. 단일 실행은 제어된 속도 향상 측정이 아닙니다. 결정적인 Test 접두사 픽스쳐를 늘리고 패키지 내 기본 자체 검사를 통과하기 위해 패키지가 다시 컴파일됩니다. 설치 후，Claude 런타임 시 명시적으로 초기화되었습니다. 8.1 몇 초 만에 연결이 성공하고 실제 세션 목록이 반환됩니다.。
