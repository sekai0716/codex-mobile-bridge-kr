# Agent Note: Windows Codex 숨겨진 창이나 확장된 메뉴를 표시하지 않고 종료

Status: implemented

## 문제

Windows Codex 일반적으로 보조자를 종료하면 원래 숨겨진 기존 기본 창이 표시되고 확장됩니다. File 메뉴 검색 Quit。창이 활성화되지 않고 마우스와 키보드 입력이 전송되지 않더라도 이 두 단계를 거치면 사용자가 보는 데스크탑이 달라집니다.。

## 결정

기존에 표시되는 기본 창에서 노출된 애플리케이션 메뉴 종료 항목만 찾으세요. 동일한 프로세스 이미지, 생성 시간, 사용자 세션, 창 소유권, 고유 메뉴 항목 및 Ctrl+Q 라벨 검증 발송하기 전에 메뉴를 다시 가져오고 항목을 종료하고 동일한 컨트롤을 비교하고 기본 확인을 확인합니다. 신뢰할 수 있는 백엔드 입구가 없으면 보고서가 즉시 보고되며 아직 제출되지 않았습니다. 컴퓨터를 정상적으로 종료하십시오. 창을 표시하거나 메뉴를 확장하지 마세요.。

하나의 디스패치를 ​​상속하고 잠금을 취소하며 submitted/pending 영수증. 발송되었으나 반송이 되지 않은 경우 재발송되지 않습니다. 기존 호출자는 원래 생성 종료를 관찰합니다. 숨겨진 창 복구만 제공하는 로깅 및 롤백 코드 제거。ZCode 팔레트 분기 및 해당 개인 출구 프로토콜은 원래 동작을 유지합니다.，CLI daemon 릴리스는 이 데스크탑 종료를 대체하지 않습니다.。

## 대안

표시된 상태로 유지되지만 활성화되지 않은 창 호출은 종료 검색 속도를 향상시키지만 여전히 보기를 방해합니다. 메뉴를 펼친 상태로 두는 것도 불만족스럽습니다. 시스템이 세션을 종료하거나 프로세스를 종료하더라도 프로세스를 사라지게 할 수는 있으나 클라이언트가 정상적으로 저장되었음을 증명할 수 없으므로 정상이라고 볼 수는 없습니다. Quit 예약하다。
