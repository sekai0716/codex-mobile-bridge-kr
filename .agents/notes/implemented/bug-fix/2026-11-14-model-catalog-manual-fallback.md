# Agent Note: 모델 디렉터리가 유효한 캐시와 정확한 수동 채우기를 유지하지 못함

Status: implemented

## 문제

Codex 공식 카탈로그가 처음으로 실패하면 예외가 발생하고 모델 설정 페이지에서 수동 채우기가 숨겨집니다. 사고력이 부족한 카탈로그를 저장하는 것도 금지됩니다. 빈 디렉터리는 가장 최근에 성공한 모델 캐시를 덮어쓸 수 있습니다. 이러한 방식으로 디렉터리를 일시적으로 읽을 수 없게 되어 기본 시스템에서 원래 지원되는 명시적 모델 구성이 차단됩니다.。

## 결정

同一已核验账号与项目身份优先使用现有 ModelStore；刷新失败或空目录保留原成功目录及时间。`config/read` 或选中 profile 的非空结构无法确认时，在查询账号与模型之前明确失败，保留已确认的默认 provider 与身份。原生 `model/list` 的响应体和每页 `data` 必须分别为对象和列表；null 或错误结构明确失败，不把不完整分页写成 fresh。可选模型元数据的 null 仍不影响有效上游目录。首次失败返回未就绪目录和已核验身份，不把错误写成成功缓存；身份变化仍拒绝旧结果。

Codex 新建与模型设置保留手填。填写的模型原样提交，未选强度时省略 effort，沿用原生值；已知模型的明确强度限制仍校验。Fast 等额外能力仍需新鲜能力确认，不从目录失败或展示缓存推断权限。`config/read` 或 `configRequirements/read` 的整体结构无效时返回 unavailable；合法空 profile 和明确可空的 requirements 保持兼容。features 与 featureRequirements 的缺失/null 沿用可选语义，非空非法类型不能变为默认允许。页面将目录获取失败作为普通状态说明，保留可编辑控件；实际设置失败继续明确报错。旧网关、账号或聊天的晚结果不能填充当前页面。

## 대안

계속해서 디렉터리 설정이 성공하도록 요구하면 사용 가능한 기본 기능이 잘못 차단됩니다. 고정 모델로 돌아가면 사용자 의도가 변경됩니다. 계정 신원 확인을 임의로 건너뛰는 경우 다른 계정 구성을 사용할 수 있습니다. 따라서 디렉터리 외부의 명시적인 모델 입력만 해제되고 원래 실행 소유권과 신원 확인은 유지됩니다.。

## 영향

사용할 수 없는 모델 디렉터리는 더 이상 사용할 수 없는 모델 구성과 동일하지 않습니다. 사용자 값은 수동으로 입력해도 유지되며 업스트림에서 알 수 없는 모델을 수락한다는 보장은 없습니다. 기본 거부가 보고되면 다른 모델이 자동으로 선택되지 않습니다.。Windows/Linux이번 라운드에서는 실제 머신 검증이 수행되지 않았습니다.。

## 공유 편집기 보충 자료

새로 생성된 디렉토리를 처음으로 가져오지 못한 경우에도 직접 입력한 컨트롤이 계속 표시되고 초안은 유지됩니다. 계정 신원이 확인되지 않은 경우 편집만 가능하며, 위조된 신원 제출은 허용되지 않습니다. 후속 읽기에서는 정확한 입력이 성공적으로 유지됩니다. 기존 채팅의 새로 고침 기간 동안 동일한 ID를 가진 유효한 캐시를 사용할 수 있습니다. 읽기 실패에는 일반 상태 설명이 사용됩니다. 실제 쓰기 실패 및 계정 변경은 여전히 ​​명확하게 차단됩니다. 확인에는 첫 번째 읽기 실패, 캐시 새로 고침 중 제출, 자동 재생 없이 저장 실패, 계정 간 지연 응답이 포함됩니다.。

## Antigravity 네이티브 매핑
