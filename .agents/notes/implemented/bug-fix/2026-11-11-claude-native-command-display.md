# Agent Note: Claude 기본 명령 기록은 일반 채팅과 별도로 표시됩니다.

Status: implemented

## 문제

Claude CLI 의 `/exit` 쓸 것이다 caveat、command、stdout 산조 원주민 user 기록. 일반 텍스트 투영은 내부 XML 버블로 표시, 넣어도 됨 `isMeta` caveat 대화 제목으로. 실제 WSL 2.1.308 기록이 동일함을 확인 sessionId/promptId 그리고 계속되는 parentUuid，하지만 일반 사용자도 동일한 태그를 입력할 수 있으며 전역적으로 제거할 수는 없습니다. XML。

## 결정

Claude 기록 모듈은 전체 기본 명령 체인을 균일하게 식별합니다.：CLI 입구、user 역할、meta caveat、같은 대화 prompt、계속되는 아버지와 아들 UUID，전체 명령 레이블은 둘 다 true여야 합니다. 프로젝트 명령 이름만/매개변수 및 기본 출력 수정하지 마세요 JSONL、정보 ID、시간, 역할 또는 일반 메시지 내용. 데스크탑 connector 증명 체인, 로컬 및 독립 원격에 필요한 문자열 필드만 보완 worker 동일한 기능을 재사용。

목록 제목은 먼저 기본으로 유지되어야 합니다. custom-title 일반적인 사용자 문제; 명령 전용 세션에는 첫 번째로 확인된 명령이 제목으로 있습니다.。meta、synthetic 기록은 제목으로 사용되지 않습니다. 체인 중간부터 페이지 매기기를 시작할 때 증거가 부족하고 원본 텍스트를 유지하며 변환을 추측할 수 없습니다.。

## 대안

레이블 규칙성에 따라 최소한의 코드를 전역적으로 제거하지만 사용자가 실제로 보낸 내용을 손상시킵니다. XML。모두 숨기기 user 명령 로깅은 사용자 작업 및 출력을 잃게 됩니다. 기본 로그를 직접 다시 작성하면 원래 클라이언트 ID 및 지속성 계약이 삭제되므로 권장되지 않습니다.。

## 영향

완전한 체인 디스플레이 `/exit` 기본 출력, 일반 메시지는 동일하게 유지되며 각 호스트는 계속해서 공유 메시지를 사용합니다. UI。일부 기록 페이지에 접두어가 누락되었습니다. caveat 원본 텍스트가 계속 표시될 수 있습니다. 이는 권한 또는 연결 성공, 디렉터리 누락, 알 수 없는 권한 및 기록으로 간주되지 않습니다. 429 여전히 실제 상태에 따라 처리됩니다.。

## 검증

사실을 읽다 WSL 기록을 변경하거나 모델 요청을 보내지 않고 기본 레코드의 구조 및 관계。5 개 Python 예상 ID, 원본 텍스트 보존, 끊어진 링크 및 로컬 시스템을 다루는 대상 검사를 통과했습니다./독립적인 원격 헤더 및 기존 custom-title；1 개 Node 페이징 내역 확인이 통과되었으며 필요한 필드가 투명하게 전송되는 것을 확인했습니다. cwd 투영에 들어가지 않습니다. 최종 설치 패키지의 실제 페이징 디스플레이는 여전히 통합되고 승인되어야 합니다.。
