# Agent Note: Claude 할당량은 명시적인 요청이 있을 때만 쿼리됩니다.

Status: implemented

## 문제

Claude 계정 패널이 열려 있고 표시될 때 5분 동안 새로 고침이 하나씩 요청됩니다. `details`。이전 백엔드는 만료된 할당량 캐시를 자동으로 해독합니다. Cookie，macOS 그럼 읽어봐 Claude Safe Storage；사용자는 크레딧 버튼을 클릭하지 않고도 키체인 인증을 받을 수 있습니다. 또한 이전 실패 결과는 마지막으로 성공한 쿼리 시간을 실패가 발생한 시간으로 덮어씁니다.。

## 결정

Claude 패널 열기, 반환, 전환 후 목록 새로 고침 및 예약 새로 고침 전용 계정 공개 스냅샷 요청。Claude `details(refresh=False)` 또한 스냅샷을 서버측 경계로만 반환합니다. 오직 명시적인 `details(refresh=True)` 한도를 확인하세요。DeepSeek Harness 및 Codex 기존 새로 고침 동작은。

식별 가능한 금액을 성공적으로 구문 분석한 후 스냅샷을 교체하고 저장합니다. `checkedAt`；기존의 성공적인 할당량과 그 할당량을 유지하지 못하는 경우 `checkedAt`，상태 및 둔감화 오류를 실패로 변경합니다. 성공한 스냅샷이 없을 경우 쿼리 성공 시간이 기록되지 않습니다. 인터페이스는 로컬입니다. `YYYY-MM-DD HH:mm` 보여주다 Claude 쿼리 성공 시간, 실패 데이터, 오래된 데이터가 동시에 표시됩니다. 쿼리 중 버튼 표시“쿼리 중”비활성화하면 동일한 패널이 반복적으로 제출되지 않습니다. 각 명시적 쿼리는 해당 호출의 로컬 사전 내에서만 재사용됩니다. Claude Safe Storage 키 파생; 호출 종료 후 프로세스 수준 일반 텍스트 키 캐시를 유지하지 않습니다.。

## 기존 메모 감사

누르면 Claude、quota、몫、keychain、키체인 검색 활성 `.agents/notes/`。기존 노트에는 고객 목록 새로 고침, 목록 상태 및 기타 기능이 포함되어 있으며 계정 한도 쿼리와 중복되지 않습니다. 동일한 이름의 승인된 제안은 로컬 무시 디렉터리에 저장됩니다. `.local/reviews/`，상호 작용 옵션과 경계가 여기에서 구현됩니다. 현지 검토 자료는 제출되지 않습니다.。

## 대안

자동 제한 쿼리를 5분 동안 유지하고 키체인 읽기만 병합하면 단일 인증 횟수를 줄이고 데이터를 최신 상태로 유지할 수 있습니다. 사용자가 수동 쿼리 선택과 일치하지 않는 제한을 적극적으로 확인하지 않는 경우에도 보호된 항목에 계속 액세스합니다. 캐시 시간을 늘리면 자동 액세스도 지연됩니다.。

## 영향

Claude 스냅샷은 오래되었을 수 있으며 인터페이스에는 항상 원래 쿼리 성공 시간이 표시됩니다. 시뮬레이션된 회귀는 암호 해독이 없는 수동 경로, 네트워킹 없음, 명시적 쿼리, 보존 실패 및 이중 언어 상태를 다룹니다. 이 변경은 계정 할당량의 액세스 경로만 처리합니다. 연결 자격 증명, 클라이언트 자체 액세스 키체인, 애플리케이션 서명 및 버전 간 인증은 팝업 창의 실제 소스를 기반으로 별도로 확인해야 합니다.。
