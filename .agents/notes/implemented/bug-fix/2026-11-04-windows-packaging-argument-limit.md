# Agent Note: 게이트웨이 패키징 매개변수는 표준 입력을 통해 전달됩니다.

Status: implemented

## 문제

PR #130 보고서 Windows 공식적인 포장 입구는 많은 수로 인해 발생합니다. --add-data 매개변수가 초과됨 CreateProcess 의 32767 글자 수 제한으로 인해 실패했습니다. 임시 짧은 경로와 별도의 패키징 스크립트를 통해 이전의 크로스 플랫폼 수용을 우회했는데, 이는 창고 표준 빌드 입구가 신뢰할 수 있음을 입증하는 데 사용할 수 없습니다.。

## 결정

동일한 독립성을 유지하다 Python 포장공정, 용도 PyInstaller 공식적인 `PyInstaller.__main__.run(args)`，매개변수 목록을 그대로 전달합니다. stdin JSON 들어오는. 실제 시작 명령 길이는 더 이상 리소스 경로 수에 따라 증가하지 않으며 매개변수 내용, 순서, 수집 규칙 및 출력 디렉터리는 변경되지 않습니다. 모든 시스템은 추가하지 않고 동일한 구현을 재사용합니다. Windows 전용 리소스 목록 또는 종속성。

## 대안

계속해서 경로를 단축하면 상한선이 연기될 뿐이며, 리소스가 늘어난 후에도 계속 실패하게 됩니다. 모든 포장을 손글씨로 변경 spec 기존 매개변수 유지 관리에서 포크를 추가합니다. 빌드 상위 프로세스에서 직접 호출됨 PyInstaller 상한을 피할 수도 있지만 전역 상태를 변경할 수 있으므로 하위 프로세스 격리가 유지됩니다.。

## 검증

방향 고정 장치는 실제 하위 프로세스 항목을 이중으로 실행합니다. PyInstaller 지나가다 32767 문자, 한자와 공백을 포함하는 리소스 경로 그룹 500개. 구문 분석된 매개변수 목록이 항목별로 동일한지, 시작 명령이 여전히 상한보다 짧은지 확인하십시오. 현실 Windows 동결된 빌드와 매개변수 전송 테스트는 별도로 기록되며 서로 대체할 수 없습니다.。

## 영향

빌드에는 여전히 기존이 필요합니다. PyInstaller 환경에서는 새로운 도구가 설치되지 않습니다. 표준 입력은 사용자 자격 증명 없이 빌드 경로와 매개변수만 전달합니다. 실패는 여전히 하위 프로세스 종료 코드를 통해 전달됩니다. 에 따라 [PyInstaller 공식적인 사용법](https://github.com/pyinstaller/pyinstaller/blob/develop/doc/usage.rst) 프로그래밍 방식의 호출 인터페이스 구현。
