# Agent Note: Feiniao Terminal Agent의 현재 포트 소스를 완료하세요.

Status: implemented

## 문제

사용자의 `.zshrc` 터미널 시작 시 Asuka 구성에서 읽기 `mixed-port`，그런 다음 에이전트 환경을 내보냅니다. 영구적인 CLI 이전 포트는 유지됩니다. 원래 자동 복구는 시스템 정적 프록시만 읽고 시스템 프록시가 활성화되지 않은 터미널 사용은 처리할 수 없습니다. 게이트웨이의 자체 시작 환경도 최신 상태가 아닐 수 있습니다.。

## 결정

기존 시스템 정적 프록시를 우선적으로 유지합니다. 오직 macOS 시스템 설정을 성공적으로 읽었습니다. 아니요 HTTP/HTTPS 정적 프록시 및 아니요 PAC、자동 검색 또는 활성화됨 SOCKS 라우팅 시 현재 사용자의 Bird 구성이 시도됩니다. 유일하게 유효한 최상위 레벨만 추출 `mixed-port`，파일 소유자, 변경 사항, 애플리케이션 식별, 실제 코어 이미지, 사용된 구성 매개변수 및 수신 포트 소유권을 확인하고 대상 주소를 전달하지 않는 파일을 만듭니다. SOCKS5 협상하다. 구성 본문, 구독 및 인증이 로그에 입력되지 않습니다.。

기존 에이전트 튜플을 반환하고 동일한 마스터 구성, 이전 에이전트 오류, 대상 우회 규칙, 유휴 대기, 사전 디스패치 검토 및 알 수 없는 작업을 재생 없이 재사용하는 복구 프로세스를 계속합니다. 여기서는 알려진 소스만 확장하고, 사용자는 실행하지 않습니다. shell、시스템 설정이 변경되지 않고, 새로운 복구 상태 머신이 없으며, 식별에 대한 약속이 없습니다. shell 스크립트 또는 기타 프록시 제품。

## 대안

상호작용을 다시 실행하세요. shell 사용자 스크립트에서 내보낸 변수를 얻을 수 있지만 다른 시작 명령도 동시에 실행됩니다. 출력 화이트리스트는 부작용을 제거할 수 없으므로 사용되지 않습니다. 게이트웨이 환경을 직접 사용한다고 해서 현재 포트임을 증명하는 것은 아닙니다. 동일한 이름을 가진 구성을 읽거나 프로브만 읽으십시오. TCP 해당 프로그램에서 포트를 제공하는지 여부를 확인할 수 없습니다.。

## 검증

15 항목 지향 회귀에는 기존 라우팅 규칙 및 시스템 소스 우선순위가 포함됩니다.、PAC/SOCKS 폴백, 오류 및 포트, 파일 또는 프로세스 변경 사항과 기타 리스너의 중복이 없습니다. 현실 Mac 새 소스를 별도로 호출하여 현재 포트가 반환되었습니다. `http://127.0.0.1:15937`；이번 라운드의 최신 시스템 정적 소스도 이 포트로 반환됩니다. 두 가지는 별도로 검증되며, 서로를 사칭하는 것이 아닙니다.。

이 소스 코드를 기반으로 패키징됨 Mac Test 실제 브라우저와 네이티브에서 이미 사용됨 0.167 CLI 확인: 마스터 구성 격리 CLI 처음에는 닫힌 프록시 포트를 보유하고 원래 세션을 클릭합니다.“계속하다”나중에 약속 1.8 연결하는 데 몇 초가 걸리며 이전 세대가 종료되고 새 세대가 현재 프록시를 채택하는 것이 확인되었습니다. 두 번째 원래 대화도 계속할 수 있습니다. 단일 세션 진입을 통해 공유 구성의 영향 범위를 확인하고 정상 릴리스를 확인한 후 네이티브 프로세스가 종료되었습니다. 다시 약속을 계속해 1.4 연결하는 데 몇 초밖에 걸리지 않으며 두 원래 세션이 모두 유지됩니다. ID、provider 및 작업 디렉터리에서는 에이전트가 이전 값으로 대체되지 않았습니다. 게이트웨이、CLI 정상 종료, 임시 구성 복원, 모델 요청 없음. 원본 증거는 다음 장소에 보관됩니다. `.tmp/feedback-20261111-10/mac-cli-direct-live/`。이 전체 복구는 당시 사용 가능한 시스템 정적 소스를 사용하며 완전히 검증되었다고 주장할 수 없습니다.“시스템 소스가 비어 있습니다.”패키지된 롤백 버드 롤백 소스는 독립적인 실제 기계 판독 및 방향 테스트를 통해 다루어집니다. 고정된 사용자 세션、Windows SSH 그리고 형식적인 App 그래픽 인수에는 여전히 별도의 승인이 필요합니다.。

시뮬레이션 테스트 누락을 실제 머신에서 발견하고 수정했습니다.：`ps` 에서 `LC_ALL=C` 다음으로 중국어 애플리케이션 경로를 벗어나면 초안이 일치하지 않습니다.“새의 속도가 빨라지다”。프로젝트의 기존 사용 `en_US.UTF-8` 규칙을 쿼리한 후 실제 핵심 경로가 일치됩니다. 핵심은 root 런타임 강력한 프로세스 ID 인터페이스 반환 EPERM；여기서는 에이전트 소스만 관찰하고 읽을 수 있는 프로세스 경로, 생성 시간 및 수신 관계를 사용하며 중지 신호를 보내기 위한 ID 자격 증명으로 사용하지 않습니다.。CLI 자체 정지 및 시작 검증이 완화되지 않았습니다.。

## 영향

확인된 새 구성 소스를 완료합니다. 원래 정적 프록시、Windows 지원되지 않는 소스로 설정된 경계를 유지합니다. 확인할 수 없는 경우 대체 포트를 추측하지 마십시오. 계정, 채팅, 기본 권한 또는 새 구성이 수정되지 않았습니다.。
