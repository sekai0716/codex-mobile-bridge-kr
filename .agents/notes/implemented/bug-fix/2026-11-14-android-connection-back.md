# Agent Note: Android연결 감지 페이지가 컴퓨터 목록으로 돌아갑니다.

Status: implemented

## 문제

#164 자동 재접속 감지 페이지가 아직 생성되지 않았습니다. WebView，handleBack 컴퓨터 목록으로 착각하여 두 번 누르면 종료됩니다.。

## 결정

기존을 기반으로 entryProgress 감지 페이지를 구별하고 전화를 회신합니다. home/clear 원래 경로; 탐지를 취소하기 위해 재사용、Cookie메모 전환 및generation，늦은 콜백이 다시 연결되지 않도록 비활성화합니다. 감지 페이지는 상단에 컴퓨터 목록 항목과 추가 메뉴를 추가합니다. 없음WebView현재는 전화통화 없이 컴퓨터 목록, 알림함, 휴대폰 설정만 제공됩니다.Web작동하다。

## 대안

바로 나가기App컴퓨터 목록으로 돌아갈 수 없습니다. 별도의 반품 프로세스를 생성하시면 늦은 답변 취소를 놓치기 쉽습니다. 그래서 기존 것을 재사용home로직을 정리하고 감지 페이지와 컴퓨터 목록만 구분합니다.。

## 영향

감지하는 동안 휴대폰 설정으로 돌아가거나 열 수 있습니다. 자동 재접속을 취소하기 위해 돌아가시면 기존 계좌번호, 주소, 휴대폰 바인딩은 그대로 유지됩니다.。

## 검증

소스 코드 위치는 원래 잘못된 분기를 확인합니다. 공식 서명 사용Test build63 APK，기존 읽기 전용AVD중간 생산Activity네이티브로 지연HTTP감지: 시스템Back、맨 위로 돌아가면 더 많은 메뉴와 휴대폰 설정이 모두 전달됩니다.；8하위 현실socket요청한 늦은 콜백은 연결 페이지에 다시 들어갈 수 없습니다. 컴퓨터를 저장하십시오./주소 기록이 유지됩니다. 인터페이스 스크린샷이 확인되었으며 시뮬레이터가 정상적으로 종료되었습니다. 실제 휴대폰을 조작하지 않았거나 네트워크 인증이 변경되지 않았습니다. 증거물이 위치해있습니다`.tmp/model-cache-20261114/android-probe/`。
