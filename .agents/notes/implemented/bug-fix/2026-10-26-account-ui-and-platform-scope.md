# Agent Note: 계정 표시 및 게이트웨이 플랫폼 범위

Status: implemented

## 문제

통합 계정 변경으로 인해 데스크톱 추가 입구가 분할되며, 모바일 편집자는 저장되지 않은 초안에 대한 모델을 얻을 수 없습니다. 데스크탑 개요 할당량은 저장된 활성 계정 줄을 읽지만 계정 관리에 사용되는 기본 로그인 카드는 누락됩니다. 숨겨진 계정 패널은 할당량 로딩을 방해할 수도 있습니다. 아니요 WSL Capability Gateway도 초기화됩니다. WSL 제어 및 관리자。

## 결정

데스크탑 복구“계정을 추가하거나 API”포털, 저장된 계정의 통합 목록을 유지합니다. 모바일은 기존 테마 변수를 상속하는 간결한 사용자 승인 그룹화 형식을 사용합니다. 명시적 및 인증됨 Codex 초안 모델이 원본 확인을 요청합니다. URL/저장, 전환 없이 디렉터리를 쿼리하고 초안 자격 증명을 유지하지 않는 주요 규칙입니다. 모델 필드가 비어 있으면 첫 번째 반환을 입력합니다. ID；수동으로 선택하고 업데이트한 편집 콘텐츠가 늦은 응답보다 우선합니다.。

데스크탑만 제거 provider 제목 그룹화 행. 게이트웨이는 자체 운영 체제에 의해 제어됩니다. WSL 전담관리자 가져오기/게이트웨이 기능을 기반으로 계정 제어를 초기화하고 로드하기만 합니다.。Windows 엔드포인트 ID, 기본 라우팅 및 쓰기 보호는 변경되지 않습니다. 데스크탑 개요는 계정 관리와 동일한 기본 로그인 ID를 사용하며 기존 표시 페이지의 할당량 읽기 리듬을 따릅니다.。

## 대안

독립적인 데스크탑 양식을 재사용 가능하게 유지 CLI 편집자이지만 원래 항목을 복원해야 하는 요구 사항을 위반했습니다. 숨기기만 WSL Control은 지원되지 않는 시스템에서 환경을 미리 로드하고 쿼리합니다. 저장된 다른 계정의 잔액을 재사용하면 셀이 채워질 수 있지만 현재 로그인을 잘못 식별하게 됩니다. 원래 로그인 카드가 우선해야 합니다.。

## 시험

직접 테스트 검증 초안에서 수정 또는 만료 응답이 생성되지 않은 것으로 확인되었습니다./수동 편집 처리, 저장되지 않은 기본 로그인 크레딧, 데스크톱 타일 행 및 Windows 그리고 비 Windows 초기화 차이점. 두 가지 기존 주제에 대한 합성 데이터 사용、320 및 390 CSS 실제 그룹 편집기를 픽셀 너비로 확인하고 수평 오버플로가 없는지 확인하세요. 주체만이 소스코드를 수정하고 테스트를 수행합니다. 빌드 에이전트는 고정된 후보 버전을 수신합니다.。

업스트림 모델 디렉토리는 증명할 수 없습니다. Responses 호환성. 누락된 금액은 이용 불가로 명확하게 표시되며 어떠한 추론도 이루어지지 않습니다.。WSL 주문형 로딩은 유지되어야 합니다 Windows 로컬 계정을 방해하지 않고 로드가 실패할 때 동작 및 보고 오류。

전체 창고 메모 확인에서 여전히 기존 항목이 보고됩니다. optimization 목차와 이전 메모의 형식이 잘못되었습니다. 이번 라운드에서 수정된 메모는 보고되지 않습니다. 프런트엔드 회귀：1200 통해，1 뛰어넘어라. 계정/플랫폼/HTTP 회귀: 플랫폼 수명 주기 확인을 추가하기 전，206 항목이 통과됨。
