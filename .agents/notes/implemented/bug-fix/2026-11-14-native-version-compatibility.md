Status: implemented

## 문제

데스크탑 흐름 업그레이드 트리거 PR169 나중에 비슷한 감사가 발견되었습니다. Codex CLI 정상적인 드레이닝, 실패한 최종 상태 릴리스 및 계정 동기화를 몇 가지 정확한 릴리스로 제한합니다. 합의는 변함이 없습니다 0.165、0.168 다른 버전도 거부되었습니다. 버전 화이트리스트는 각 작업에 대한 기존 작업 및 프로세스 확인을 대체할 수 없습니다.。

## 결정

Codex CLI 기존 공유 graceful_restart_supported 검증된 계약서의 도입 하한을 기준으로 응모, 후보자 심사：POSIX 0.164.0，Windows 0.167.0-alpha.3.2。호환되는 새로운 마이너 버전이나 안정 버전에는 재등록이 필요하지 않습니다. 인식할 수 없는 기본 핸드셰이크, 오래된 버전 및 지원되지 않는 플랫폼은 여전히 ​​기능을 얻지 못합니다. 해당 버전은 후보자 판단에만 사용되며 종료 권한을 부여할 수 없습니다. home、이미지, 프로세스 생성、socket peer、실시간 작업/승인/백엔드 터미널、Windows shutdown 기본 태그, 채널 확인 및 발송 영수증이 모두 유지됩니다.。

Linux 플랫폼 worker 시스템 ID, 커널 기능 및 기본 버전 메타데이터의 존재만 확인되며 비즈니스 버전 테이블은 더 이상 반복적으로 유지되지 않습니다. 일반 종료를 위한 프로토콜 자격은 공유 클라이언트에 의해 결정됩니다. LinuxCliControl 판단, 실제 분포를 다시 확인하면 동일함 generation。알 수 없는 버전은 여전히 ​​명시적으로 승인된 강제 종료 경로만 유지하며 이를 일반적인 배수 기능과 동일시하지 않습니다.。

나가서 한 번 계속 걷기 SIGHUP 또는 검증됨 Windows 채널을 비공개로 닫고 네이티브로 변경하지 마세요. daemon stop/restart。현직 공무원 app-server 소스코드와 daemon README 확인 SIGHUP 예 graceful-only；stop/restart 창을 기다린 후 강제로 종료될 수 있으며 이 프로젝트의 기본 정상적인 종료 프로세스를 대체할 수 없습니다.。

Claude CLI 의 `--permission-prompts` ～부터 2.1.259 만 제공되며 현재 공식 기본값은 `host`。로컬 시스템과 원격 끝은 기본 기본값을 공유합니다. 특별판결만 삭제하세요. 2.1.168 버전 감지 및 중복성 매개변수, 예약됨 `--permission-prompt-tool stdio`、원래 권한 모드 및 승인 제어 요청입니다. 각각 생성할 필요 없음/추가 시작 버전 쿼리를 복원합니다. 공식적인 근거：[CLI reference](https://code.claude.com/docs/en/cli-reference)。

Claude Windows 알려진 세션 점유율 기록 `procStart` 문자열 및 프로세스 생성 ticks 검증, 더 이상 승인이 아니다 2.1.168。PID 사라지거나 재사용되는 경우에만 계속할 수 있습니다. 동일한 활성 프로세스는 여전히 이중 쓰기를 방지합니다. 포함하다 `pidDomain` / `procStartFt` 다른 형식, 조회할 수 없는 권한, 잘못된 형식의 필드는 아직 알려지지 않았으며 알 수 없는 것은 무료로 간주되지 않습니다.。Windows 이번 라운드에는 실제 기계가 작동하지 않습니다. 15 복합 기록/프로세스 테스트에는 버전 변경 및 원래 보호 경계가 포함됩니다.。

## 대안

정확한 릴리스 번호를 계속 추가하면 대부분의 변경 사항이 저장되지만 모든 기본 업그레이드에는 게이트웨이 릴리스가 필요합니다. 모든 버전 및 ID 확인을 완전히 제거하면 아직 계약을 제공하지 않은 이전 런타임에 적용할 수 없는 작업이 전송됩니다. 읽기 전용 핸드셰이크에만 의존하면 종료로 인해 강제가 확대되는지 여부를 증명할 수 없으므로 기존 최소 계약 및 실제 제어 채널 확인이 유지되며 새로운 백그라운드 시작 감지 인스턴스 또는 지속적인 검색이 없습니다.。

## 검증

동일한 핸드셰이크 버전을 교체하면 이전 액세스 제어 거부가 재현됩니다. 0.165/0.168；새 버전은 후속 버전과 호환되는 것으로 승인되며 이전 및 알 수 없는 소스는 거부됩니다. 직접 테스트에는 네트워크 복구, 계정 동기화, 최종 상태 릴리스 실패, 프로세스 생성, 반복 종료 및 알 수 없는 수신이 포함됩니다.；Linux 에서 Mac 구성 사용 /proc/socket/pidfd 고정물, 대표하지 않음 Linux 실제 기계를 통과함。Windows/Linux 이번 라운드는 사용자 요구사항에 따라 운영되지 않습니다.。

Claude 로컬 머신/SSH/WSL 명령이 먼저 반환된 다음 새 매개변수와 함께 다시 나타납니다.，84 오리엔테이션 테스트 통과；Mac 설치됨 Claude 2.1.292 격리된 빈 구성에서는 다음을 사용합니다. stdio 승인 매개변수 완료됨 true initialize、모델 디렉터리 및 설정 읽기, 닫기 stdin 종료 코드 0；모델 요청이 전송되지 않았으며, 공식 계정을 읽을 수 없습니다.。

유사한 스캔 결과：DSH 의 bridge revision/플러그인 패키지 형식、Antigravity 설치 소스 및 해시、ZCode 애플리케이션 ID/프로토콜 필드 및 Claude 파일 보관 형식과 바이너리 증거 테이블은 다양한 계약을 보호합니다. 이번 라운드에서는 이러한 검사를 제거할 만큼 충분한 증거가 발견되지 않았으므로 해당 검사는 유지되며 이 버전과의 호환성을 이유로 완화되지 않습니다.。
