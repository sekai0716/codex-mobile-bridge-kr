# Agent Note: 데스크탑 업데이트 핸드오버는 대상 설치에만 바인딩됩니다.

Status: implemented

## 문제

Test 게이트웨이는 다음에서 실행됩니다. 8788，그러나 창에는 또 다른 데이터 디렉터리 및 포트 세트가 표시됩니다. 원래 디렉터리를 수동으로 선택한 후 창이 복원됩니다. 데스크톱 컨트롤러는 상속된 업데이트 환경 변수를 직접 사용하고, 창이 열린 후 동일한 변수에 따라 영수증을 작성합니다. 공식 버전과 Test 공존하는 경우 이전 업데이트 환경은 현재 설치가 저장된 디렉터리를 덮어씁니다.。

## 결정

컨트롤러는 현재 설치 대상, 버전, 데이터 디렉터리 및 임의의 항목만 사용합니다. token 일관되고 불완전한 핸드오버. 트랜잭션 디렉터리는 설치 옆의 업데이트 디렉터리여야 하며 보조자는 해당 준비 레코드를 작성해야 합니다. 어시스턴트가 새 프로세스를 기록했습니다. PID 시대도 일관성이 있어야 합니다. 하위 프로세스가 우선합니다. PID 레코드가 시작 항목에 도달하면 먼저 준비된 레코드와 계획을 통해 바인딩됩니다. 스냅샷이 완료된 후 거래가 검증되고 영수증만 작성됩니다. 트랜잭션이 만료된 후 업데이트된 점유 상태가 동시에 해제됩니다.。

## 대안

오직 에서 Test 실행 프로그램 정리 환경은 시작 방법을 재정의할 수 있으며 시스템 메뉴나 외부 프로그램에서 시작된 창을 보호할 수 없습니다. 데이터 디렉터리 업데이트를 완전히 생략하면 일반 업데이트나 롤백에서 잘못된 구성을 사용할 수 있습니다. 거래가 없고 token 롤백은 보조자가 원래 전달한 데이터 디렉터리를 유지합니다.。

## 영향

测试覆盖跨安装、已结束事务、错误 token、路径、版本和进程、PID 记录竞争、写回执前事务失效以及回滚。被拒绝的事务不得覆盖显式配置或窗口保存的目录，也不得占用更新状态或向原事务写回执。

## 已保存目录指针

已存在的 bridge-location.json 必须可读取且包含非空字符串目录；损坏或读取失败交给启动错误提示并退出，不能静默显示另一套默认资料。指针不存在仍沿用原默认选择。合法路径仅以 trim 判断空白，不修改原字符串，尾空格目录保持同一身份。环境变量与更新事务的原优先级不变。

返回默认目录能让窗口继续打开，但会隐藏原账号、绑定和偏好，因此拒绝把损坏指针当成首次启动。隔离真实文件与启动回调覆盖尾空格绑定哨兵、无指针默认及坏指针不发布资料/不开窗；不启动真实 Electron。

## 指针原子替换

saveDataDir 只通过同目录临时文件写入后 rename 安装；临时文件缺失、rename 失败或测试替身未实现 rename 都不能直写目标。失败清理本次临时文件并保留旧指针字节。测试替身实现该文件系统契约，不为 mock 增加生产降级分支。现有目录选择的内存提交顺序不在本次修正范围。
