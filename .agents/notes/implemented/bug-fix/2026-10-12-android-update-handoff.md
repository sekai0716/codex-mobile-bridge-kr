# Agent Note: Android 업데이트 다운로드 및 설치 인계

Status: implemented

## 문제

PR #32 묶음 Android 대신 브라우저에서 업데이트가 다운로드됩니다. App 시스템 설치 프로그램을 다운로드하고 호출하십시오. 다운로드 완료, 나가기 Activity 설치 권한 부여, 반환 App、설치 취소 및 저장 APK 설치 프로그램을 반복적으로 열거나 작업이 손실되는 것을 방지하려면 동일한 확인된 파일을 보관해야 합니다.。GitHub 연결할 수 없는 경우 사용자에게는 명확한 재시도 및 버전 페이지 항목도 필요합니다.。

## 결정

- 다운로드 및 재사용 `ArtifactDownload.Task`。직접 액세스 GitHub 이 프로젝트에 대해서만 업데이트 요청이 허용됩니다. Release 자산 주소 및 GitHub HTTPS 게이트웨이 없이 허용 목록 리디렉션 Cookie。크기와 SHA-256 유효해야 하며 전체 검증을 통과한 후에만 설치할 수 있습니다. 이후에 추가된 게이트웨이 소스는 다음과 같습니다. [게이트웨이는 기록 업데이트를 지원합니다.](../feature/2026-10-12-gateway-assisted-android-update.md)，설치 인계 제약 조건이 계속 적용됩니다.。
- `UpdateInstallSession` 완벽한 APK 설치 권한 전송 상태는 다음 위치에 저장됩니다. App 개인 디렉토리. 복구 및 설치 전에 파일을 다시 확인하십시오. 수명주기 중단은 파일 손상을 의미하지 않습니다. 다운로드 완료 이벤트는 1번만 자동으로 전달됩니다. 사용자가 설치를 취소한 후 ”설치” 버튼을 사용하여 다시 시도합니다.。
- `DownloadProvider` 복제가 완료되면 읽기 전용 복사본이 원자적으로 해제됩니다. 이전 복사본의 길이가 일치하지 않는 것으로 확인되면 다시 복제됩니다. 시스템 보호기의 반환 결과는 방지하기 위해 원래 작업이 복원될 때까지 기다립니다. Activity 재구축 후 저장된 개체 손실。
- 「저장＞내보내기 APK，「Install”을 선택하여 시스템 설치 프로그램을 호출합니다. 확인에 실패한 경우 제공됩니다. GitHub 버전 페이지 입구; 실패한 카드 다운로드「GitHub ↗」입구는 외부 브라우저에서 감지된 버전을 엽니다. APK 직선 체인, 세부정보 보기 [다운로드 방법 선택 기록](../feature/2026-10-12-android-update-download-choice.md)。이러한 포털은 네트워크 쌍을 우회할 수 없습니다. GitHub 제한。
- 업데이트 연습을 반복하여 사용하세요. `.tmp/` 독립적이고 독립적인 소스 코드의 사본 App 심벌 마크. LAN 메타데이터, 테스트 버전 및 동일한 버전의 재설치는 이 복사본에만 존재합니다. 공식 소스 코드의 버전 선택에는 여전히 업데이트된 버전이 엄격히 필요합니다.。

## 대안

- **브라우저 다운로드를 기본 프로세스로 유지**：구현이 간단하고 사용자가 브라우저의 네트워크 환경을 편리하게 사용할 수 있습니다. 하지만 이번에는 만족할 수 없어 App 대상 내에서 직접 다운로드 및 설치되므로 실패에 대한 대체 수단으로만 사용됩니다.。
- **오직 에서만 Activity 설치 개체 유지**：디스크 포맷이나 복구 검증 비용이 없습니다. 그러나 시스템 권한 페이지와 파일 선택기가 트리거될 수 있습니다. Activity 재구성으로 인해 파일이 다운로드되지만 작업을 계속할 수 없으므로 완료된 파일과 필요한 핸드오버 상태만 유지됩니다.。
- **공식 소스 코드는 모든 업데이트 서버 또는 강제 업데이트 스위치를 제공합니다.**：테스트에는 편리하지만 프로덕션 업데이트에 대한 신뢰도가 높아집니다. 이번에는 무시된 소스 코드의 복사본에서 테스트 입력만 대체됩니다.。

## 시험

`scripts/test-mobile-downloads.py` 누락된 업데이트 메타데이터, 요약 및 크기 불일치, 리디렉션 허용 목록, 자격 증명 격리, 반복적인 핸드오버, 권한 상태 복구, 파일 변조 및 복구 중단 후 재시도를 다룹니다. 원래의 공통 첨부 파일 다운로드 및 이력서 다운로드 사용 사례는 계속 실행됩니다.。Android 빌드 및 격리 시뮬레이터 확인 기록은 다음 위치에 저장됩니다. `.tmp/pr32-local/`；사용자는 실제 테스트를 통과했으며 소스 코드만 병합할 권한이 있다고 보고했습니다.。

## 영향

전체 업데이트가 완료될 수 있습니다. Activity/프로세스가 재개되고 사용자는 여전히 시스템 설치를 제어합니다. 절충안은 소량의 개인 상태를 유지하고 복원, 설치 시 이를 다시 읽는 것입니다. APK 확인; 프로세스 간 재개 가능한 다운로드는 이 검토 범위에 속하지 않습니다. 버전이 설치되거나 사용자가 작업을 닫을 때 설치할 파일을 정리합니다.。

과거 결정 검색에서 기존 항목을 찾지 못했습니다. `.agents/notes/`、`docs/adr/` 또는 `docs/decisions/` 이 인도에 대한 기록 전화 설치 지침은 다음 위치에 있습니다. [mobile/README.md](../../../../mobile/README.md)，기존 결정을 교체할 필요가 없습니다.。
