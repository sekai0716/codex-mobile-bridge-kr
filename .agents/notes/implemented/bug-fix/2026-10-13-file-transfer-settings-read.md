# Agent Note: 파일 전송 설정은 표시되고 로그인되었을 때 읽혀집니다.

Status: implemented

## 문제

파일 전송 설정은 게이트웨이 장착 시 즉시 읽혀지며, 로그인하기 전에 읽혀집니다.“로그인해주세요”모양 패널에 머물러 있습니다. 후속 읽기에 성공하면 입력 값만 업데이트되고 이 이전 오류는 지워지지 않습니다. 데스크탑 고급 패널도 숨겨지면 미리 설정을 요청합니다.。

## 결정

파일 전송 설정은 패널이 표시되고, 페이지가 숨겨지지 않고, 호출자가 준비된 경우에만 읽혀집니다.。Web 호출자는 명시적으로 로그인한 후 애플리케이션의 준비 상태를 확인합니다. 데스크톱 네이티브 호출자는 준비 상태를 명시적으로 제공합니다. 패널 표시, 창 포커스 및 로그인 완료 이벤트는 폴링을 추가하지 않고도 읽기를 트리거합니다. 성공적인 읽기는 이전 읽기 오류를 지우고 편집 중인 값을 덮어쓰지 않습니다.。

## 대안

로그인 시 자동으로 재시도하고 탑재 시 요청을 유지합니다. 트리거 수는 적지만 여전히 의미 없는 무단 요청을 생성하며 데스크톱 숨김 패널의 시나리오를 처리할 수 없습니다.。

## 영향

열지 않은 설정 패널은 더 이상 읽기를 트리거하지 않습니다. 오류는 사용자가 실제로 설정을 볼 때만 나타나고 다음 읽기에 성공하면 사라집니다. 독립 저장 버튼은 계속 업데이트됩니다. clickDownloadMiB，게이트웨이 일반 설정 초안을 입력하지 마세요. 숨겨진 장착을 확인하고 읽기 및 독립적인 저장을 표시하는 데스크탑 설정 테스트。
