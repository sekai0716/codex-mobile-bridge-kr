# Agent Note: 설치된 개발 도구가 여전히 반복적으로 나타납니다. Git 설치 팁

Status: implemented

## 문제

이 기계는 이미 설치되어 있습니다. Command Line Tools，하지만 시작 ZCode 또는 Codex 후에도 여전히 팝업이 표시됩니다.“git 이 명령에는 명령줄 개발자 도구를 사용해야 합니다.”。팝업을 취소하거나 다시 설치하세요. CLT 해결될 수 없습니다. 서로 다른 시점의 통합 로그는 Codex 내장형 액추에이터 및 ZCode 지역의 host，하나의 속성을 사용하여 모든 후속 상황을 대체할 수는 없습니다.。

## 결정

먼저 시스템이 선택한 개발자 디렉터리와 실제 실패 이유를 확인한 후 환경을 변경하지 않고 처리합니다. Bridge 허가 확인 또는 원본 App 패키지를 설치합니다. 현재 선택완료 Xcode 26.3；`xcodebuild -version` 성공할 수 있지만 실행이 선택됨 SDK 아래에 `-find git` 승인되지 않은 것으로 명확하게 보고됨 Xcode 및 Apple SDK 특허. 독립적인 CLT 의 Git 사용 가능은 시스템에서 선택되었음을 의미하지 않습니다. Xcode 툴체인 사용 가능。

사용자가 로컬 라이선스 경로를 검토하고 명시적으로 승인한 후 Xcode 기본 라이센스 인터페이스가 허용됩니다. 관리자 인증은 시스템 창에서 사용자가 완료합니다. 도구는 비밀번호를 읽거나 입력하지 않습니다. 시스템 개발 도구 디렉토리를 전환하거나 소프트웨어를 반복적으로 설치할 필요가 없습니다.。

## 대안

각 발신자에 대해 필수 CLT 해당 경로는 일시적으로 팝업을 방지할 수 있지만 다른 팝업은 복구할 수 없습니다. App 체계 Git，사용자의 기대치가 바뀔 수도 있습니다. iOS 컴파일 툴체인이므로 사용되지 않습니다. 개정하다 ZCode 패키지 설치 또는 개인 파이프 인증 완화는 이 문제와 관련이 없습니다. 라이센스를 직접 자동으로 수락하는 것은 사용자 인증이 부족하므로 먼저 명시적으로 확인한 후 시스템 인증을 기다립니다.。

## 검증

라이센스를 확인하기 전에 직접 선택을 실행하십시오. Xcode 의 `-sdk ... -find git` 종료 코드 반환 69 권한 프롬프트가 허용되지 않습니다. 완료 후에는 임시 환경 적용 범위가 추가되지 않습니다. `/usr/bin/git --version` 뒤로 Git 2.50.1，`xcrun --find git` 원본으로 돌아가기 Xcode 26.3 이내에 Git，`xcode-select -p` 변함없이 유지됩니다. 이전 설치에서는 프로세스가 더 이상 존재하지 않는다는 메시지가 표시됩니다.。

## 영향

이는 기본 개발 환경 수정 사항이며 제품 출시에 추가 소프트웨어 설치가 필요하다는 증거로 사용되지 않습니다. 다른 컴퓨터에도 동일한 텍스트가 나타나면 선택한 디렉터리, 라이센스 및 설치 상태를 다시 확인해야 합니다. 이 질문은 다음과 관련이 있습니다.[중국어 경로 프로세스 쿼리](2026-11-04-macos-process-query-utf8.md)근본 원인은 서로 독립적으로 혼합될 수 없습니다.。
