# Agent Note: Windows 실행을 포함하는 최초의 완전한 발견 WSL

Status: implemented

## 문제

데스크톱 우선 검색 전송됨 `inventoryOnly`，따라서 공유 관리자는 폐쇄됩니다. WSL 주사; 로컬 설치 캐시가 있는 경우에도 계속 입력됩니다. WSL 등록 전에 반환하십시오. 게이트웨이를 중지하면 기존 캐시도 삭제됩니다. `loadClients` 첫 번째 발견 건너뛰기。Windows 의 Codex 및 Claude Code 이미 있더라도 WSL 시스템에 존재하며 사용자가 수동으로 다시 검색하는 경우에만 나타날 수 있습니다.。

## 결정

Windows 이번 게이트웨이 프로세스에서 처음으로 기본 관리자가 완성되었습니다. inventory 다중화에는 두 가지가 있다. WSL 한번 등록해보세요. 평범한 `clients` / `clients_status` 감지되지 않습니다. 이번 라운드에 아직 시도하지 않은 경우에만 공유됨 `inventoryAvailable` 다음과 같이 예상됨 false，기존 드라이브 `loadClients → scan(inventoryOnly)` 입구. 이 시스템에서 첫 번째 검색이 발생했습니다. inventory 반환되기 전에 일찍 캐시되었습니다. 독립적인 Desktop 하위 인스턴스、macOS 및 Linux 이 채널에 들어오지 마세요。

레지스터를 호출하기 전에 메모리에 기록된 플래그를 표시해 보십시오. 두 등록기관이 별도로 시도되며 기존 등록기관과 함께 오류나 예외가 발생합니다. `errors` 모양 캐시가 반환되었습니다. 합격자는 유지됩니다. 이번 라운드 실패 후 inventoryAvailable 이 시도는 페이지 열기 또는 상태 새로 고침으로 인해 반복 감지 없이 ​​계속 완료됩니다. 사용자 매뉴얼 스캐닝 및 기존 `scan-wsl` 명시적으로 재시도하고 이번 라운드의 결과를 바꾸세요. 데스크톱 검사 피드백은 실제 오류를 표시하고, 부분 오류 완료를 호출하지 않으며, 반환된 클라이언트를 제거하지 않습니다.。

등록자는 실행 중인 배포만 계속 감지하고 실제로 호출하기 전에 다시 확인합니다. 메모리 후보만 업데이트되고 구성이 등록되거나 활성화되지 않으며 릴리스 버전이 시작되지 않는 것으로 나타났습니다.、CLI 또는 daemon，세션은 복원되지 않으며 기존 작업은 변경되지 않습니다. 저장됨 profiles/enabled 원래 연결 개체를 유지합니다. 실행 중인 배포가 없을 때만 빈 후보를 얻습니다. 후보는 현재 설계된 대로 프로세스 내에서 캐시되며, 지속적인 검색 예약을 추가하지 않고도 새 관리자의 첫 번째 전체 검색을 다시 검색할 수 있습니다.。

## 대안

상태를 읽을 때마다 스캔하면 새로운 설치 환경을 구성할 수 있지만 계속해서 실행됩니다. WSL 하위 프로세스를 수행하고 디스플레이 판독을 검색 작업으로 전환합니다. 영구적인 지속성“스캔됨”다시 시작한 후 읽기를 줄일 수 있지만 다음 실행에서는 메모리에만 존재하는 후보가 사라지게 됩니다. 조정만 inventoryOnly 매개변수 변경사항은 적지만 기존 설치 캐시의 조기 반환을 우회할 수 없으며, 첫 페이지가 열릴 때 발견할 수도 없습니다. 따라서 기존의 명시적 inventory 입장, 이번 라운드의 첫 번째 접근 제어 및 후보 캐시 상태만 추가됩니다.。

## 검증

현실 `clients_status` 및 scan 프로덕션 데스크탑에 대한 다른 연결에 응답 DOM 의 `loadClients`，첫 번째 액세스 제어가 실제로 트리거되었는지 확인 inventoryOnly、부분적인 오류가 계속 표시됩니다. Codex 후보 및 오류, 일반 새로 고침 보존 오류, 수동 재시도 복구라는 두 가지 범주가 있습니다. 위의 내용이 처음 실행됩니다. Mac 격리 설비. 비공개 소스코드 패키지 동결 Windows 전체 279 회원 SHA 검증 후, 또 다른 실제 읽기 전용 프로브가 실행 중인 각 배포판에서 하나를 발견했습니다. Codex / Claude Code 후보: 처음으로 구성 프로브를 한 번 실행한 다음 inventory/status 더 이상 실행되지 않으며 수동 재검색이 각각 한 번씩 추가됩니다. 오류가 0이고, 후보가 활성화되지 않았으며, 등록 또는 기본이 없습니다. owner，실행 중인 세트는 변경되지 않습니다. 조사 PID12400 정상 exit0，같은 Terra 사실에 기반한 완전한 검토. 사실이다 WSL 메타데이터 및 2개의 등록기관 기본적으로 설치됨 inventory 격리 캐시 고정 장치를 의도적으로 사용한다고 해서 설치를 의미하는 것은 아닙니다. CLI 실행, 형식 App 또는 엔드 투 엔드 수용 모델。

## 영향

Windows 첫 번째 완전한 검색은 당시 실행 중이던 것을 보여줍니다. WSL Codex 및 Claude Code，그런 다음 정상적으로 페이지를 엽니다./재사용 후보를 새로 고칩니다. 비용은 기존 제한 시간 및 상태 검토에 따라 관리자 프로세스당 추가 검색입니다. 나중에 시작되거나 실패한 릴리스는 사용자가 수동으로 다시 검색해야 합니다. 기존 배포가 실행되고 있지 않으면 검색을 위해 깨어나지 않으며 새로 추가되지 않습니다. macOS/Linux 의 WSL 옵션을 변경하거나 수동 등록이나 디렉터리 권한을 변경하지 마세요.。
