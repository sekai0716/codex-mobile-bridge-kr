2026-11-08 실제 사용자 Android 휴대폰 확인 : 게이트웨이 `2.2.0-test.20261108.rc5` 휴대폰과 호환 가능 rc3，채널이 정상적으로 감지되고 닫힐 수 있습니다. WiFi 그런 다음 공용 네트워크로 전환하고 다시 연결할 수 있습니다. WiFi 그런 다음 LAN으로 다시 전환할 수 있습니다. 이전에 핸드셋과 게이트웨이 조합이 종료되었습니다.“거짓 도달 불가능”수락 차단; 사용자 피드백을 모든 장치로 확장하거나 코드를 다시 스캔하여 중복을 제거하거나 첨부 파일 초안을 유지하지 말고 이에 따라 고유한 근본 원인을 찾았다고 주장하지 마십시오. 이후에는 이 통과된 결과가 활용되며, 버전명 조정으로 인해 동일한 점검이 반복되지 않습니다.。

2026-11-12 기존에 Android 35 시뮬레이터에서 독립적인 테스트 패키지로 전체 패키지를 컴파일합니다. ## 영향

후속[LAN 우선순위 규칙](../feature/2026-11-02-prefer-lan-channel.md)교체됨“LAN 복구 후에도 여전히 정상 상태로 유지됨 HTTPS”공용 네트워크 간의 자동 장애 조치; 장치 바인딩, 첫 번째 경쟁 및 원본 페이지 핸드오버는 이 디자인을 따릅니다.。

오래된 게이트웨이와 DSH Mobile 원래 입구로 계속 가세요. 처음으로 컴퓨터를 켤 때 페이지를 로드해야 합니다. 채팅이 활성화되면 회선 변경이 성공할 때마다 동일한 게이트웨이에 대한 요청 채널만 다시 설정되며 채팅은 계속해서 기존 커서를 사용하여 후속 콘텐츠를 읽습니다. 업로드가 중단되면 원본 업로드가 사용됩니다. ID 재시도 규칙을 적용하면 업로드된 첨부 파일이 입력 상자에 그대로 유지됩니다.。
