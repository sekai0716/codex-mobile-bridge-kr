# Agent Note: DSH 독립 플러그인 소스 코드와 게이트웨이 내장 사본 간의 경계

Status: implemented

## 문제

사용자는 공통적으로 독립적인 창고 유지 관리가 필요합니다. DSH 플러그인. 기존 공식 원클릭 설치와 수동 내보내기가 공유됩니다. host 소스 코드, 파일을 직접 제거하면 기존 설치 동작이 변경됩니다.。

## 결정

독립 창고 `dsh-codex-mobile-bridge` 완전한 런타임, 원본 라이센스, 소스 매니페스트, 루프백 프로토콜 테스트 및 재현 가능한 패키지 스크립트를 보유합니다.。Bridge 다음을 통해 현재 내장된 복사본을 보관하세요. `plugin-source.json` 독립 실행형 저장소 커밋을 수정했습니다. 명시적으로 지정된 로컬 저장소만 읽도록 검사 스크립트를 수정했습니다. Git 객체, 런타임 및 라이선스를 바이트 단위로 비교하고 패키지 버전, 코어 버전 및 프로토콜 필드를 비교하며 플로팅 작업 공간을 읽지 않으며 네트워크에 연결하지 않으며 실제 액세스를 업데이트하지 않습니다.。

후속 플러그인 런타임 수정이 독립 웨어하우스에서 완료된 후 Bridge 주제 분기 및 업데이트 고정 커밋. 문서화 및 저장소 메타정보는 독립적으로 유지 관리될 수 있습니다. 런타임 변경 사항은 함께 검토해야 합니다. 모든 변경 사항에 대해 기본 제공 host 공개된 내용을 유지하면서/이전 버전 원본 설치 LF/CRLF 기존 설치 기록, 경로 및 개인 자격 증명의 공동 확인을 위한 해시입니다. 이전 소스 코드를 식별한다고 해서 실행 중인 작업 검사를 자동으로 덮어쓰거나 건너뛰는 것을 의미하지는 않습니다. 이후 사용자는 생성되어 푸시된 독립 플러그인의 소스 코드 공개를 명시적으로 승인했습니다. `try2love/dsh-codex-mobile-bridge`，원격 main 로컬 커밋 및 파일 목록으로 확인했습니다. 게시되지 않음 npm 또는 설치 가능한 시장. 원래 패키지 작성자 및 `coding-mobile` MIT 라이선스 예약, 독립 저장소의 초기 가져오기는 전체 저작권을 상속한다고 주장하지 않습니다. Git 역사。

## 대안

내장 복사본을 즉시 제거하면 물리적 중복이 제거되지만 고정 배포 및 기본 원클릭 설치에는 필요하며 로드 경로는 현재 마이그레이션되지 않습니다. 별도의 디렉토리를 복사하는 것이 더 간단하지만 향후 편차를 감지하지 못하므로 고정 커밋 검사가 추가됩니다.。

## 검증

독립 창고의 플러그인 루프백 테스트 및 재현 가능한 포장 테스트를 통과했습니다.。Bridge 올바르게 고정된 커밋, 고정된 소스에 영향을 주지 않는 작업 공간 변경, 내장 파일 드리프트 및 버전 필드 드리프트의 적용 범위를 확인합니다.。2026-11-04 ～에서 Test 128.11 업그레이드 승인 중에는 기존 revision 9 파일 및 d75c61e 패키지된 소스 코드 바이트는 일관되지만 새 호환성 목록에서는 이 해시를 생략하고 액세스를 거부합니다. 보충 고정 Git 개체와 실제 설치 파일 간에 두 개의 개행 요약이 이중으로 확인되며 식별 프로세스에서는 구성, 원본 자격 증명 및 소스 파일이 변경되지 않습니다. 알 수 없는 소스 코드는 여전히 거부됩니다. 플러그인 소스 코드 프로토콜 테스트 및 업그레이드 식별 확인은 별도로 설정되며 각 플랫폼의 실제 설치 및 승인을 대체하지 않습니다.。

## 영향

플러그인에는 독립적인 유지 관리 입구가 있으며 기존 설치 및 내보내기는 변경되지 않습니다. 그 대가는 관리자가 명시적으로 동기화해야 한다는 것입니다. 독립 소스 코드를 게시할 수 있는 라이센스는 이 저장소에만 적용됩니다.；npm、시장도 그렇고 Bridge 기본 저장소 푸시 및 버전 릴리스가 아직 승인되지 않았습니다.。
