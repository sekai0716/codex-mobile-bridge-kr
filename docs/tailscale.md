# Tailscale 결정된 HTTPS 입구

자체 서버나 초대 코드를 구축할 필요가 없습니다. 게이트웨이는 컴퓨터에 설치된 공식 버전을 재사용합니다. Tailscale 클라이언트는 기존 워크벤치에 고정 주소를 제공합니다. 컴퓨터, 게이트웨이 및 Agent 클라이언트는 계속 실행되어야 합니다.；Tailscale 잠자고 있는 컴퓨터를 깨우지 않음。

## 최초 구성

1. 설치하다 [Tailscale 공식 고객](https://tailscale.com/download)，귀하의 계정에 로그인하고 연결을 엽니다。macOS 처음 시작할 때 시스템 설정에서 네트워크 확장을 허용해야 합니다.；Windows/Linux 공식 서비스가 실행 중이어야 합니다. 필요 1.52 이상。
2. 게이트웨이에서 **네트워크 접속** 다음에 추가 **결정된 HTTPS · Tailscale**。선택하다 **공용 네트워크 액세스 · Funnel**，구성 저장。
3. 딸깍 하는 소리 **발각 Tailscale 그리고 주소를 읽어보세요**，그런 다음 자동 완성된 주소를 저장하세요. 도메인 이름이나 비밀번호를 수동으로 입력할 필요가 없습니다.；Tailscale 로그인 자격 증명은 공식 클라이언트에서 관리됩니다.。
4. 게이트웨이를 시작하십시오. 승인하라는 메시지가 표시되면 **계속하다 Tailscale 승인하다**，에서 Tailscale 공식 페이지 활성화됨 HTTPS / Funnel。해당 네트워크 관리 권한이 필요합니다. 권한이 없으면 직접 문의하세요. Tailscale 네트워크 관리자。
5. 딸깍 하는 소리 **고정된 출입구 감지**，그런 다음 개요에서 휴대폰 페어링 코드를 생성하세요. 일반 모바일 브라우저 및 휴대폰 App 설치할 필요가 없습니다 Tailscale；게이트웨이의 원래 로그인과 QR 코드 페어링을 계속 사용하세요.。
6. 휴대폰 꺼짐 Wi-Fi，첫 번째 열기, 채팅 읽기 및 쓰기, 파일 다운로드 및 다시 연결을 확인합니다. 컴퓨터 측 감지는 셀룰러 네트워크에 연결할 수 있음을 의미하지 않습니다.。

macOS 추천 Tailscale 공식 웹사이트의 독립 설치 패키지（Standalone）；Funnel 플랫폼 요구 사항은 다음을 참조하세요.[공식 설명](https://tailscale.com/docs/features/tailscale-funnel)。

Funnel 공용망으로 입구가 제공되므로 게이트웨이 로그인 인증을 활성화해야 합니다. 연결 문제를 해결하기 위해 확인을 끄지 마십시오。

## 비공개 액세스

선택하다 **비공개 네트워킹 · Serve** , 단지 동일 Tailscale 사설망에 접근할 수 있는 권한이 있는 장치만 들어갈 수 있습니다. 브라우저에는 플러그인이 필요하지 않지만 휴대폰에서는 플러그인이 필요하지 않습니다./컴퓨터에는 다음이 있어야 합니다. Tailscale 네트워크 연결. 이 버전은 휴대폰에서 사용할 수 없습니다. App 임베디드 Tailscale。

## 주소 및 시작/중지

- 주소는 `https://장치 이름.네트워크 이름.ts.net`，HTTPS 증명서 Tailscale 관리하다. 일반 재부팅에서는 장치 ID와 이름이 보존되는 동안 임시 주소를 다시 할당하지 않습니다.。
- 기기를 삭제하거나, 계정을 전환하거나, 이름을 변경한 후에는 게이트웨이를 중지하고 다시 감지하여 저장해야 합니다. 원래 휴대폰 주소를 업데이트해야 할 수도 있습니다.。
- 포털은 게이트웨이와 함께 시작되고 중지됩니다. 제어판을 종료하고 게이트웨이를 유지하면 포털은 그대로 유지됩니다.。
- 게이트웨이가 종료되지 않습니다. Tailscale，실행되지 않음 `serve reset`、`tailscale down` 또는 `logout`。이 프로젝트에서 생성된 포그라운드 세션은 다음에 의해 제어됩니다. Tailscale 청소하다。
- 기본적으로 사용됨 HTTPS 443。다른 사람에 의해 Tailscale 서비스가 점유된 경우에는 덮어쓰지 않으며, 다음으로 변경될 수 있습니다. 8443 또는 10000，확인하고 다시 저장하세요. 이제 액세스 주소에 포트가 포함됩니다.。
- 컴퓨터를 다시 시작한 후，Tailscale 연결을 복원하고 게이트웨이를 시작해야 합니다. 게이트웨이의 자동 시작 옵션은 운영 체제를 대체하지 않거나 Tailscale 로그인 설정。

## 네트워크 제한 및 문제 해결

Funnel 사용 Tailscale 공용 네트워크 서비스에는 대역폭 제한이 있으며 국내 셀룰러 네트워크 속도를 보장하지 않습니다. 고정 도메인 이름은 주소 변경 문제를 해결하며 실제 회선 테스트를 대체할 수 없습니다.。Funnel 내장의 HTTPS 입장이 제한됩니다. `.ts.net`，사용자 정의 도메인 이름을 직접 지원하지 않습니다.。

| 힌트 | 다루다 |
| --- | --- |
| 클라이언트를 찾을 수 없습니다 | 공식 설치 Tailscale，재테스트；macOS 애플리케이션 카탈로그 및 Homebrew，Windows 표준 설치 디렉토리 지원，Linux 지원하다 PATH/표준 카탈로그 |
| 로그인 또는 네트워크 권한을 기다리는 중 | 열려 있는 Tailscale，완전한 로그인 및 시스템 네트워크 인증 |
| 기다리다 HTTPS/Funnel 승인하다 | 승인을 계속하고 공식 페이지 작업을 완료하려면 클릭하세요. |
| 첫 번째 인증 후에는 공용 네트워크에서 도메인 이름을 찾을 수 없습니다. | 공용 네트워크 DNS 로깅에는 최대 10 분 스프레드; 컴퓨터 MagicDNS 개인 주소를 먼저 확인할 수 있지만, 휴대폰의 셀룰러 네트워크를 사용하여 공용 네트워크 액세스를 확인해야 합니다. |
| 다른 서비스에서 포트를 사용하고 있습니다. | 지원되는 다른 선택 HTTPS 포트, 기존 재설정 필요 없음 Tailscale 설정 |
| 계정 또는 장치 주소 변경 | 게이트웨이를 중지하고 현재 계정을 확인한 후 저장하세요. |
| 포털이 시작되지만 감지에 실패함 | 조사하다 DNS、자격증、Funnel 승인 및 공용 네트워크 회선 건너뛰지 마세요 TLS 또는 게이트웨이 확인을 끄세요 |
