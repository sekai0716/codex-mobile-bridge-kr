| Windows 인식 가능한 매장 설치 | 공개 목록에 있는 제품 및 설치 패키지의 ID를 확인합니다. 확인 후 해당 전화를 엽니 다 Microsoft Store 제품 페이지 |
| 다른 채널 또는 인식할 수 없는 설치 | 컴퓨터나 패키지 관리자를 확인하라는 메시지가 표시됩니다. 다운로드 주소를 추측하지 마세요 |

공개 버전 비교는 장치 업데이트 자격과 동일하지 않습니다. 그레이스케일 게시, 조직 정책, 계정 자격 및 설치 확인은 기본 업데이트 프로그램 또는 스토어에서 처리됩니다. 쿼리 실패는 표시되지 않습니다.“이미 최신”。

“확인하다 Codex 새 버전”공개 버전 정보만 읽고, 바탕화면 메뉴를 조작하지 않으며, 접근성 권한을 요청하지 않습니다.。“컴퓨터 업데이트 창을 엽니다”원본 버전의 경우 Codex Desktop。macOS 앱을 포그라운드로 가져와서 트리거합니다.“업데이트 확인 / Check for Updates…”메뉴, 이후 확인, 다운로드, 설치는 컴퓨터에서 이루어져야 합니다. Codex 자체 처리; 게이트웨이 App 별도의 업데이트 포털 사용。Web 이 제한사항은 휴대폰에 직접 표시됩니다.。

포털을 시작하기 전에 웹 페이지에 표시되지 않는 작업을 포함하여 모든 데스크톱 작업이 종료되었는지 확인해야 합니다. 게이트웨이는 또한 알려진 실행 중인 작업, 보류 중인 작업 및 대기 중인 메시지를 가로챕니다. 비밀번호 없이 액세스하면 데스크탑 업데이트를 시작할 수 없습니다.。

macOS 실행 중인 대상 애플리케이션, 잠금 해제된 데스크탑, 제어가 필요합니다. System Events 자동화 권한 및 접근성 권한. 대상 프로세스별 게이트웨이 검색“업데이트 확인”메뉴, 시스템 인증 및 메뉴 응답에 최대 3분이 소요됩니다. 실패한 경우 권한, 시간 초과, 누락되거나 사용할 수 없는 메뉴가 구별되고 재시도 항목이 유지됩니다. 재시도할 때마다 데스크톱 작업이 종료되었는지 확인해야 합니다. 인증이 켜져 있지만 시스템이 여전히 거부하는 경우 게이트웨이를 종료했다가 다시 열고 다시 시도할 수 있습니다.。

메뉴 작업이 성공한 후 인터페이스가 표시됩니다.“컴퓨터의 확인을 기다리는 중”，설치는 여전히 기본 업데이트 프로그램에 의해 결정됩니다. 메뉴 열기, 스토어 열기, 체크 성공 시에는 설치 완료로 간주되지 않습니다. 현재는 무인 원격 다운로드 및 설치가 제공되지 않습니다. 설치 버전의 변경 사항을 감지한 후 결과를 검증하게 되며, 여전히 입구가 열려 있는 것은 업데이트가 완료된 것으로 볼 수 없습니다.。
