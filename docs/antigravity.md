# Antigravity 연결

설치 및 사용 Antigravity 그런 다음 컴퓨터 게이트웨이에서 애플리케이션을 다시 검사하고 활성화합니다. Antigravity，브라우저나 휴대폰에서 보기 App、IDE 및 CLI 지역 역사。

기본이 아닌 설치 위치는 다음에서 찾을 수 있습니다.“클라이언트 및 액세스 → 클라이언트 추가 → Antigravity”선택하다 App、IDE 아니면 공식적으로 `agy` 프로그램. 세 개의 프로그램이 하나를 공유합니다. Antigravity 관리 포털은 해당 기본 데이터에 계정과 세션을 유지합니다. 기존 설치 목록은 다음 시작 시 재사용됩니다. 새 클라이언트 설치 후 클릭“다시 스캔”。

실시간 작업을 위해서는 컴퓨터의 해당 소스에서 기본 서비스가 계속 실행되어야 합니다. 게이트웨이는 원래 세션과 프로젝트를 계속 사용합니다. 새 채팅을 생성할 때 프로젝트를 선택하고 원래 클라이언트가 프로젝트 소유권을 확인한 후 전송될 첫 번째 메시지를 입력하세요. 모델 목록은 현재 소스의 원래 클라이언트에서 제공되며 독립적인 사고 강도 및 할당량 관리를 제공하지 않습니다.。

컴퓨터 게이트웨이 Antigravity 관리 페이지를 별도로 볼 수 있습니다. App、CLI、IDE 기록 및 연결 상태, 채팅을 선택하고 전송 모델 및 게이트웨이 구성 Hook 승인 방법. 모델 및 승인 설정은 선택한 채팅에만 적용됩니다. 계정과 로그인은 원래 클라이언트에서 계속 관리됩니다. 채팅 목록을 클릭할 수 있습니다. APP、CLI、IDE 필터. 기본 서비스 연결이 끊어지면 입력 영역, 초안 및 기록이 유지되며 이는 지원되지 않습니다. Skill、계획 및 목표 모드는 비활성화된 상태로 유지됩니다.。

액세스를 활성화하면 별도의 Codex Mobile Bridge Hook 플러그인. 원래 세션 로드 중 Hook 마지막으로 휴대폰을 사용하여 질문을 승인하고 대기열에 넣을 수 있습니다. 추가 작업은 현재 기본 단계가 끝날 때 주입되고, 원래 클라이언트가 작업이 유휴 상태임을 확인한 후 대기 중인 메시지가 주입됩니다. 원래 상태를 알 수 없거나 연결이 중단되었습니다. 자동으로 재전송되지 않습니다. 먼저 컴퓨터에서 원래 세션을 확인하세요.。

업로드된 첨부 파일은 로컬 파일 참조를 통해 원래 클라이언트로 전달됩니다. 기록 사진은 현재 세션이나 프로젝트 내의 파일만 미리 볼 수 있습니다.。

비활성화하다 Antigravity 이 플러그인이 비활성화되고 모바일 액세스가 종료됩니다. 아직 제공되지 않은 애플리케이션, 계정 관리 및 기본 작업을 종료하려면 컴퓨터의 원래 클라이언트에서 완료하십시오.。
