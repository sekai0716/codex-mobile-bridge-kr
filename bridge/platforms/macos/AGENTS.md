# macOS 플랫폼 유지보수

- 이 디렉터리는 앱 패키지 식별과 실행 파일 해석, 같은 사용자의 프로세스, Launch Services를 통한 시작·종료, Claude의 활성 프로필 경로 검색, Swift 네이티브 도우미를 담당합니다.
- macOS 고유 문제는 이 디렉터리에서 우선 수정합니다. `bridge.clients` 또는 `bridge.features`를 역방향으로 가져와서는 안 됩니다. 앱 활성화, 계정 전환, 작업 상태, 권한 부여, 재시작 판단은 계속 공통 기능 계층에서 처리합니다.
- `.app` 패키지 식별과 실제 실행 파일 경로 검증을 유지합니다. 프로세스 명령을 읽을 때 전체 경로와 공백을 보존하고, 제품 표시 이름으로 앱의 신원을 대신해서는 안 됩니다.
- GUI 실행에는 기존 Launch Services 경로를 사용하며 호출자가 지정한 환경과 사용자 디렉터리를 유지합니다. 게이트웨이가 내장 CLI를 직접 실행하는 방식으로 바꾸거나, 클라이언트의 개인정보 보호 권한이 게이트웨이의 신원을 기준으로 적용되도록 변경해서는 안 됩니다.
- Claude 프로필 검색은 지정한 앱이 열어 둔 파일의 경로만 읽습니다. Cookie, 토큰, 그 밖의 프로필 내용은 읽지 않습니다. Swift 도우미는 선택한 클라이언트만 조작하며, 권한과 취소 결과는 공통 연결 계층에 반환합니다.
- 여러 상태를 표시할 때 네이티브 조회를 합칠 수 있습니다. 종료·재시작 작업을 보내기 전에는 반드시 공통 진입점에서 프로세스를 다시 검증해야 하며, 표시용 캐시를 재사용해서는 안 됩니다.
- `posix/`의 프로세스·터미널 구현은 Linux에서도 사용합니다. 공통 부분을 수정할 때 Linux와 Windows가 터미널 공용 메서드에 의존하는 부분을 확인하고, 네이티브 도우미의 빌드·리소스 경로가 일치하도록 유지합니다.
