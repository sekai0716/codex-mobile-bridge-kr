# Android 및 iOS App

휴대폰에서 게이트웨이 QR 코드를 스캔해 Codex, Claude Desktop, DeepSeek Harness에 연결합니다. 작업은 컴퓨터에서 계속 실행됩니다. 모바일 앱은 여러 컴퓨터 저장, 네이티브 QR 스캔, 클립보드, 파일 다운로드, 알림을 지원하며 브라우저로도 접속할 수 있습니다.

이 한국어 포크는 원본의 LAN HTTP·HTTPS 접속을 유지합니다. 외부 인터넷 접속에는 HTTPS를 사용합니다. 아래 과거 릴리스 설명과 원본 다운로드 링크는 업스트림의 배포 이력이며, 이 포크의 한국어·보안 변경이 포함된 설치 파일을 뜻하지 않습니다.

## 컴퓨터 연결 및 관리

1. 패키지 열기 v2 게이트웨이, 애플리케이션 구성을 완료하고 ”클라이언트 및 액세스”에서 필요한 클라이언트를 활성화합니다. 도달 가능한 네트워크 입구를 선택하고 게이트웨이를 시작하십시오.。
2. 휴대폰에서 ”QR 코드를 스캔하여 컴퓨터에 연결”을 클릭하고 게이트웨이 개요에서 이 포털에 대해 생성된 페어링 코드를 스캔하세요. 전체 게이트웨이 주소를 붙여넣고 게이트웨이 계정 비밀번호를 입력할 수도 있습니다.。
3. ”내 컴퓨터”에서 카드나 애플리케이션 아이콘을 클릭하면 해당 클라이언트 채팅 목록에 들어갈 수 있습니다. 컴퓨터는 최근 액세스를 기준으로 정렬되며 이름을 바꾸거나 제거하거나 온라인 상태를 수동으로 새로 고칠 수 있습니다.。
4. 컴퓨터, 게이트웨이 및 해당 클라이언트를 온라인 상태로 유지합니다. LAN을 사용하려면 컴퓨터에 액세스하기 위해 휴대폰이 필요합니다. 외출시 선택사항 [Tailscale](../docs/tailscale.md)、[Cloudflare](../docs/fixed-domain.md)、[자체 서버 + SSH](../docs/server-ssh.md) 아니면 이미 HTTPS 반세대적。

QR 코드를 스캔하면 게이트웨이 비밀번호를 저장하지 않고 철회 가능한 신뢰 기기 바인딩을 만듭니다. Android는 시스템 키로 암호화한 바인딩을, iOS는 키체인에 바인딩을 저장합니다. WebView 로그인 상태를 잃으면 해당 게이트웨이에서 유효성을 먼저 확인한 뒤 복원합니다. 명시적 로그아웃, 컴퓨터 제거, 서버에서의 기기 철회 후에는 복원하지 않습니다. 일시적으로 네트워크에 연결할 수 없다는 이유로 바인딩을 삭제하지 않으며, 앱이나 게이트웨이를 재시작해도 유효한 바인딩은 유지됩니다. 휴대폰의 장기 페어링은 일반 브라우저의 로그인 유효기간과 별도로 유지됩니다. PC의 ‘로그인 및 기기’에서 바인딩을 철회할 수 있습니다. 컴퓨터 제거, 앱 데이터 삭제, 인증 변경, 명시적 철회 후에는 다시 페어링해야 할 수 있습니다. 만료된 이전 로그인은 자격 증명 없이 새 바인딩으로 승격되지 않습니다.

카메라 스캐닝은 네트워크 채널을 설정하지 않습니다. 고정된 주소는 국내 직접 연결 속도를 보장하지 않습니다. 실제 확인해주세요 Wi-Fi、셀룰러 인증。Tailscale Funnel 휴대폰 설치가 필요하지 않습니다. Tailscale；사적인 Serve 그런 다음 휴대폰에 액세스할 수 있는 권한이 필요합니다. tailnet。

### 임시 주소 변경

평범한 Cloudflare 다시 시작한 후 임시 주소가 변경될 수 있으며, 휴대폰은 잘못된 URL만으로는 컴퓨터를 찾을 수 없습니다. 고정된 입구를 사용하거나 게이트웨이 시작을 활성화하는 것이 좋습니다/출입구 변경 알림 및 새 주소 받기。

소스 코드는 종속성을 유지하고 안정적입니다. HTTPS 쿼리 서비스의 주소 검색 프로토콜은 항목이 이전에 바인딩되었고 쿼리 서비스에 연결할 수 있는 경우에만 항목을 확인하고 복원할 수 있습니다. 모든 임시 터널에 대한 자동 주소 갱신을 약속하는 것은 아닙니다.。v2 초대코드 ’자체생성릴레이’가 데스크탑에서 삭제되었습니다. · ”내부 베타” 구성 입구. 안정적인 항목이 변경되거나 페어링이 취소되거나 컴퓨터 데이터가 재구성된 후에도 QR 코드를 다시 스캔해야 할 수 있습니다.。
